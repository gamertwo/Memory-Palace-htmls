Closed Cube in Nonuniform Field

This page is not about crunching every number. It is about remembering how to inspect a field component and decide which cube faces can possibly contribute.

Start Formula
$$\vec E=3.0x\,\hat i+4.0\,\hat j$$
End Formula
Net flux comes from the faces whose outward normals match the field components.
Rooms

Room 1: Read the Field

  • The field has an x part and a y part.
  • There is no z part to worry about.

Room 2: Match Faces to Components

  • X faces care about the x component.
  • Y faces care about the y component.

Room 3: Constant or Changing

  • The y component is constant.
  • The x component changes with x.

Room 4: Opposite Faces Compare

  • Check each pair of opposite faces.
  • Ask whether their flux cancels or leaves a net result.

Room 5: Ignore Wrong Directions

  • If a field component does not point through a face, that face gets nothing from that component.
  • This keeps the bookkeeping simple.

Room 6: Assemble Net Flux

  • Net flux is the sum of the contributing face groups.
  • The cube story is about matching direction first, arithmetic second.
Simple Summary

Read the field by components, match each component to the correct faces, ignore the wrong directions, and then compare opposite faces to get the net flux.
