Lab 6 Debugging Task 1

Fix the Broken Recursive Sum of Digits

This debugging task is mostly about base-case correctness. One wrong symbol in recursion can destroy the entire logic.

$$\text{if } n==0 \text{ return } 0,\qquad \text{else return } n\bmod 10 + sumDigits(n/10)$$
Recursion GuideOpen in Memory Builder
Broken Code Shape
int sumDigits(n)
{
    if (n = 0)
        return 0;
    else
        return n % 10 + sumDigits(n / 10)
}
Corrected Code
#include <stdio.h>

int sumDigits(int n)
{
    if (n == 0) {
        return 0;
    }

    return n % 10 + sumDigits(n / 10);
}

int main(void)
{
    int num;

    printf("Enter number: ");
    scanf("%d", &num);
    printf("Sum of digits = %d\n", sumDigits(num));
    return 0;
}
Core Rooms

Room 1: Parameter Needs a Type

  • The function header must declare int n.
  • Untyped parameters are not valid for this lab style.
  • The corrected header is int sumDigits(int n).

Room 2: Base Case Uses Comparison, Not Assignment

  • n = 0 assigns zero.
  • The test must be n == 0.
  • This is the key logical repair.

Room 3: Recursive Formula Uses Last Digit Plus Smaller Problem

  • n % 10 extracts the last digit.
  • n / 10 removes that last digit.
  • The function keeps summing until zero remains.

Room 4: Missing Semicolon Still Matters

  • The return statement must end with ;.
  • Recursive logic can be right and still fail to compile.
  • Always check punctuation after fixing logic.

Room 5: Trace Example

  • sumDigits(123) becomes 3 + sumDigits(12).
  • Then 2 + sumDigits(1), then 1 + sumDigits(0).
  • The base case returns 0, so the total becomes 6.
