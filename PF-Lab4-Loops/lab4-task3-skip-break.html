Task 3

Print 1 to 50, Skip Multiples of 4, Stop After 40

This task is about loop control inside the body. One condition skips output for a value, and another condition ends the loop completely.

continue skips this turn, break ends all later turns.
Loop GuideOpen in Memory Builder
Quick Data
Main loop
for (i = 1; i <= 50; ++i)
Skip rule
i % 4 == 0
Stop rule
i > 40
Core skill
condition ordering
Actual Code
#include <stdio.h>

int main(void)
{
    int i;

    for (i = 1; i <= 50; ++i) {
        if (i > 40) {
            break;
        }
        if (i % 4 == 0) {
            continue;
        }
        printf("%d ", i);
    }

    return 0;
}
Core Rooms

Room 1: Why For Still Fits

  • The range 1 to 50 is known in advance.
  • The base repetition is still count-controlled.
  • The special behavior happens in the body.

Room 2: Break Means Full Stop

  • When the number becomes greater than 40, no later numbers should print.
  • That is not a skip; it is a final exit.
  • So use break.

Room 3: Continue Means Skip This One

  • Multiples of 4 should not print, but the loop should continue later.
  • That is exactly what continue does.
  • The next iteration still happens normally.

Room 4: Order Matters

  • Think about stop and skip rules before the print line.
  • The print statement should run only when no rule blocks it.
  • Bad ordering can print values that should not appear.

Room 5: Iteration Story

  • i = 8 triggers continue, so 8 is skipped.
  • i = 41 triggers break, so everything ends.
  • This task teaches local skip versus global stop.
