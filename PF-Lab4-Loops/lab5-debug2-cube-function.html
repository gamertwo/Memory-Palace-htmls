Lab 5 Debugging Task 2

Fix the Broken Cube Function Program

This debugging task tests whether you can spot mismatched return types, bad input syntax, and missing statement endings inside a function-based program.

$$\text{value-returning function} \Rightarrow \text{typed parameter} \Rightarrow \text{correct scanf} \Rightarrow \text{clean return}$$
Functions GuideOpen in Memory Builder
Broken Code Shape
void cube(num) {
    return num * num * num;
}

int main(void) {
    int n;
    printf("Enter number: ")
    scanf("%d", n);
    printf("Cube is: %d", cube(n));
    return 0
}
Corrected Code
#include <stdio.h>

int cube(int num)
{
    return num * num * num;
}

int main(void)
{
    int n;

    printf("Enter number: ");
    scanf("%d", &n);
    printf("Cube is: %d\n", cube(n));
    return 0;
}
Core Rooms

Room 1: void Cannot Return a Cube Value

  • The function computes a number and sends it back.
  • So the return type cannot be void.
  • It should be int cube(int num).

Room 2: Parameter Needs a Type

  • num must be declared as an integer parameter.
  • Untyped parameters break modern C code.
  • The corrected header fixes both issues together.

Room 3: scanf Needs Address of n

  • Input should be stored into n.
  • So use &n in scanf.
  • Without the address operator, the read is wrong.

Room 4: Missing Semicolons Matter

  • The broken code misses semicolons after printf and return 0.
  • Add them to complete the statements.
  • Debugging often starts with punctuation.

Room 5: Final Flow

  • Read number into n.
  • Call cube(n).
  • Print the returned cube value.
