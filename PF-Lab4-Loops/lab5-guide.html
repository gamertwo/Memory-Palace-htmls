How to Read and Write Functions

A function is easiest to memorize when you track the data path: input enters through parameters, work happens in the body, and a result returns to the caller.

$$\text{caller} \rightarrow \text{arguments} \rightarrow \text{function body} \rightarrow \text{return value or action}$$

Function Writing Checklist

1. Name the task

Choose a function name that says exactly what the code should do.

2. Choose return type

Return a value if the caller needs a result. Use void if it only performs work.

3. Define parameters

Pass in only the data the function truly needs.

4. Keep one job

One function should solve one clear subproblem.

5. Verify the call

Check argument types, order, commas, and assignment of the returned value.
