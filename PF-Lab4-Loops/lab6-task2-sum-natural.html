Lab 6 Task 2

Recursive Sum of First n Natural Numbers

This task turns a familiar arithmetic sum into a recursion pattern that keeps peeling off the largest number.

$$sum(n)=n+sum(n-1),\qquad sum(0)=0$$
Recursion GuideOpen in Memory Builder
Quick Data
Function
int sum(int n)
Base case
n == 0
Recursive case
n + sum(n - 1)
Idea
reduce by one until zero
Actual Code
#include <stdio.h>

int sum(int n)
{
    if (n == 0) {
        return 0;
    }

    return n + sum(n - 1);
}

int main(void)
{
    int n;

    printf("Enter n: ");
    scanf("%d", &n);

    printf("Sum = %d\n", sum(n));
    return 0;
}
Core Rooms

Room 1: Smallest Solvable Input

  • The sum of the first 0 natural numbers is 0.
  • That is the cleanest stopping point.
  • So the base case returns 0.

Room 2: Peel Off the Largest Term

  • To find the sum up to n, keep n and delegate the rest.
  • The smaller problem is the sum up to n - 1.
  • This creates the recursive case.

Room 3: Return Expression Structure

  • The recursive statement is not just a call.
  • It must add the current value to the returned smaller sum.
  • That gives n + sum(n - 1).

Room 4: Trace Example

  • sum(3) becomes 3 + sum(2).
  • Then 2 + sum(1), then 1 + sum(0).
  • The base case returns 0 and the stack rebuilds 1, 3, 6.

Room 5: Memory Sentence

  • Stop at zero.
  • Add current n.
  • Ask the smaller version for the rest.
