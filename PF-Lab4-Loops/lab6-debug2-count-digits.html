Lab 6 Debugging Task 2

Fix the Broken Recursive Count Digits Program

This problem tests whether you really understand how a digit-count recursion should shrink. The bugged version shrinks the number the wrong way and also breaks several core C rules.

$$\text{if } n<10 \text{ return } 1,\qquad \text{else return } 1 + countDigits(n/10)$$
Recursion GuideOpen in Memory Builder
Broken Code Shape
int countDigits(n)
{
    if(n == 1)
        return 1;
    else
        return 1 + countDigits(n - 10);
}

int main()
{
    int num;
    printf("Enter a number: ")
    scanf("%d", num);
    digits = countDigits();
    printf("Total digits are: %d", digits)
}
Corrected Code
#include <stdio.h>

int countDigits(int n)
{
    if (n < 10) {
        return 1;
    }

    return 1 + countDigits(n / 10);
}

int main(void)
{
    int num;
    int digits;

    printf("Enter a number: ");
    scanf("%d", &num);
    digits = countDigits(num);
    printf("Total digits are: %d\n", digits);
    return 0;
}
Core Rooms

Room 1: Parameter Type Must Be Declared

  • The function needs int n in the parameter list.
  • This is the first syntax repair.
  • The corrected header becomes int countDigits(int n).

Room 2: Base Case Should Catch Any Single Digit

  • The broken code stops only at exactly 1.
  • But 0 through 9 are all single-digit numbers.
  • So the better base case is n < 10.

Room 3: Shrink by Division, Not Subtraction

  • Digit count is reduced by removing one decimal place.
  • That means n / 10, not n - 10.
  • This is the main logical fix.

Room 4: main Must Pass the Number In

  • countDigits() without arguments is wrong.
  • The function needs the number, so call countDigits(num).
  • Also declare the variable digits before using it.

Room 5: Input and Output Repairs

  • Use &num in scanf.
  • Add the missing semicolons after printf and the final print.
  • The fixed program now reads input, counts digits correctly, and prints the answer.
