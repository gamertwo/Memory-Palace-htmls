Menu-Driven Calculator with Functions

The menu chooses the operation, but each operation still lives in its own function so the program stays organized.

$$\text{menu choice} \Rightarrow \text{call matching operation function}$$

Actual Code
#include <stdio.h>

float add(float a, float b) { return a + b; }
float subtract(float a, float b) { return a - b; }
float multiply(float a, float b) { return a * b; }
float divide(float a, float b) { return a / b; }

int main(void)
{
    int choice;
    float x, y;

    printf("1. Addition\n2. Subtraction\n3. Multiplication\n4. Division\n");
    printf("Enter your choice: ");
    scanf("%d", &choice);

    printf("Enter two numbers: ");
    scanf("%f %f", &x, &y);

    switch (choice) {
        case 1:
            printf("Result = %.2f\n", add(x, y));
            break;
        case 2:
            printf("Result = %.2f\n", subtract(x, y));
            break;
        case 3:
            printf("Result = %.2f\n", multiply(x, y));
            break;
        case 4:
            if (y == 0) {
                printf("Division by zero is not allowed.\n");
            } else {
                printf("Result = %.2f\n", divide(x, y));
            }
            break;
        default:
            printf("Invalid choice.\n");
    }

    return 0;
}
Core Rooms

Room 1: Menu Stays in main

  • The user chooses the operation in main.
  • That makes main the control center.
  • It decides which function should run.

Room 2: One Function Per Operation

  • Addition, subtraction, multiplication, and division each get separate functions.
  • This keeps every operation small and readable.
  • It also makes debugging easier.

Room 3: switch Matches Choice to Function

  • After reading the menu choice, use switch.
  • Each case calls the matching function.
  • The result is printed immediately.

Room 4: Division Needs a Guard

  • Division by zero must be blocked before calling the function.
  • This check belongs in the division case.
  • It prevents invalid arithmetic.

Room 5: Modular Calculator Memory

  • Menu chooses.
  • Function computes.
  • printf reports the answer.
