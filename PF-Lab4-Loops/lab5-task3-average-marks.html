Lab 5 Task 3

Input Marks and Find Average Using Two Functions

This task trains modular division of work: one function gathers marks and another computes the average.

$$\text{average}=\frac{\text{sum of marks}}{\text{number of students}}$$

Actual Code
#include <stdio.h>

void inputMarks(int marks[], int n)
{
    int i;

    for (i = 0; i < n; i++) {
        printf("Enter marks of student %d: ", i + 1);
        scanf("%d", &marks[i]);
    }
}

float averageMarks(int marks[], int n)
{
    int i;
    int sum = 0;

    for (i = 0; i < n; i++) {
        sum += marks[i];
    }

    return (float) sum / n;
}

int main(void)
{
    int n;
    int marks[100];

    printf("Enter number of students: ");
    scanf("%d", &n);

    inputMarks(marks, n);
    printf("Average marks = %.2f\n", averageMarks(marks, n));
    return 0;
}
Core Rooms

Room 1: Two Jobs, Two Functions

  • Reading marks is one job.
  • Calculating the average is another job.
  • So the lab explicitly asks for two separate functions.

Room 2: inputMarks Fills the Array

  • This function takes the array and number of students.
  • It loops through each index and stores input.
  • It does not need to return a value, so void is enough.

Room 3: averageMarks Returns a Float

  • The average may contain decimals.
  • So this function should return float.
  • It sums the array and divides by n.

Room 4: main Coordinates the Workflow

  • main asks for the student count first.
  • Then it calls inputMarks.
  • Finally it calls averageMarks and prints the result.

Room 5: Data Passing Memory

  • The same marks array is passed to both functions.
  • One function fills it and the other reads it.
  • This is a strong modular-programming pattern to remember.
