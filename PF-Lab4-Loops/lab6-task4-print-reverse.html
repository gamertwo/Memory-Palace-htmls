Lab 6 Task 4

Print Digits of a Number in Reverse Order

This recursion problem is about processing the last digit first, then removing that digit and repeating on the shorter number.

$$\text{print } n \bmod 10,\qquad \text{then recurse on } \left\lfloor \frac{n}{10} \right\rfloor$$

Quick Data
Function
void printReverse(int n)

Actual Code
#include <stdio.h>

void printReverse(int n)
{
    if (n < 10) {
        printf("%d", n);
        return;
    }

    printf("%d", n % 10);
    printReverse(n / 10);
}

int main(void)
{
    int num;

    printf("Enter a number: ");
    scanf("%d", &num);

    printf("Reverse order: ");
    printReverse(num);
    printf("\n");
    return 0;
}
Core Rooms

Room 1: This Function Prints, Not Returns

  • The question asks to print digits in reverse order.
  • So the function can be void.
  • Its job is output, not value return.

Room 2: Single Digit Is the Base Case

  • If the number has only one digit left, just print it.
  • No more recursion is needed after that.
  • This stops the process cleanly.

Room 3: Last Digit Comes First

  • The reverse order starts from n % 10.
  • That extracts the current last digit.
  • Print it before the recursive call.

Room 4: Remove the Printed Digit

  • After printing the last digit, shrink the number with n / 10.
  • This removes the digit already handled.
  • Then recurse on the shorter number.

Room 5: Order Memory

  • Extract last digit.
  • Print it immediately.
  • Recurse on the remaining front part.
