Loop Choice + Iteration Method

Why, How, and Which Loop Syntax

The fastest way to solve these lab tasks is to classify the repetition first. If you know whether the loop is count-controlled, sentinel-controlled, or nested pattern logic, the code almost writes itself.

$$\text{Known count} \Rightarrow \texttt{for},\qquad \text{unknown count} \Rightarrow \texttt{while},\qquad \text{must run once} \Rightarrow \texttt{do-while}$$

Iteration Checklist

1. Setup

Initialize counters, totals, products, or the first input before the loop begins.

2. Test

State clearly what keeps the loop alive and what makes it stop.

3. Body

Do the real work: print, multiply, add, compare, or update.

4. Update

Move the state forward with i++, new input, or changed control variables.

5. Verify

Trace the first iteration, a middle one, and the stop condition.

Why Students Lose Marks

Do

  • Put the update inside the correct place for while and do-while loops.
  • Check break and continue conditions in the order the question needs.
  • Use nested loops only when one repetition lives inside another.
  • Keep sentinel values out of totals and counts when the question says so.

Do Not

  • Do not put a semicolon right after while (...) unless you truly want an empty loop.
  • Do not forget braces when the logic spans more than one statement.
  • Do not update the wrong variable or forget the update entirely.
  • Do not divide by count if no valid inputs were entered.
