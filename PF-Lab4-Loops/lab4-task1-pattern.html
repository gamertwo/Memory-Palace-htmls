Task 1

Pattern 1, 12, 123, 1234, 12345

This is a nested-loop pattern problem. The outer loop decides the row number, and the inner loop prints from 1 up to that row.

$$\text{row } i \Rightarrow \text{ print } 1 \text{ through } i$$

Actual Code
#include <stdio.h>

int main(void)
{
    int i, j;

    for (i = 1; i <= 5; i++) {
        for (j = 1; j <= i; j++) {
            printf("%d", j);
        }
        printf("\n");
    }

    return 0;
}
Core Rooms

Room 1: Why Nested Loops

  • You have repeated rows, and each row has repeated printing inside it.
  • That means one loop for rows and one loop for entries inside a row.
  • A single loop cannot describe both dimensions cleanly.

Room 2: Outer Loop Controls Rows

  • Let i move from 1 to 5.
  • Each value of i means build one row.
  • So row 4 must end at digit 4.

Room 3: Inner Loop Prints 1 Through i

  • Let j move from 1 to i.
  • Print j each inner iteration.
  • The pattern grows because the upper limit changes with the row.

Room 4: Newline Placement

  • Print the newline only after the inner loop finishes.
  • If newline is inside the inner loop, the pattern breaks into vertical output.
  • The row must complete before moving down.

Room 5: Iteration Story

  • i = 1 prints 1.
  • i = 3 prints 123.
  • i = 5 prints 12345.
