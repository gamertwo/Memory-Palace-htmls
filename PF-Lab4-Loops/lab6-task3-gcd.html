Lab 6 Task 3

Find GCD with a Recursive Function

This task uses the Euclidean method: replace the bigger pair with a smaller equivalent pair until the second value becomes zero.

$$gcd(a,b)=gcd(b,a\bmod b),\qquad gcd(a,0)=a$$
Recursion GuideOpen in Memory Builder
Quick Data
Function
int gcd(int a, int b)
Base case
b == 0
Recursive case
gcd(b, a % b)
Shrink step
remainder is smaller than divisor
Actual Code
#include <stdio.h>

int gcd(int a, int b)
{
    if (b == 0) {
        return a;
    }

    return gcd(b, a % b);
}

int main(void)
{
    int x, y;

    printf("Enter two numbers: ");
    scanf("%d %d", &x, &y);

    printf("GCD = %d\n", gcd(x, y));
    return 0;
}
Core Rooms

Room 1: Stop When the Second Number Is Zero

  • If the second input becomes 0, the first input is the GCD.
  • This is the Euclidean stopping condition.
  • So return a when b == 0.

Room 2: Replace the Pair Smartly

  • The next pair is not random.
  • It becomes (b, a % b).
  • This keeps the same GCD while shrinking the problem.

Room 3: Remainder Drives Termination

  • The remainder is always smaller than the divisor.
  • That means the recursion moves toward zero.
  • So the calls cannot continue forever if written correctly.

Room 4: Trace Example

  • gcd(48, 18) becomes gcd(18, 12).
  • Then gcd(12, 6), then gcd(6, 0).
  • The final answer is 6.

Room 5: Memory Sentence

  • Move second to first.
  • Move remainder to second.
  • Stop when second is zero.
