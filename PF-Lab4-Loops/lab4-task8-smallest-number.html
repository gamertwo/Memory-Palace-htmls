Task 8

Find the Smallest of Several Integers

This task mixes count-controlled input with decision logic. The first value tells you how many numbers remain, and each later input must be compared against the current smallest value.

$$\text{smallest} \leftarrow \min(\text{current smallest},\text{new input})$$

Actual Code
#include <stdio.h>

int main(void)
{
    int count, num, smallest, i = 1;

    printf("How many numbers? ");
    scanf("%d", &count);

    if (count > 0) {
        printf("Enter number 1: ");
        scanf("%d", &smallest);

        while (i < count) {
            printf("Enter number %d: ", i + 1);
            scanf("%d", &num);

            if (num < smallest) {
                smallest = num;
            }
            i++;
        }

        printf("Smallest = %d\n", smallest);
    }

    return 0;
}
Core Rooms

Room 1: First Input Is Special

  • The first value is not part of the comparison set.
  • It tells you how many actual numbers are still coming.
  • This separates control information from data.

Room 2: Initialize Smallest Correctly

  • After reading the count, read the first actual number and store it as smallest.
  • This gives the comparison logic a real starting point.
  • Then process the remaining values in the loop.

Room 3: Compare Every New Number

  • Each loop cycle reads one value.
  • If the new value is smaller, replace smallest.
  • Otherwise keep the old smallest.

Room 4: Control the Remaining Count

  • The while loop should run until all remaining values are processed.
  • That means the loop-control counter must change each iteration.
  • No update means an infinite loop or repeated reads without progress.

Room 5: Iteration Story

  • Read the total count.
  • Use the first real number as the starting smallest.
  • Then compare every later number against it until none remain.
