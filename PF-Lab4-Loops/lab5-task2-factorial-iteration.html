Factorial Function Using Iteration

This function still returns one value, but the work inside the function is iterative instead of formula-based.

$$n! = 1 \times 2 \times 3 \times \dots \times n$$

Actual Code
#include <stdio.h>

int factorial(int n)
{
    int i;
    int result = 1;

    for (i = 1; i <= n; i++) {
        result *= i;
    }

    return result;
}

int main(void)
{
    int num;

    printf("Enter a positive integer: ");
    scanf("%d", &num);

    printf("Factorial = %d\n", factorial(num));
    return 0;
}
Core Rooms

Room 1: Function Header Says Job Clearly

  • The input is an integer n.
  • The output is also an integer for normal small lab values.
  • That creates the header int factorial(int n).

Room 2: Product Starts at 1

  • Factorial is multiplication, not addition.
  • So the running result must start from 1.
  • Starting from 0 would destroy every product.

Room 3: Loop Lives Inside the Function

  • The loop multiplies all integers from 1 to n.
  • Each iteration updates the running product.
  • Only the final product is returned.

Room 4: main Only Handles Input and Output

  • main should not contain the factorial logic itself.
  • It reads the number, calls the function, and prints the answer.
  • This keeps the design modular.

Room 5: Reuse Memory

  • Any time another problem needs factorial, call this same function.
  • The algorithm is stored once in one place.
  • That is the whole point of modular programming.
