Lab 6 Task 1

Recursive Power Function

Power is one of the cleanest recursion problems because the exponent shrinks by exactly one each call.

$$base^{exp}=base \times base^{exp-1},\qquad base^0 = 1$$

Actual Code
#include <stdio.h>

int power(int base, int exp)
{
    if (exp == 0) {
        return 1;
    }

    return base * power(base, exp - 1);
}

int main(void)
{
    int base, exp;

    printf("Enter base and exponent: ");
    scanf("%d %d", &base, &exp);

    printf("Result = %d\n", power(base, exp));
    return 0;
}
Core Rooms

Room 1: Find the Stop First

  • Any number to the power 0 equals 1.
  • That gives the base case immediately.
  • If exp == 0, return 1.

Room 2: Shrink Only the Exponent

  • The base stays the same in every call.
  • The exponent moves from exp to exp - 1.
  • This drives the problem toward zero.

Room 3: Multiply on the Way Back

  • Each waiting call contributes one extra factor of base.
  • So the return expression is base * power(base, exp - 1).
  • The multiplication happens as calls return.

Room 4: main Only Supplies Input

  • main reads base and exponent.
  • It sends both values into the function.
  • The recursive work stays hidden inside power.

Room 5: Call Stack Story

  • power(2, 3) waits for power(2, 2).
  • Then that waits for power(2, 1), then power(2, 0).
  • The base case returns 1, and the stack rebuilds 2, 4, 8.
