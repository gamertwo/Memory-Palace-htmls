Lab 5 Task 1

Function to Calculate Area of a Circle

This is the cleanest possible function problem: one float goes in, one float comes back out.

$$\text{areaCircle}(r)=\pi r^2$$
Functions GuideOpen in Memory Builder
Quick Data
Function type
returns float
Input
radius r
Output
area of circle
Caller
main reads radius and prints result
Actual Code
#include <stdio.h>

float areaCircle(float r)
{
    const float pi = 3.14159f;
    return pi * r * r;
}

int main(void)
{
    float radius;

    printf("Enter radius: ");
    scanf("%f", &radius);

    printf("Area = %.2f\n", areaCircle(radius));
    return 0;
}
Core Rooms

Room 1: Return Type Comes First

  • The answer can contain decimals, so float fits the job.
  • The function is not just printing, it is returning a computed value.
  • That is why the heading starts with float areaCircle.

Room 2: Radius Is the Parameter

  • The function only needs one input: the radius.
  • Put it inside parentheses as float r.
  • This keeps the function reusable for any radius value.

Room 3: Formula Lives Inside the Function

  • Use the area formula inside the body.
  • Return pi * r * r.
  • The caller does not need to know the internal calculation steps.

Room 4: main Reads Then Calls

  • main handles user interaction.
  • It reads radius with scanf and passes the value to the function.
  • The returned area is printed with formatting.

Room 5: Value Flow Story

  • User enters radius.
  • The value moves into areaCircle(radius).
  • The function returns the area back to printf.
