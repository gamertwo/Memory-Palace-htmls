Task 4

Nested Multiplication Table

This task uses nested loops again, but now each inner iteration prints a formatted multiplication sentence instead of a single character or digit.

$$\text{outer loop} \Rightarrow \text{table number},\qquad \text{inner loop} \Rightarrow \text{multiplier}$$

Actual Code
#include <stdio.h>

int main(void)
{
    int i, j;

    for (i = 1; i <= 5; i++) {
        for (j = 1; j <= 5; j++) {
            printf("%d x %d = %d\n", i, j, i * j);
        }
        printf("\n");
    }

    return 0;
}
Core Rooms

Room 1: Why Nested Loops Again

  • Each table contains many multiplication lines.
  • The outer loop chooses the main number and the inner loop walks through the multipliers.
  • This is still row-and-column thinking.

Room 2: Outer Loop Chooses the Table

  • If the outer value is 2, the whole inner loop builds the 2-times block.
  • When the outer value changes, a new table block begins.
  • This creates structure in the output.

Room 3: Inner Loop Computes the Product

  • The inner loop changes the multiplier each time.
  • The product is outer value times inner value.
  • The print line uses both loop variables and the product.

Room 4: Formatting Is Part of the Logic

  • The output is a formatted statement, not just a number.
  • You must print both operands and the result in order.
  • A blank line after each outer cycle can improve readability.

Room 5: Iteration Story

  • Outer 1 and inner 3 prints 1 x 3 = 3.
  • Outer 2 and inner 5 prints 2 x 5 = 10.
  • The algorithm repeats the same sentence shape with new values.
