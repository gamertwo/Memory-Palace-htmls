Lab Route
Guide

Loop Syntax and Iteration Logic

Lock the why, how, and which syntax first: for, while, do-while, nested loops, break, continue, and sentinel flow.
Task 1

Pattern 1, 12, 123...

Nested for-loops where the outer loop controls rows and the inner loop prints increasing digits per row.
Task 2

Factorial of a Positive Integer

Counter-controlled repetition using a running product that multiplies from 1 to n.
Task 3

Skip Multiples of 4, Stop After 40

One for-loop that combines continue and break in the correct order so the output logic stays clean.
Task 4

Nested Multiplication Table

Print structured rows with nested loops and formatted multiplication statements.
Task 5

While Loop Value Table

Use a while loop and tab spacing to print N, 10N, 100N, and 1000N in aligned columns.
Task 6

Do-While Sentinel Average

Read integers until 9999, track sum and count, then compute an average only if valid data exists.
Task 7

Fix Syntax and Logical Errors

Debug a broken while-loop by repairing the semicolon bug, printf syntax, increment logic, and return statement.
Task 8

Smallest of Several Integers

Use count-controlled input with a while loop and if-else updates to track the current smallest value.
How To Use This Folder

1. Read the guide

Decide which loop family fits the task before you memorize code.

2. Walk the task page

Use the rooms to memorize the algorithm in writing order: setup, condition, body, update, stop.

3. Send rooms to builder

Import the page into the memory builder and lay out your own palace blocks.

4. Rehearse iterations

Dry-run each loop with small values so off-by-one and sentinel mistakes become visible.
