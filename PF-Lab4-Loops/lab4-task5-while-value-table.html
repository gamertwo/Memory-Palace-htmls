Task 5

While Loop Table of N, 10N, 100N, 1000N

This task uses a while loop to print a structured value table. The main logic is: start at 1, keep going to 10, and print one complete row per iteration.

$$N,\;10N,\;100N,\;1000N$$

n = 1

Actual Code
#include <stdio.h>

int main(void)
{
    int n = 1;

    printf("N\t10*N\t100*N\t1000*N\n");
    while (n <= 10) {
        printf("%d\t%d\t%d\t%d\n", n, 10 * n, 100 * n, 1000 * n);
        n++;
    }

    return 0;
}
Core Rooms

Room 1: Why While Is Acceptable Here

  • The task explicitly asks for a while loop.
  • You can still solve a known-count problem with while if you manage the control variable yourself.
  • That is the main syntax lesson here.

Room 2: One Row Per Iteration

  • Each loop cycle should print one full row of four values.
  • Compute or print n, 10*n, 100*n, and 1000*n.
  • Then move to the next row by incrementing n.

Room 3: Tab Spacing Matters

  • The question specifically asks for \t.
  • Tabs help keep the four columns visually separated.
  • The print format is part of the required answer, not decoration.

Room 4: Update Must Be Inside the Loop

  • After printing the row, increment n.
  • If the update is missing, the loop becomes infinite.
  • This task is a good place to practice body-then-update discipline.

Room 5: Iteration Story

  • When n = 3, the row is 3, 30, 300, 3000.
  • When n = 10, the row is 10, 100, 1000, 10000.
  • After incrementing past 10, the loop stops.
