Task 6

Do-While Average with Sentinel 9999

This task is about sentinel-controlled repetition. You keep accepting numbers until 9999 appears, but that sentinel must not be counted in the sum or the average.

$$\text{average}=\frac{\text{sum of valid inputs}}{\text{count of valid inputs}}$$

Actual Code
#include <stdio.h>

int main(void)
{
    int num;
    int sum = 0;
    int count = 0;

    do {
        printf("Enter a number (9999 to stop): ");
        scanf("%d", &num);

        if (num != 9999) {
            sum += num;
            count++;
        }
    } while (num != 9999);

    if (count != 0) {
        printf("Average = %.2f\n", (float)sum / count);
    } else {
        printf("No numbers were entered.\n");
    }

    return 0;
}
Core Rooms

Room 1: Why Do-While Fits

  • The program must read at least one value before it can decide whether to continue.
  • That matches the post-test nature of do-while.
  • Body first, condition after.

Room 2: Sentinel Value Is Not Data

  • The number 9999 means stop, not average me.
  • So check for the sentinel before adding to sum or count.
  • This is the central logic trap in the task.

Room 3: Track Sum and Count Together

  • Every valid input changes both the sum and the count.
  • At the end, average needs both values.
  • If one update is missing, the final answer becomes wrong.

Room 4: Handle No Valid Inputs

  • If the first number is 9999, count stays zero.
  • You must print a message instead of dividing by zero.
  • This is why the post-loop if-check matters.

Room 5: Iteration Story

  • Read a number.
  • If it is not 9999, add it, count it, and read again.
  • If it is 9999, stop and compute only if count is nonzero.
