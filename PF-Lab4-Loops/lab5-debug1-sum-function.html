Lab 5 Debugging Task 1

Fix the Broken Sum Function Program

The lab gives a short function program with multiple syntax mistakes. This page helps you remember the repair order instead of guessing randomly.

$$\text{fix types} \rightarrow \text{fix call syntax} \rightarrow \text{declare result} \rightarrow \text{print output}$$
Functions GuideOpen in Memory Builder
Broken Code Shape
int sum(a, b) {
    return a + b
}

int main() {
    int num1 = 5, num2 = 10;
    result = sum(num1 num2);
    printf("Sum = %d", result);
}
Corrected Code
#include <stdio.h>

int sum(int a, int b)
{
    return a + b;
}

int main(void)
{
    int num1 = 5, num2 = 10;
    int result;

    result = sum(num1, num2);
    printf("Sum = %d\n", result);
    return 0;
}
Core Rooms

Room 1: Parameters Need Types

  • In modern C, the function parameters must have declared types.
  • So sum(a, b) becomes sum(int a, int b).
  • This is the first syntax repair.

Room 2: return Needs a Semicolon

  • The statement return a + b is incomplete without ;.
  • A missing semicolon is a classic lab bug.
  • Repair it before moving on.

Room 3: result Must Be Declared

  • The variable result is used before declaration.
  • Add int result; inside main.
  • Undeclared variables always break compilation.

Room 4: Function Call Needs a Comma

  • The call sum(num1 num2) is missing a comma.
  • Correct it to sum(num1, num2).
  • Each argument must be separated clearly.

Room 5: main Should Finish Properly

  • Use int main(void) and return 0.
  • This makes the program complete and standard.
  • The fixed version now compiles and prints the sum.
