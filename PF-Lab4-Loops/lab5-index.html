Programming Fundamentals Lab 5

Introduction to Functions

Lab 5 moves from loops into modular programming. The goal is to memorize how functions are declared, called, and connected so each task becomes a sequence of reusable parts instead of one long main function.

$$\text{return type} + \text{function name} + \text{parameters} + \text{body} \Rightarrow \text{clean reusable code}$$
