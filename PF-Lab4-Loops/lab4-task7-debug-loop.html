Task 7

Fix All Syntax and Logical Errors

This debugging task teaches you to read loops critically. The sample code has both syntax problems and logic problems, so the goal is not just to compile but to restore the intended behavior.

while (count <= 10) should control the body, not become an empty loop.

Corrected Code
#include <stdio.h>

int main(void)
{
    unsigned int count = 1;

    while (count <= 10) {
        printf("%s\n", count % 2 ? "****" : "++++++++");
        ++count;
    }

    return 0;
}
Core Rooms

Room 1: Empty Loop Bug

  • A semicolon right after while (...) creates an empty loop.
  • The block after it is no longer controlled the way you think.
  • This is one of the most common loop mistakes in C.

Room 2: Print Strings Need Quotes

  • The stars and plus signs are string literals, so they need double quotes.
  • Without quotes, the code is invalid syntax.
  • Printing depends on proper string formatting.

Room 3: Update Must Actually Change Count

  • count + 1; only computes a value and throws it away.
  • You need count = count + 1; or ++count;.
  • Without a real update, the loop can become infinite.

Room 4: Return Statement Syntax

  • C statements end with semicolons.
  • return 0; is correct, while return 0 is incomplete.
  • Even simple syntax details matter in debugging tasks.

Room 5: Logic After Repair

  • The loop should print 10 lines.
  • Odd counts print one symbol pattern, even counts print another.
  • Once control, print, update, and return are repaired, the code works as intended.
