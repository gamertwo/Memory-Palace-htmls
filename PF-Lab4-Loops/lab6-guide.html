How to Build a Recursive Function

Every recursive solution should answer two questions immediately: when do I stop, and how does the next call make the problem smaller?

$$\text{if stop condition} \Rightarrow \text{return base value},\qquad \text{else} \Rightarrow \text{solve smaller version}$$
