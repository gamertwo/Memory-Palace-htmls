Factorial of a Positive Integer

Factorial is a running-product loop. Start at 1, then multiply by every integer from 1 to n.

$$n! = 1 \times 2 \times 3 \times \cdots \times n$$
Loop GuideOpen in Memory Builder
Quick Data
Loop type
for
Accumulator
running product
Start value
factorial = 1
Update
factorial *= i
Actual Code
#include <stdio.h>

int main(void)
{
    int n, i;
    int factorial = 1;

    printf("Enter a positive integer: ");
    scanf("%d", &n);

    for (i = 1; i <= n; i++) {
        factorial *= i;
    }

    printf("Factorial = %d\n", factorial);
    return 0;
}
Core Rooms

Room 1: Why For Fits

  • You know the repetition count from the input n.
  • The loop goes from 1 to n in fixed steps.
  • That makes this a count-controlled loop.

Room 2: Product Starts at 1

  • A product starts at 1, not 0.
  • If you start at 0, every later multiplication stays 0.
  • This is the key logic point in factorial code.

Room 3: Multiply, Do Not Add

  • Use factorial *= i.
  • Each iteration folds one new factor into the answer.
  • The loop body is small, but its meaning is important.

Room 4: Dry Run a Small Case

  • If n = 4, the product sequence is 1, 2, 6, 24.
  • That trace shows the update is correct.
  • Small traces catch logic mistakes fast.

Room 5: Stop at i = n

  • The last needed factor is n.
  • The answer is complete only after multiplying by it.
  • Then print after the loop ends.
