Pattern Palace Hub Design 7-12

Design Exercise 7-14

This is a design problem for a first-order RL circuit. Instead of solving from a circuit, you reverse-engineer a valid circuit that produces the target inductor current.

$$i_L(t)=5-5e^{-500t}\text{ mA},\quad t\ge 0$$
Rooms

Room 1: Recognize the Design Target

  • The waveform already has the standard first-order RL charging form.
  • So the goal is to choose a source, resistor, and inductor that realize that exact current response.

Room 2: Read the Final Current

  • As $t\to\infty$, the exponential vanishes.
  • So $$i_L(\infty)=5\text{ mA}.$$

Room 3: Read the Initial Current

  • At $t=0$, $e^0=1$.
  • So $$i_L(0)=5-5=0\text{ mA}.$$
  • This is a zero-state inductor current.

Room 4: Extract the Time Constant

  • Match $e^{-t/\tau}$ with $e^{-500t}$.
  • That gives $$\frac{1}{\tau}=500 \quad \Rightarrow \quad \tau=\frac{1}{500}=2\text{ ms}.$$
  • For an RL circuit, $$\tau=\frac{L}{R}.$$

Room 5: Choose Standard Parts

  • Pick a standard resistor, for example $$R=1\Omega.$$
  • Then solve for the inductor:
  • $$L=\tau R=(2\text{ ms})(1\Omega)=2\text{ mH}.$$
  • That is already a clean standard inductor value.

Room 6: Infer the Source

  • The final current is $$5\text{ mA}.$$
  • With $$R=1\Omega,$$ the needed steady-state forcing is
  • $$I_{\text{source}}=5\text{ mA}.$$
  • So one valid design is a current source $$i_s(t)=5u(t)\text{ mA}$$ driving a parallel RL network.

Room 7: Rebuild the Governing ODE

  • The first-order RL form is
  • $$\tau\frac{di_L}{dt}+i_L=i_L(\infty)u(t).$$
  • Using $$\tau=0.002 \quad \text{and} \quad i_L(\infty)=5,$$
  • the target equation is $$0.002\frac{di_L}{dt}+i_L=5u(t),$$
  • with current measured in mA.

Room 8: Quick Verification

  • Differentiate the desired response:
  • $$\frac{di_L}{dt}=2500e^{-500t}\text{ mA/s}.$$
  • Substitute into the left side:
  • $$0.002(2500e^{-500t})+\left(5-5e^{-500t}\right)=5e^{-500t}+5-5e^{-500t}=5.$$
  • So the target waveform matches the governing first-order RL equation.
Memory Clues

Clue 1

RL design problems run backward: read the current waveform first, then choose the hardware that matches it.

Clue 2

The outside constant is the final current. The full expression at t=0 gives the initial current.

Clue 3

The exponent coefficient gives tau immediately by inversion.

Clue 4

Once you know tau = L/R, choosing one standard part lets you solve for the other.
