Exercise 7-21

Find the forced component solution of $$10^{-3}\frac{dv(t)}{dt}+v(t)=10\cos(\omega t)\ \text{V}$$ for $$\omega=500,\ 1000,\ 2000\ \text{rad/s}.$$ Use a cosine-plus-sine trial, match coefficients, then convert each result to amplitude-phase form.

$$v_F(t)=\frac{10}{1+\left(10^{-3}\omega\right)^2}\cos(\omega t)+\frac{10\left(10^{-3}\omega\right)}{1+\left(10^{-3}\omega\right)^2}\sin(\omega t)\ \text{V}$$ $$=\frac{10}{\sqrt{1+\left(10^{-3}\omega\right)^2}}\cos\!\left(\omega t-\tan^{-1}(10^{-3}\omega)\right)\ \text{V}$$
Quick Data
Differential Equation
$$10^{-3}\frac{dv}{dt}+v=10\cos(\omega t)$$
Trial Form
$$v_F(t)=A\cos(\omega t)+B\sin(\omega t)$$
Cos Coefficient
$$A+10^{-3}\omega B=10$$
Sin Coefficient
$$B-10^{-3}\omega A=0$$
General Coefficients
$$A=\frac{10}{1+(10^{-3}\omega)^2},\quad B=\frac{10(10^{-3}\omega)}{1+(10^{-3}\omega)^2}$$
Main Trend
Higher $$\omega$$ gives smaller amplitude and larger phase lag.

Rooms

Room 1: Pick the Right Forced Template

  • The input is sinusoidal, so the forced response must also be sinusoidal at the same frequency.
  • Because differentiation can swap cosine into sine, guess both terms at once:
  • $$v_F(t)=A\cos(\omega t)+B\sin(\omega t).$$

Room 2: Differentiate and Substitute

  • Differentiate the trial function:
  • $$\frac{dv_F}{dt}=-A\omega\sin(\omega t)+B\omega\cos(\omega t).$$
  • Substitute into the equation:
  • $$10^{-3}\!\left[-A\omega\sin(\omega t)+B\omega\cos(\omega t)\right]+A\cos(\omega t)+B\sin(\omega t)=10\cos(\omega t).$$

Room 3: Match Cosine and Sine Coefficients

  • Collect cosine terms and sine terms separately.
  • From cosine:
  • $$A+10^{-3}\omega B=10.$$
  • From sine:
  • $$B-10^{-3}\omega A=0.$$

Room 4: Solve the General System First

  • Let $$\alpha=10^{-3}\omega.$$ Then the equations become
  • $$A+\alpha B=10,\qquad B=\alpha A.$$
  • Substitute $$B=\alpha A$$ into the first equation:
  • $$A+\alpha^2A=10 \quad \Rightarrow \quad A=\frac{10}{1+\alpha^2}.$$
  • Then
  • $$B=\alpha A=\frac{10\alpha}{1+\alpha^2}.$$

Room 5: Case (a), $$\omega=500$$ rad/s

  • Here $$\alpha=10^{-3}(500)=0.5.$$
  • So
  • $$A=\frac{10}{1+0.5^2}=8,\qquad B=\frac{10(0.5)}{1+0.5^2}=4.$$
  • Therefore
  • $$\boxed{v_F(t)=8\cos(500t)+4\sin(500t)\ \text{V}}.$$
  • Amplitude-phase form:
  • $$v_F(t)=8.94\cos(500t-26.6^\circ)\ \text{V}.$$

Room 6: Case (b), $$\omega=1000$$ rad/s

  • Now $$\alpha=10^{-3}(1000)=1.$$
  • So
  • $$A=\frac{10}{1+1^2}=5,\qquad B=\frac{10(1)}{1+1^2}=5.$$
  • Therefore
  • $$\boxed{v_F(t)=5\cos(1000t)+5\sin(1000t)\ \text{V}}.$$
  • Amplitude-phase form:
  • $$v_F(t)=7.07\cos(1000t-45^\circ)\ \text{V}.$$

Room 7: Case (c), $$\omega=2000$$ rad/s

  • Now $$\alpha=10^{-3}(2000)=2.$$
  • So
  • $$A=\frac{10}{1+2^2}=2,\qquad B=\frac{10(2)}{1+2^2}=4.$$
  • Therefore
  • $$\boxed{v_F(t)=2\cos(2000t)+4\sin(2000t)\ \text{V}}.$$
  • Amplitude-phase form:
  • $$v_F(t)=4.47\cos(2000t-63.4^\circ)\ \text{V}.$$

Room 8: Read the Filter Behavior

  • The amplitude is $$\dfrac{10}{\sqrt{1+(10^{-3}\omega)^2}}.$$
  • As $$\omega$$ rises from 500 to 2000 rad/s, the denominator grows, so the output amplitude falls.
  • The phase shift is $$-\tan^{-1}(10^{-3}\omega),$$ so higher frequency produces more lag.
  • This is the standard first-order low-pass pattern.

Amplitude-Phase Shortcut

If $$v_F(t)=A\cos(\omega t)+B\sin(\omega t),$$ then write it as $$M\cos(\omega t-\phi),$$ where $$M=\sqrt{A^2+B^2}$$ and $$\phi=\tan^{-1}\!\left(\frac{B}{A}\right).$$ That is why the phase lag grows from $$26.6^\circ$$ to $$63.4^\circ$$ as frequency increases.

Key Shortcut

General Forced Response

For $$\tau \dfrac{dv}{dt}+v=V_m\cos(\omega t),$$ the forced component can be read directly as $$v_F(t)=\dfrac{V_m}{1+(\tau\omega)^2}\cos(\omega t)+\dfrac{V_m\tau\omega}{1+(\tau\omega)^2}\sin(\omega t),$$ or as $$\dfrac{V_m}{\sqrt{1+(\tau\omega)^2}}\cos\!\left(\omega t-\tan^{-1}(\tau\omega)\right).$$
