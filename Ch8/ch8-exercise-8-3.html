Exercise 8-3

Construct and Add Current Phasors

This exercise repeats the additive-property flow with current signals. The muscle memory is the same: catch both waveforms, confirm the common angular frequency, convert to phasors, add in rectangular form, then coat the one result back into a cosine current.

$$i_1(t)=100\cos(2000t)\text{ mA}\qquad i_2(t)=50\cos(2000t-60^\circ)\text{ mA}$$ $$i(t)=i_1(t)+i_2(t)$$
Major GuideOpen in Memory Builder
Quick Data
Phasors
$$I_1=100\angle0^\circ,\qquad I_2=50\angle-60^\circ$$
Rectangular Pieces
$$I_1=100+j0,\qquad I_2=25-j43.3\text{ mA}$$
Answer Form
One current phasor and one final current waveform.
Rooms: Full Solution

Room 1: Match the Frequency

  • Check the frequency before you add. Both currents use $$\omega=2000,$$ so they may be represented in one phasor diagram and added.
  • Now read the two cosines directly into polar phasor form: $$I_1=100\angle0^\circ,\quad I_2=50\angle-60^\circ.$$
  • The first current has phase $$0^\circ,$$ so its phasor lies exactly on the positive real axis.

Room 2: Split the Second Current

  • The first phasor is already easy in rectangular form: $$I_1=100\angle0^\circ=100+j0\text{ mA}.$$
  • Now convert the tilted phasor with $$M\angle\theta=M(\cos\theta+j\sin\theta).$$
  • So $$I_2=50(\cos-60^\circ+j\sin-60^\circ).$$
  • Use $$\cos-60^\circ=\frac12$$ and $$\sin-60^\circ=-\frac{\sqrt3}{2}\approx-0.866.$$
  • That gives real part $$50\cdot\frac12=25$$ and imaginary part $$50(-0.866)=-43.3.$$
  • Therefore $$I_2=25-j43.3\text{ mA}.$$

Room 3: Add on the Mat

  • Now both currents are in rectangular form, so add horizontal and vertical parts separately.
  • $$I=I_1+I_2=(100+25)+j(0-43.3).$$
  • So the combined current is $$I=125-j43.3\text{ mA}.$$
  • The positive real part and negative imaginary part tell you the sum sits in quadrant IV before you even rebuild the angle.

Room 4: Rebuild Polar Form

  • Find the magnitude from the rectangular coordinates: $$|I|=\sqrt{125^2+43.3^2}\approx132\text{ mA}.$$
  • Find the angle from the tangent ratio: $$\theta=\tan^{-1}\left(\frac{-43.3}{125}\right)\approx-19.1^\circ.$$
  • Because the real part is positive and the imaginary part is negative, the phasor lies in quadrant IV, so the negative angle is the correct one.
  • Thus $$I=132\angle-19.1^\circ\text{ mA}.$$

Room 5: Coat the Final Wave

  • Return to the time domain with the same angular frequency $$\omega=2000.$$
  • Use the coat rule $$M\angle\theta\rightarrow M\cos(\omega t+\theta).$$
  • That means amplitude $$132,$$ frequency term $$2000t,$$ and phase shift $$-19.1^\circ.$$
  • So $$\boxed{i(t)=132\cos(2000t-19.1^\circ)\text{ mA}}$$

Key Shortcut

The first current already lies on the real axis, so only the second current really needs the knife treatment before the mat addition.

Why The Addition Is Easy Here

$$I_1$$ is already sitting on the positive real axis as $$100+j0,$$ so the only real conversion work is for $$I_2.$$ Once $$I_2$$ is split into its rectangular pieces, the addition becomes simple bookkeeping: add the real parts, add the imaginary parts, then rebuild one final magnitude-angle phasor from the result.

Rectangular Form As Coordinates

Think of $$125-j43.3$$ as the point $$(125,-43.3)$$ in the phasor plane. The magnitude is then the distance from the origin, and the phase is the direction from the positive real axis. That geometric picture is why rectangular form is so useful right after addition.
