Exercise 8-15

Pull the Inductor Voltage Out of Example 8-10

This page is a short but complete memory movie. You first catch the source current found in Example 8-10, then let the inductor impedance rotate that current by ninety degrees, stamp the inductor-voltage phasor, and finally coat it back into the time domain. The key memory move is angle addition: the inductor contributes a +90 degree turn.

$$v_L(t)=100\cos(2000t+143^\circ)\text{ V}$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Given
Use the solved current from Example 8-10 and the inductor impedance.
Find
Find the inductor voltage phasor $V_L$ and the waveform $v_L(t).$
Target
This question is asking for the voltage across the inductor only.
Quick Data
Known Current
$$I=0.2\angle53.1^\circ\text{ A}$$ from Example 8-10
Inductor Impedance
$$Z_L=j\omega L=j500=500\angle90^\circ\,\Omega$$
Final Voltage
$$V_L=100\angle143.1^\circ\text{ V}$$
Rooms: Full Solution

Room 1: Catch the Current from Example 8-10

  • From Example 8-10, the source current is already known: $$I=0.2\angle53.1^\circ\text{ A}.$$
  • This is the same current through the series inductor, so there is no new circuit reduction here.
  • The whole page hangs on one rule: once $$I$$ and $$Z_L$$ are known, use $$V_L=Z_LI.$$

Room 2: Pull Out the Inductor Impedance with $$\omega$$

  • Use $$\omega=2000$$ and $$L=0.25\text{ H}$$ to get $$Z_L=j\omega L=j(2000)(0.25)=j500\,\Omega.$$
  • In polar form, $$j500=500\angle90^\circ.$$ The inductor contributes a positive ninety-degree rotation.
  • So the memory line is: inductive voltage means add ninety degrees to the current angle.

Room 3: Multiply $$Z_L$$ and $$I$$ to Form the Phasor Voltage

  • Use $$V_L=Z_LI=(500\angle90^\circ)(0.2\angle53.1^\circ).$$
  • Multiply magnitudes: $$500\times0.2=100.$$
  • Add angles: $$90^\circ+53.1^\circ=143.1^\circ.$$
  • So $$V_L=100\angle143.1^\circ\text{ V}.$$

Room 4: Why the Answer Matches in Both Cases

  • The textbook says the answer is the same for both cases because the Multisim check and the hand solution describe the same sinusoidal steady-state phasor.
  • Once the current and inductor impedance are fixed, the inductor voltage cannot come out differently.
  • So the memory sentence is: same current, same impedance, same inductor voltage.

Room 5: Coat the Voltage Back into the Time Domain

  • Return the phasor to cosine form with the same angular frequency $$\omega=2000.$$
  • $$v_L(t)=100\cos(2000t+143.1^\circ)\text{ V}$$
  • Rounded to the textbook style, this is $$v_L(t)=100\cos(2000t+143^\circ)\text{ V}.$$

Key Shortcut

When an inductor voltage is built from a known current, memorize the phrase: keep the current, pull out $$j\omega L$$, multiply magnitudes, add ninety degrees.

Why This Flow Matters

This page trains a reusable reflex. In Chapter 8, many follow-up questions are really asking whether you can take a solved current and quickly stamp the voltage of one element without redoing the whole circuit.
