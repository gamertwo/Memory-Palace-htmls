Exercise 8-14

Reuse the Parallel Admittance Route with a Shifted Source

This is the fast parallel movie after Example 8-9, but the memory still has to feel connected: catch the shifted source current, pull out the branch impedances with the omega wheel, flip them into admittances, notice the cancellation that makes the total admittance purely real, divide to get the common voltage, then stamp the branch currents and coat the waveforms.

$$i_s(t)=100\cos(1000t-45^\circ)\text{ mA}$$
Major GuideOpen in Memory Builder
Quick Data
Source Phasor
$$I_S=0.1\angle-45^\circ\text{ A}$$
Branch Language
$$Z_C=-j1000,\qquad Z_{RL}=500+j500$$
Key Simplification
$$Y_{EQ}=0.001\angle0^\circ\text{ S},\qquad V=100\angle-45^\circ\text{ V}$$
Rooms: Full Solution

Room 1: Confirm the Source and Pull Out the Branch Impedances

  • The source is already in cosine form, so read it directly into phasor language: $$I_S=100\angle-45^\circ\text{ mA}=0.1\angle-45^\circ\text{ A}.$$
  • Now let $$\omega=1000$$ pull the branch impedances out of hiding.
  • For the capacitor branch, $$Z_C=\frac{1}{j\omega C}=\frac{1}{j(1000)(1\times10^{-6})}=-j1000\,\Omega.$$
  • For the series RL branch, the resistor stays real and the inductor becomes $$j\omega L=j(1000)(0.5)=j500,$$ so $$Z_{RL}=500+j500\,\Omega.$$
  • The memory trigger is: parallel current source first, branch impedances second, admittances third.

Room 2: Flip the Two Branches into Admittance Form

  • Parallel branches do not add cleanly in impedance form, so flip each branch into admittance language.
  • The capacitor branch becomes $$Y_1=\frac{1}{Z_C}=\frac{1}{-j1000}=j0.001=0.001\angle90^\circ\text{ S}.$$
  • For the RL branch, first note that $$500+j500=707.1\angle45^\circ\,\Omega.$$ When you take the reciprocal, the magnitude becomes $$1/707.1=1.414\times10^{-3}$$ and the angle changes sign, so $$Y_2=1.414\times10^{-3}\angle-45^\circ\text{ S}.$$
  • Convert $$Y_2$$ to rectangular form because the next move is addition: $$Y_2=(1.414\times10^{-3})(\cos(-45^\circ)+j\sin(-45^\circ))=0.001-j0.001.$$

Room 3: Add the Admittances and See Why the Angle Vanishes

  • Now add in rectangular form: $$Y_1=j0.001,\qquad Y_2=0.001-j0.001.$$
  • When you combine them, the imaginary parts cancel: $$Y_{EQ}=j0.001+(0.001-j0.001)=0.001+j0.$$
  • That is the key simplification of the whole problem. The total admittance is purely real, so $$Y_{EQ}=0.001\angle0^\circ\text{ S}.$$
  • Because the denominator angle is now zero, dividing by $$Y_{EQ}$$ will keep the same angle as the source current.
  • So the common voltage is $$V=\frac{I_S}{Y_{EQ}}=\frac{0.1\angle-45^\circ}{0.001\angle0^\circ}=100\angle-45^\circ\text{ V}.$$

Room 4: Stamp the Branch Currents from the Common Voltage

  • In a parallel network, both branches share the same voltage, so each branch current comes from $$I=YV.$$
  • For the series RL branch, $$I_R=I_L=Y_2V=(1.414\times10^{-3}\angle-45^\circ)(100\angle-45^\circ)=0.1414\angle-90^\circ\text{ A}.$$
  • That is $$141.4\angle-90^\circ\text{ mA}.$$ The resistor and inductor are in series inside that branch, so they carry the same current.
  • For the capacitor branch, $$I_C=Y_1V=(0.001\angle90^\circ)(100\angle-45^\circ)=0.1\angle45^\circ\text{ A}=100\angle45^\circ\text{ mA}.$$

Room 5: Coat the Final Waveforms

  • Keep the same angular frequency $$\omega=1000$$ when you return to the time domain.
  • $$v(t)=100\cos(1000t-45^\circ)\text{ V}$$
  • $$i_R(t)=141.4\cos(1000t-90^\circ)\text{ mA}$$
  • $$i_L(t)=141.4\cos(1000t-90^\circ)\text{ mA}$$
  • $$i_C(t)=100\cos(1000t+45^\circ)\text{ mA}$$

Key Shortcut

This page is really about one lucky cancellation. Once the admittance pieces become $$j0.001$$ and $$0.001-j0.001,$$ the imaginary parts wipe each other out and the total becomes purely real. That is why the common voltage comes out so cleanly.

Why The Common Voltage Keeps the Same Angle

Division in polar form subtracts angles. Since $$Y_{EQ}=0.001\angle0^\circ,$$ the denominator contributes no angle shift. So $$V$$ keeps the source angle $$-45^\circ$$ while only the magnitude changes from $$0.1$$ to $$100.$$
