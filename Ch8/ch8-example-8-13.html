Example 8-13

Choose the Reactance that Makes the Load Purely Resistive

This page is a compensation movie. You first convert the given load from polar to rectangular thinking, solve for its real and imaginary parts, add an equal and opposite reactance, and then translate that required reactance into a practical capacitor value. The memory emphasis is that the compensating element does not replace the load; it cancels the unwanted reactive lane.

$$R=146.2\,\Omega,quad X=292.5\,\Omega,quad C\approx9.1\,\mu ext{F}$$

Find
Find what reactance must be added to make the total load purely resistive.
Target
Then convert that required reactance into a practical component value.
Quick Data
Given Load
$$Z_L=327.6\angle63.4^\circ\,\Omega$$
Recovered Parts
$$R=146.2\,\Omega,quad X=292.5\,\Omega$$
Compensation Choice
Add $$-j292.5\,\Omega$$, so use a capacitor near $$10\,\mu ext{F}$$
Rooms: Full Solution

Room 1: Read the Polar Load into Component Relationships

  • The given load is $$Z_L=327.6\angle63.4^\circ\,\Omega.$$
  • The phase angle tells you $$\tan63.4^\circ=\frac{X}{R}=2,$$ so $$X=2R.$$
  • This is the first memory shortcut: use the angle to get a ratio before you use the magnitude.

Room 2: Use the Magnitude to Solve for $$R$$ and $$X$$

  • Since $$X=2R,$$ the magnitude relation becomes $$\sqrt{R^2+X^2}=\sqrt{R^2+4R^2}=R\sqrt5=327.6.$$
  • So $$R=146.2\,\Omega.$$
  • Then $$X=2R=292.5\,\Omega.$$

Room 3: Decide the Opposite Reactance You Must Add

  • The load has a positive imaginary part, so it is inductive.
  • To make the total purely resistive, add the opposite reactance $$-j292.5\,\Omega.$$
  • This is the central memory move: compensation means equal magnitude, opposite sign.

Room 4: Convert the Needed Reactance into a Capacitor

  • A negative reactance in this frequency setting means a capacitor.
  • Use $$X_C=\frac{1}{\omega C}$$ so $$C=\frac{1}{\omega X_C}=\frac{1}{(377)(292.5)}\approx9.1\,\mu ext{F}. $$
  • The book notes that the nearest practical value is $$10\,\mu ext{F}. $$

Room 5: State the Practical Compensation Answer

  • The load components are $$R=146.2\,\Omega$$ and $$X=292.5\,\Omega.$$
  • Add a compensating capacitor that contributes $$-j292.5\,\Omega.$$
  • A practical choice is about $$10\,\mu ext{F}. $$

Key Shortcut

Let the phase angle give you a ratio first. Only after that should the magnitude be used to recover the actual component values.

Why This Flow Matters

This page helps you memorize compensation as a clean, reusable pattern: read the load, split it into lanes, then cancel only the unwanted imaginary lane with an equal and opposite reactance.
