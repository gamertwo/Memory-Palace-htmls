Example 8-4

Convert Phasors to Waveforms and Add Them

This example mixes both directions. First coat each given phasor into a sinusoid, then use rectangular phasor addition to produce the combined output waveform.

$$V_1=20+j20\text{ V},\qquad V_2=10\sqrt{2}\,e^{-j45^\circ}\text{ V},\qquad \omega=500\text{ rad/s}$$ $$v_3(t)=v_1(t)+v_2(t)$$
Major GuideOpen in Memory Builder
Quick Data
Polar View of $$V_1$$
$$V_1=20\sqrt{2}\angle45^\circ$$
Rectangular View of $$V_2$$
$$V_2=10-j10$$
Frequency
Both waveforms use $$\omega=500.$$
Rooms: Full Solution

Room 1: Coat $$V_1$$

  • Start with the rectangular phasor $$V_1=20+j20.$$ To convert it to a waveform cleanly, first rewrite it in polar form.
  • The magnitude is $$|V_1|=\sqrt{20^2+20^2}=20\sqrt2,$$ and because the real and imaginary parts are equal and both positive, the angle is $$45^\circ.$$
  • So $$V_1=20\sqrt2\angle45^\circ.$$
  • Now coat it back into the time domain with the shared $$\omega=500:$$ $$\boxed{v_1(t)=20\sqrt{2}\cos(500t+45^\circ)\text{ V}}.$$

Room 2: Coat $$V_2$$

  • The second phasor is already given in polar form: $$V_2=10\sqrt{2}\angle-45^\circ.$$
  • If you want its rectangular picture for later addition, use $$M(\cos\theta+j\sin\theta):$$ $$V_2=10\sqrt2(\cos-45^\circ+j\sin-45^\circ)=10-j10.$$
  • For the waveform, keep the same magnitude and phase and attach the common frequency $$\omega=500.$$
  • Thus $$\boxed{v_2(t)=10\sqrt{2}\cos(500t-45^\circ)\text{ V}}.$$

Room 3: Add in Rectangular Form

  • Now switch back to rectangular form because addition is easiest there.
  • Use $$V_1=20+j20$$ and $$V_2=10-j10.$$
  • Add real parts and imaginary parts separately: $$V_3=V_1+V_2=(20+10)+j(20-10)=30+j10.$$
  • This tells you the combined phasor sits in quadrant I because both parts are positive.

Room 4: Rebuild Polar Form

  • Now convert the sum $$30+j10$$ back to polar form.
  • Magnitude: $$|V_3|=\sqrt{30^2+10^2}=31.6.$$
  • Angle: $$\theta=\tan^{-1}\left(\frac{10}{30}\right)=18.4^\circ.$$
  • Because both rectangular parts are positive, quadrant I is correct, so no angle adjustment is needed.
  • So $$V_3=31.6\angle18.4^\circ\text{ V}.$$

Room 5: Coat the Output Wave

  • Use the common angular frequency $$\omega=500.$$
  • Apply the coat rule $$M\angle\theta\rightarrow M\cos(\omega t+\theta).$$
  • That gives amplitude $$31.6,$$ frequency term $$500t,$$ and phase shift $$+18.4^\circ.$$
  • So $$\boxed{v_3(t)=31.6\cos(500t+18.4^\circ)\text{ V}}$$

Key Shortcut

Coat the inputs from polar form, but add the actual phasors in rectangular form. That split of jobs keeps the work clean.

Why The Page Uses Both Directions

This example makes you practice both conversions on purpose. First you read phasors back into waveforms so you can see what each input signal looks like in time. Then you return to phasor addition, because adding waveforms directly is messy while adding rectangular phasor components is clean and exact.

How To Decide Which Form To Use

Use polar form when you want a clean amplitude-angle description or when you are about to coat a waveform. Use rectangular form when you need component arithmetic such as addition. This page is useful because it makes you switch forms for the right reason instead of using one form for everything.
