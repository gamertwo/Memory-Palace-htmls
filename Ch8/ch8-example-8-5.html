Example 8-5

Find the Steady-State Voltage in a Series RC Circuit

This example extends Chapter 8 from pure phasor conversion into circuit analysis. Catch the source current, convert the resistor and capacitor into impedances, compute the element voltages with $$V=ZI,$$ add them with KVL, and then coat the total phasor back into the time-domain voltage waveform.

$$i(t)=4\cos(5000t)\text{ A},\qquad R=10\,\Omega,\qquad C=10\,\mu\text{F}$$ $$\text{Find the steady-state voltage }v(t).$$
Major GuideOpen in Memory Builder
Quick Data
Source Phasor
$$I=4\angle0^\circ=4+j0\text{ A}$$
Element Impedances
$$Z_R=10+j0,\qquad Z_C=\frac{1}{j\omega C}=-j20$$
Big Move
Find $$V_R$$ and $$V_C$$ first, then add them with KVL to get the total phasor voltage.
Rooms: Full Solution

Room 1: Catch the Current and Convert the Elements

  • The source current is already in cosine-reference form, so its phasor is $$I=4\angle0^\circ=4+j0\text{ A}.$$
  • The resistor impedance is purely real: $$Z_R=R=10+j0.$$
  • For the capacitor, use $$Z_C=\dfrac{1}{j\omega C}.$$ Here $$\omega=5000$$ and $$C=10\,\mu\text{F}=10\times10^{-6}=10^{-5}\text{ F}.$$
  • So $$Z_C=\frac{1}{j(5000)(10^{-5})}=\frac{1}{j(0.05)}=-j20\,\Omega.$$

Room 2: Find the Resistor Voltage

  • Use the impedance form of Ohm's law: $$V_R=Z_RI.$$
  • So $$V_R=(10+j0)(4+j0).$$
  • Because both factors lie on the real axis, the result is purely real: $$V_R=40+j0\text{ V}.$$
  • This makes sense physically because the resistor voltage stays in phase with the current.

Room 3: Find the Capacitor Voltage

  • Now compute the capacitor voltage with the same rule: $$V_C=Z_CI.$$
  • So $$V_C=(-j20)(4+j0)=-j80\text{ V}.$$
  • The result is purely negative imaginary, which matches the capacitor idea that voltage lags current by $$90^\circ.$$
  • So the resistor contributes the horizontal part, while the capacitor contributes the downward vertical part.

Room 4: Add the Element Voltages

  • Apply KVL around the loop: the total steady-state voltage is the sum of the element voltages.
  • $$V=V_R+V_C=(40+j0)+(0-j80)=40-j80.$$
  • Now rebuild polar form. The magnitude is $$|V|=\sqrt{40^2+80^2}=89.4\text{ V}.$$
  • The angle is $$\theta=\tan^{-1}\left(\frac{-80}{40}\right)=-63.4^\circ.$$ Because the real part is positive and the imaginary part is negative, quadrant IV is correct.
  • So $$V=89.4\angle-63.4^\circ\text{ V}.$$

Room 5: Coat the Steady-State Waveform

  • Return to the time domain with the same angular frequency $$\omega=5000.$$
  • Use the coat rule $$M\angle\theta\rightarrow M\cos(\omega t+\theta).$$
  • That gives amplitude $$89.4,$$ frequency term $$5000t,$$ and phase shift $$-63.4^\circ.$$
  • So the steady-state voltage waveform is $$\boxed{v(t)=89.4\cos(5000t-63.4^\circ)\text{ V}}.$$

Key Shortcut

In series phasor circuits, convert each element to its impedance first, use $$V=ZI$$ on each element, and then add the element voltages. That is cleaner than trying to jump straight from the source current to the final waveform.

Why The Capacitor Voltage Points Down

The capacitor impedance is $$-j20,$$ which lies on the negative imaginary axis. Multiplying the current phasor by that impedance rotates the resulting voltage downward by $$90^\circ.$$ That is why $$V_C$$ becomes $$-j80$$ and not a positive imaginary quantity.

How KVL Looks In Phasor Form

Kirchhoff's voltage law still works in sinusoidal steady state. The only difference is that you add phasor voltages instead of time-domain expressions. So $$V=V_R+V_C$$ is the phasor version of the same loop rule you already know from circuits.
