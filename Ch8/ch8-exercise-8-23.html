Exercise 8-23

Use Superposition to Find the Phasor Current $$I_x$$

This exercise is the current-output companion to Example 8-16. The method is unchanged: turn off one source at a time, solve the current contribution produced by each reduced circuit, and then add the contributions because the sources share the same frequency. The memory emphasis is that superposition cares about the output type only at the last step; the isolate, solve, add rhythm stays the same.

$$I_x=0.206\angle-158^\circ\text{ A}$$

Rooms: Full Solution

Room 1: Recognize the Same-Frequency Superposition Pattern

  • This exercise belongs to the same superposition family as Example 8-16.
  • The sources share one operating frequency, so each contribution to $$I_x$$ can remain a phasor until the final addition.

Room 2: Solve the Contribution from Source 1 Alone

  • Turn off source 2 and keep source 1 active.
  • Reduce the resulting network and find the phasor current contribution through the branch labeled $$I_x.$$
  • This produces the first partial response for the output current.

Room 3: Solve the Contribution from Source 2 Alone

  • Now turn off source 1 and let source 2 act by itself.
  • Again reduce the circuit and recover the second phasor contribution to $$I_x.$$
  • The output current now has two phasor pieces at the same frequency.

Room 4: Add the Two Partial Current Responses

  • Because the partial responses live at the same frequency, add them as phasors.
  • This is the same final move used for the voltage output in Example 8-16, but now the object being added is a current.

Room 5: State the Textbook Answer Cleanly

  • The final phasor current is $$I_x=0.206\angle-158^\circ\text{ A}.$$
  • The memory sentence is: isolate one source, solve one current piece, repeat, then phasor-add the pieces.

Key Shortcut

If the frequencies match, current responses combine just as cleanly as voltage responses do. Only the output label changes.

Why This Flow Matters

This exercise helps separate the superposition method from the output quantity. The same source-isolation logic works whether the final answer is a voltage or a current.
