Exercise 8-22

Use the Unit Output Method When the Desired Output Is a Current

This page is the current-output twin of Example 8-15. Instead of assuming a unit voltage at the output node, you assume a unit output current, solve the network once for that trial case, and then scale by the source current. The memory emphasis is that the unit output method works for current outputs just as cleanly as it does for voltage outputs.

$$K=\frac{I_o}{I_s}=0.204\angle-24.3^\circ,\qquad I_o=10.22\angle-9.28^\circ\text{ mA}$$

Rooms: Full Solution

Room 1: Recognize the Current-Output Version of the Method

  • This exercise uses the same unit output method as Example 8-15, but now the desired output is a current instead of a voltage.
  • So the thing you temporarily force to a unit value is the output current $$I_o,$$ not the output voltage.

Room 2: Solve the Circuit Once for a Unit Output Current

  • Assume a clean trial value such as $$I_o=1\angle0^\circ.$$
  • Then walk backward through the circuit to determine what source current would be required to produce that unit output.
  • The algebra details depend on the network, but the memory move stays the same: unit output first, recovered input second.

Room 3: Turn the Trial Run into a Transfer Ratio

  • Once the unit run is finished, convert it into a proportionality factor between the output current and the source current.
  • The textbook gives that factor directly as $$K=\frac{I_o}{I_s}=0.204\angle-24.3^\circ.$$
  • This ratio is the reusable prize of the whole method.

Room 4: Scale the Real Source Current

  • Now use the actual source current from the figure: $$I_s=50\angle15^\circ\text{ mA}.$$
  • Multiply by the transfer ratio: $$I_o=K I_s=(0.204\angle-24.3^\circ)(50\angle15^\circ\text{ mA}).$$
  • Add angles and multiply magnitudes to get $$I_o=10.22\angle-9.28^\circ\text{ mA}.$$

Room 5: State the Final Memory Hook

  • The final answer is $$I_o=10.22\angle-9.28^\circ\text{ mA}.$$
  • The memory sentence is: assume unit output current, recover the source current, store the ratio, then scale the real source.

Key Shortcut

For a current-output unit method problem, remember the chain: unit $$I_o,$$ recover $$I_s,$$ form $$K=I_o/I_s,$$ then scale the real source.

Why This Flow Matters

The method stays stable even when the output type changes. That makes the circuit feel less like a new problem and more like a reused movie with one label swapped.
