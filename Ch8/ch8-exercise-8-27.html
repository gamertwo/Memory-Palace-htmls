Exercise 8-27

Convert the Thevenin Circuit in Example 8-20 into Norton Form

This is a pure source-transformation exercise, but it still deserves a full explanation. Every number on this page comes from the Thevenin result of Design Example 8-20, and the key idea is that the source changes form while the terminal behavior seen by the load stays identical.

$$I_N=\frac{V_T}{Z_T}=50\text{ mA},\qquad Z_N=500-j500~\Omega,\qquad Z_L=235.3-j58.8~\Omega$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Given
From Design Example 8-20, $$V_T=35.35\angle-45^\circ\text{ V}$$ and $$Z_T=500-j500~\Omega.$$
Find
Convert that Thevenin circuit into its Norton equivalent.
Big Rule
Use $$I_N=V_T/Z_T$$ and keep the same equivalent impedance at the terminals.
Rooms: Full Solution

Room 1: Start from the Thevenin Pair Already Found

  • The previous page already reduced the fixed network to $$V_T=35.35\angle-45^\circ\text{ V},\qquad Z_T=500-j500~\Omega.$$
  • This exercise does not ask us to re-derive those numbers. It asks us to change only the source representation.
  • So the entire job starts from one known voltage source in series with one known impedance.

Why This Is Legitimate

Thevenin and Norton circuits are two different internal pictures of the same terminal behavior. If the Thevenin pair is already known, the Norton pair follows directly from the source-transformation rule.

Room 2: Rewrite $$Z_T$$ in Polar Form So the Division Is Transparent

  • The given impedance is rectangular: $$Z_T=500-j500~\Omega.$$
  • Its magnitude comes from the Pythagorean formula: $$|Z_T|=\sqrt{500^2+(-500)^2}=\sqrt{500000}=707.1~\Omega.$$
  • Its angle comes from the ratio of imaginary part to real part: $$\angle Z_T=\tan^{-1}\left(\frac{-500}{500}\right)=\tan^{-1}(-1)=-45^\circ.$$
  • So the same impedance can be written as $$Z_T=707.1\angle-45^\circ~\Omega.$$

Why the Angle Is Negative

The real part is positive and the imaginary part is negative, so the impedance point lies in the fourth quadrant. That is why its phase is $$-45^\circ.$$

Why We Convert

Division is easiest in polar form because magnitudes divide and angles subtract. That lets us explain the Norton current magnitude and phase separately.

Room 3: Divide $$V_T$$ by $$Z_T$$ to Get the Norton Current

  • The source-transformation rule is $$I_N=\frac{V_T}{Z_T}.$$
  • Substitute the polar forms: $$I_N=\frac{35.35\angle-45^\circ}{707.1\angle-45^\circ}.$$
  • Now do the two polar-division jobs separately.

Magnitude Origin

The magnitude comes only from dividing the voltage magnitude by the impedance magnitude: $$|I_N|=\frac{35.35}{707.1}=0.05\text{ A}=50\text{ mA}.$$ That is where the number $$50\text{ mA}$$ comes from.

Phase Origin

The angle comes only from subtracting the impedance angle from the voltage angle: $$\angle I_N=(-45^\circ)-(-45^\circ)=0^\circ.$$ The two $$-45^\circ$$ angles cancel exactly, so the Norton current has zero phase shift.

Current in Final Form

Therefore, $$I_N=0.05\angle0^\circ\text{ A}=50\text{ mA}.$$ Because the angle is zero, many books simply write the answer as $$50\text{ mA}.$$

Room 4: Keep the Same Equivalent Impedance

  • Source transformation does not change the impedance seen at the output terminals.
  • So the Norton impedance is exactly the same as the Thevenin impedance: $$Z_N=Z_T=500-j500~\Omega.$$
  • If you prefer polar form, that is also $$Z_N=707.1\angle-45^\circ~\Omega.$$

Why This Number Does Not Change

The source is what gets repackaged. The port behavior must stay identical, so the impedance seen by any external load must remain unchanged.

Room 5: Explain Why the Same Load Still Works

  • Design Example 8-20 chose the load $$Z_L=235.3-j58.8~\Omega$$ to produce the required output.
  • That load was chosen from the terminal behavior of the source network, not from the internal picture of the source.
  • Since Thevenin and Norton forms are terminally equivalent, the same load must produce the same load voltage and current in both versions.

Physical Meaning

If two source models have the same terminal $$v$$-$$i$$ behavior, a load connected at those terminals cannot tell which internal model is being used. That is why the designed load stays $$Z_L=235.3-j58.8~\Omega.$$

Room 6: State the Final Norton Circuit Cleanly

  • The Norton current source is $$I_N=50\text{ mA}.$$
  • The Norton parallel impedance is $$Z_N=500-j500~\Omega.$$
  • The previously designed load remains $$Z_L=235.3-j58.8~\Omega.$$

Final Answer

Equivalent Norton form: $$I_N=50\text{ mA},\qquad Z_N=500-j500~\Omega.$$

Compact Exam-Style Working

$$Z_T=500-j500=707.1\angle-45^\circ~\Omega$$ $$I_N=\frac{V_T}{Z_T}=\frac{35.35\angle-45^\circ}{707.1\angle-45^\circ}=0.05\angle0^\circ\text{ A}=50\text{ mA}$$ $$Z_N=Z_T=500-j500~\Omega$$
