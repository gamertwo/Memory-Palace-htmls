Exercise 8-27

Convert the Thevenin Circuit in Example 8-20 into Norton Form

This exercise is the immediate after-movie for the design example. You take the Thevenin pair just found, transform it into a Norton pair, and notice that the same designed load must still work because equivalent circuits present the same terminal behavior.

$$I_N=\frac{V_T}{Z_T}=50\text{ mA},\qquad Z_N=500-j500~\Omega,\qquad Z_L=235.3-j58.8~\Omega$$
Major GuideOpen in Memory Builder
Rooms: Full Solution

Room 1: Reuse the Thevenin Pair from Example 8-20

  • From Example 8-20, $$V_T=35.35\angle-45^\circ\text{ V}$$ and $$Z_T=500-j500~\Omega.$$
  • These are the only starting values you need.
  • The source transformation is now mechanical.

Why This Step

This page is meant to feel short on purpose. The analysis work was already done in the design example, so now you are just changing the source representation.

Room 2: Divide to Get the Norton Current

  • Use $$I_N=V_T/Z_T.$$
  • With the Example 8-20 values, this gives $$I_N=50\text{ mA}.$$
  • This is the Norton current source.

Why This Step

This is the same transformation rule from Example 8-19, now applied to the values produced inside a bigger design problem.

Room 3: Keep the Same Impedance

  • The Norton impedance equals the Thevenin impedance.
  • So $$Z_N=500-j500~\Omega.$$
  • The final source model is a current source in parallel with this impedance.

Why This Step

Equivalent circuits must present the same load behavior at the port, so the impedance seen by the load cannot change.

Room 4: Keep the Same Designed Load

  • Because the Thevenin and Norton versions are equivalent, the load requirement does not change.
  • So the same load $$Z_L=235.3-j58.8~\Omega$$ still produces the required output.
  • The whole point is that source transformation does not alter external behavior.

Why This Step

This is the physical meaning of equivalence. Different internal pictures are allowed as long as the load sees the same terminal voltage-current behavior.
