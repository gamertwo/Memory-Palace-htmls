Exercise 8-9

Find Element Impedances and Voltages in an LC Series Circuit

This exercise blends the impedance formulas with element-voltage phasors and waveform coating. Catch the current source, compute the inductor and capacitor impedances, find each phasor voltage with $$V=ZI,$$ then coat those voltages back into time-domain signals and interpret the lead-lag relationships.

$$L=12\,\text{mH},\qquad C=20\,\text{pF},\qquad i_L(t)=20\cos(10^6 t)\text{ mA}$$ $$\text{Find }Z_L,\;Z_C,\;V_L,\;V_C,\;v_L(t),\;v_C(t)\text{ and the lead-lag facts.}$$
Major GuideOpen in Memory Builder
Quick Data
Current Phasor
$$I=20\angle0^\circ\text{ mA}=0.02\angle0^\circ\text{ A}$$
Impedance Rules
$$Z_L=j\omega L,\qquad Z_C=\frac{1}{j\omega C}$$
Big Idea
Use the same current phasor through both series elements, then compute each voltage from its own impedance.
Rooms: Full Solution

Room 1: Convert the Current and Element Impedances

  • The current waveform is $$i_L(t)=20\cos(10^6 t)\text{ mA},$$ so the phasor current is $$I=20\angle0^\circ\text{ mA}=0.02\angle0^\circ\text{ A}.$$
  • For the inductor, $$Z_L=j\omega L=j(10^6)(12\times10^{-3})=j12{,}000=j12\text{ k}\Omega.$$
  • For the capacitor, $$Z_C=\dfrac{1}{j\omega C}=\dfrac{1}{j(10^6)(20\times10^{-12})}=-j50{,}000=-j50\text{ k}\Omega.$$

Room 2: Find the Inductor Voltage

  • Use $$V_L=Z_LI.$$
  • So $$V_L=(j12{,}000)(0.02\angle0^\circ)=j240\text{ V}.$$
  • In polar form that is $$V_L=240\angle90^\circ\text{ V}.$$
  • The positive imaginary direction matches the idea that inductor voltage leads current by $$90^\circ.$$

Room 3: Find the Capacitor Voltage

  • Now use $$V_C=Z_CI.$$
  • So $$V_C=(-j50{,}000)(0.02\angle0^\circ)=-j1000\text{ V}.$$
  • In polar form that is $$V_C=1000\angle-90^\circ\text{ V}.$$
  • The negative imaginary direction matches the capacitor idea that voltage lags current by $$90^\circ.$$

Room 4: Coat the Time-Domain Voltages

  • Now move back to the time domain with the same angular frequency $$\omega=10^6.$$
  • For the inductor: $$\boxed{v_L(t)=240\cos(10^6 t+90^\circ)\text{ V}}.$$
  • For the capacitor: $$\boxed{v_C(t)=1000\cos(10^6 t-90^\circ)\text{ V}}.$$
  • Notice that the capacitor has the larger voltage magnitude because its reactance magnitude is larger here.

Room 5: State the Lead-Lag Relationships

  • For the inductor, voltage leads current by $$90^\circ,$$ so the current lags the inductor voltage by $$90^\circ.$$
  • For the capacitor, current leads voltage by $$90^\circ.$$
  • So the key facts are $$\boxed{\text{current lags }v_L\text{ by }90^\circ}$$ and $$\boxed{\text{current leads }v_C\text{ by }90^\circ}.$$

Key Shortcut

Once the current phasor is known, the whole exercise is just repeated use of the two impedance formulas and $$V=ZI.$$ The only change from one element to the other is whether the impedance points up or down the imaginary axis.

Why The Inductor and Capacitor Point Opposite Ways

Inductor impedance is positive imaginary, so it rotates the voltage upward to $$+90^\circ.$$ Capacitor impedance is negative imaginary, so it rotates the voltage downward to $$-90^\circ.$$ That sign difference is the whole reason the two lead-lag statements come out opposite.

How To Read The Lead-Lag Statement

If voltage is at $$+90^\circ$$ while current is at $$0^\circ,$$ voltage is ahead and current lags. If voltage is at $$-90^\circ$$ while current is at $$0^\circ,$$ current is ahead and therefore leads.
