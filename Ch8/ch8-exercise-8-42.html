Exercise 8-42

Find the Average Power Delivered to the 25-Ohm Load

The key move is to solve for the load-node voltage first. After that, the load current and average power are direct.

$$V_O=97.5-j46.9\text{ V},\qquad I_L=3.90-j1.87\text{ A},\qquad P=234\text{ W}$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Left Source
$$150\angle0^\circ\text{ V}$$ connected to the load node through $$j2\ \Omega.$$
Right Source
$$125\angle-90^\circ\text{ V}$$ connected to the load node through $$j4\ \Omega.$$
Load
A 25-$$\Omega$$ resistor from the load node to ground.
Rooms: Full Solution

Room 1: Let the Load-Node Voltage Be $$V_O$$

  • Call the top node voltage $$V_O.$$ It is also the voltage across the 25-$$\Omega$$ load resistor.

Room 2: Write KCL at the Load Node

  • Current to the left source: $$\frac{V_O-150\angle0^\circ}{j2}$$
  • Current to the right source: $$\frac{V_O-125\angle-90^\circ}{j4}$$
  • Current to ground through the resistor: $$\frac{V_O}{25}$$
  • KCL gives $$\frac{V_O-150\angle0^\circ}{j2}+\frac{V_O-125\angle-90^\circ}{j4}+\frac{V_O}{25}=0.$$

Room 3: Solve the Node Equation

  • Using $$125\angle-90^\circ=-j125,$$ the solution is $$V_O=97.5-j46.9\text{ V}. $$

Room 4: Find the Load Current

  • $$I_L=\frac{V_O}{25}=\frac{97.5-j46.9}{25}=3.90-j1.87\text{ A}. $$
  • So $$|I_L|=4.33\text{ A}. $$

Room 5: Compute the Average Power

  • Using peak phasors, $$P=\frac{1}{2}R|I|^2.$$
  • So $$P=\frac{1}{2}(25)(4.33)^2=234\text{ W}. $$

Why Only the Resistor Gets Average Power

The reactive feed branches shape the current, but the resistor is the element that dissipates net energy.

Room 6: Final Answer

  • $$V_O=97.5-j46.9\text{ V},\qquad I_L=3.90-j1.87\text{ A},\qquad P=234\text{ W}. $$
