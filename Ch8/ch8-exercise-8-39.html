Exercise 8-39

Use Mesh-Current or Node-Voltage Analysis to Find $$V_2$$ and $$Z_{IN}$$

This circuit is friendly in node form because the bottom rail is ground and the source fixes the left source node. Two unknown node voltages are enough to recover both the output voltage and the input impedance.

$$V_2=1.77\angle-135^\circ\text{ V},\qquad Z_{IN}=100-j100~\Omega$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Given
The source is $$V_S=5\angle0^\circ\text{ V}.$$ The network contains a series 50-$$\Omega$$ input resistor, two shunt capacitors $$-j50\ \Omega,$$ a series inductor $$j100\ \Omega,$$ and a shunt 50-$$\Omega$$ load.
Unknowns
The output voltage $$V_2$$ and the input impedance $$Z_{IN}.$$
Method Choice
Node-voltage analysis gives two equations in two unknown node voltages.
Rooms: Full Solution

Room 1: Choose the Two Unknown Node Voltages

  • Let $$V_A$$ be the voltage at the first top node after the 50-$$\Omega$$ input resistor.
  • Let $$V_B$$ be the voltage at the output node. Because the output is measured from that node to ground, $$V_2=V_B.$$
  • The source node itself is already known: $$V_S=5\angle0^\circ\text{ V}.$$

Room 2: Write the KCL Equation at Node $$A$$

  • Current back through the input resistor: $$\frac{V_A-V_S}{50}$$
  • Current through the left capacitor: $$\frac{V_A}{-j50}$$
  • Current through the inductor to node $$B$$: $$\frac{V_A-V_B}{j100}$$
  • KCL gives $$\frac{V_A-V_S}{50}+\frac{V_A}{-j50}+\frac{V_A-V_B}{j100}=0.$$

Room 3: Write the KCL Equation at Node $$B$$

  • Current through the inductor back to $$A$$: $$\frac{V_B-V_A}{j100}$$
  • Current through the right capacitor: $$\frac{V_B}{-j50}$$
  • Current through the load resistor: $$\frac{V_B}{50}$$
  • KCL gives $$\frac{V_B-V_A}{j100}+\frac{V_B}{-j50}+\frac{V_B}{50}=0.$$

Room 4: Solve for $$V_A$$ and $$V_B$$

  • Substituting $$V_S=5$$ and solving gives $$V_A=3.75-j1.25\text{ V},\qquad V_B=-1.25-j1.25\text{ V}. $$
  • Because $$V_2=V_B,$$ the output voltage is already known in rectangular form.

Convert $$V_2$$ to Polar Form

$$|V_2|=1.77\text{ V},\qquad \angle V_2=-135^\circ,$$ so $$V_2=1.77\angle-135^\circ\text{ V}. $$

Room 5: Find the Input Current and the Input Impedance

  • The input current is $$I_{IN}=\frac{V_S-V_A}{50}=\frac{5-(3.75-j1.25)}{50}=0.025+j0.025\text{ A}. $$
  • Then $$Z_{IN}=\frac{V_S}{I_{IN}}=\frac{5}{0.025+j0.025}=100-j100~\Omega.$$

Room 6: Final Answer

  • Output voltage: $$V_2=1.77\angle-135^\circ\text{ V}. $$
  • Input impedance: $$Z_{IN}=100-j100~\Omega. $$
