New Method
Do not use mesh currents this time. Use node-voltage thinking instead.
Main Lesson
A circuit can be mathematically correct under more than one method, but one method may be much shorter.
Rooms: Method Comparison

Room 1: Ask Which Variables the Sources Already Fix

  • In Figure 8-58, the independent sources determine several node voltages directly.
  • That means node analysis does not have to solve for every node from scratch.
  • After the obvious source-defined nodes are recognized, only one true unknown node voltage remains.

Room 2: Write One Unknown-Node KCL Equation

  • Because only one node voltage is unknown, KCL produces only one unknown-node equation.
  • Once that one node voltage is found, each branch current follows from a direct impedance division.
  • The point of the exercise is not that node analysis gives different physics. It gives the same answer with less algebra.

Room 3: Final Branch Currents

  • The branch currents are the same as in Example 8-32:
  • $$I_1=12.4\angle-15.0^\circ\text{ A}$$ $$I_2=3.61\angle-16.1^\circ\text{ A}$$ $$I_3=1.30\angle166.5^\circ\text{ A}$$

Room 4: Which Method Is Easier Here?

  • For this specific circuit, node-voltage analysis is easier.
  • The reason is structural: this four-node circuit reduces to only one unknown node-voltage equation.
  • That is lighter than solving the three mesh-current equations used in Example 8-32.
