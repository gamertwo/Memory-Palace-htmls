Example 8-6

Solve a Series RLC Circuit by Phasors

This is the full series-circuit movie: catch the source, convert each element to impedance, collapse the series path into one equivalent impedance, solve the current, then push that same current back through each element to recover all voltages and their waveforms.

$$v_s(t)=35\cos(1000t)\text{ V},\qquad R=50\,\Omega,\qquad C=10\,\mu\text{F},\qquad L=25\,\text{mH}$$
Major GuideOpen in Memory Builder
Quick Data
Source Phasor
$$V_s=35\angle0^\circ\text{ V}$$
Element Impedances
$$Z_R=50,\qquad Z_L=j25,\qquad Z_C=-j100$$
Equivalent
$$Z_{EQ}=50-j75=90.1\angle-56.3^\circ\,\Omega$$
Rooms: Full Solution

Room 1: Convert the Source and Element Impedances

  • Read the source directly into phasor form: $$V_s=35\angle0^\circ\text{ V}.$$
  • For the resistor, $$Z_R=R=50\,\Omega.$$
  • For the inductor, $$Z_L=j\omega L=j(1000)(25\times10^{-3})=j25\,\Omega.$$
  • For the capacitor, $$Z_C=\dfrac{1}{j\omega C}=\dfrac{1}{j(1000)(10^{-5})}=-j100\,\Omega.$$

Room 2: Collapse the Series Circuit

  • Series impedances add directly, so $$Z_{EQ}=Z_R+Z_L+Z_C.$$
  • That gives $$Z_{EQ}=50+j25-j100=50-j75\,\Omega.$$
  • Now convert this rectangular form into polar form. The magnitude comes from the right-triangle length: $$|Z_{EQ}|=\sqrt{50^2+(-75)^2}=\sqrt{8125}=90.1.$$
  • The angle comes from the tangent ratio: $$\tan\theta=\frac{\text{imaginary part}}{\text{real part}}=\frac{-75}{50}=-1.5.$$ So $$\theta=\tan^{-1}(-1.5)=-56.3^\circ.$$
  • That negative angle is correct because $$50-j75$$ lies in quadrant IV: the real part is positive and the imaginary part is negative, so the phasor points down and to the right.
  • So the same impedance in polar form is $$Z_{EQ}=90.1\angle-56.3^\circ\,\Omega.$$

Room 3: Solve the Series Current

  • Use Ohm's law in phasor form: $$I=\dfrac{V_s}{Z_{EQ}}.$$
  • So $$I=\dfrac{35\angle0^\circ}{90.1\angle-56.3^\circ}=0.388\angle56.3^\circ\text{ A}.$$
  • The positive angle means the source voltage is behind the current here because the net impedance angle is negative.

Room 4: Find the Element Voltages

  • The same series current flows through all elements, so use $$V=ZI$$ on each one.
  • $$V_R=Z_RI=50(0.388\angle56.3^\circ)=19.4\angle56.3^\circ\text{ V}.$$
  • $$V_L=Z_LI=j25(0.388\angle56.3^\circ)=9.70\angle146.3^\circ\text{ V}.$$
  • $$V_C=Z_CI=-j100(0.388\angle56.3^\circ)=38.8\angle-33.7^\circ\text{ V}.$$

Room 5: Coat the Waveforms

  • Now coat each phasor back into the time domain with the same $$\omega=1000.$$
  • $$i(t)=0.388\cos(1000t+56.3^\circ)\text{ A}$$
  • $$v_R(t)=19.4\cos(1000t+56.3^\circ)\text{ V}$$
  • $$v_L(t)=9.70\cos(1000t+146.3^\circ)\text{ V}$$
  • $$v_C(t)=38.8\cos(1000t-33.7^\circ)\text{ V}$$

Key Shortcut

In a series circuit, add impedances first and solve one current phasor. After that, every element voltage comes from reusing the same current with its own impedance.

Why The Inductor and Capacitor Voltages Split Apart

The inductor adds $$+90^\circ$$ to the current angle, while the capacitor adds $$-90^\circ.$$ That is why $$V_L$$ and $$V_C$$ end up on opposite sides of the phasor plane even though the same current flows through both.

Why The $$Z_{EQ}$$ Angle Is Negative

Picture $$50-j75$$ as a phasor arrow from the origin. It moves 50 units right on the real axis and 75 units down on the imaginary axis. That places it in quadrant IV, so the angle must be negative. The exact tilt comes from $$\tan\theta=-75/50,$$ which gives $$\theta=-56.3^\circ.$$
