Exercise 8-16

Use the Resonance Formula on Figure 8-25

This page is the substitution version of Application Example 8-11. You carry in the resonance formula, plug in the given values, solve for the resonant frequency, and then evaluate the equivalent impedance at resonance. The memory emphasis is that resonance kills the imaginary lane but not necessarily the whole impedance.

$$\omega_0=2000\text{ rad/s},\qquad Z_{EQ}=200+j0\,\Omega$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Given
$R=1\text{ k}\Omega, L=200\text{ mH}, C=1\,\mu\text{F}.$
Find
Find the resonant frequency and then find $Z_{EQ}$ under resonance.
Target
This question wants both $\omega_0$ and the equivalent impedance at that operating point.
Quick Data
Given Values
$$R=1\text{ k}\Omega,\quad L=200\text{ mH},\quad C=1\,\mu\text{F}$$
Resonant Frequency
$$\omega_0=2000\text{ rad/s}$$
Equivalent Impedance
$$Z_{EQ}=200+j0\,\Omega$$
Rooms: Full Solution

Room 1: Bring in the Parent Resonance Formula

  • From Application Example 8-11, the resonant frequency is $$\omega_0=\sqrt{\frac{1}{LC}-\frac{1}{(RC)^2}}.$$
  • This exercise is mainly about substituting carefully, not re-deriving the whole formula.

Room 2: Substitute the Given Values

  • Use $$L=0.2\text{ H},\ C=10^{-6}\text{ F},\ R=1000\,\Omega.$$
  • Then $$\frac{1}{LC}=\frac{1}{(0.2)(10^{-6})}=5\times10^6,$$ and $$\frac{1}{(RC)^2}=\frac{1}{(1000\times10^{-6})^2}=10^6.$$
  • So $$\omega_0=\sqrt{5\times10^6-10^6}=\sqrt{4\times10^6}=2000\text{ rad/s}. $$

Room 3: Evaluate the Real Part of $$Z_{EQ}$$ at Resonance

  • Use the real-part formula $$R_{EQ}=\frac{R}{1+(\omega RC)^2}. $$
  • At resonance, $$\omega RC=(2000)(1000)(10^{-6})=2.$$
  • So $$R_{EQ}=\frac{1000}{1+2^2}=\frac{1000}{5}=200\,\Omega.$$

Room 4: Show That the Imaginary Part Vanishes

  • At resonance the whole point is that $$X_{EQ}(\omega_0)=0.$$
  • So the equivalent impedance is purely real, not because every element disappeared, but because the positive and negative reactance contributions balance exactly.

Room 5: State the Final Resonance Answer

  • The resonant frequency is $$\omega_0=2\text{ krad/s}. $$
  • Under those conditions, $$Z_{EQ}=200+j0\,\Omega.$$
  • This is a good memory checkpoint: resonance here means a real input impedance of $$200\,\Omega$$, not $$1000\,\Omega$$.

Key Shortcut

Use the parent formula first, then compute $$\omega RC$$ before you touch the real part of the impedance.

Why This Flow Matters

This page trains you not to confuse physical resistance $$R$$ with the equivalent input resistance at resonance. The network can resonate and still present a different real value at the input terminals.
