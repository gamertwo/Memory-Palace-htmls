Example 8-16

Use Superposition When Both Sources Have the Same Frequency

This page is the first full superposition movie in the chapter. You turn off one source at a time, reduce the remaining network seen by the output node, compute the individual phasor responses, and then add those phasors directly because both sources operate at the same frequency. The memory emphasis is simple: same frequency means same phasor floor, so the responses can combine as phasors.

$$V_R=227\angle-47.9^\circ\text{ V},\qquad v_R(t)=227\cos(5000t-47.9^\circ)\text{ V}$$

What You Are Asked To Find
Given
Use superposition on Figure 8-32 for $$R=20\,\Omega,\ L_1=2\text{ mH},\ L_2=6\text{ mH},\ C=20\,\mu\text{F}.$$
Sources
$$v_{s1}=100\cos(5000t)\text{ V},\qquad v_{s2}=120\cos(5000t+30^\circ)\text{ V}$$
Find
Find the steady-state resistor voltage $$v_R(t)$$ and validate it with Multisim.
Quick Data
Impedances at $$\omega=5000$$
$$Z_{L1}=j10,\qquad Z_{L2}=j30,\qquad Z_C=-j10$$
Partial Responses
$$V_{R1}=166\angle-56.3^\circ\text{ V},\qquad V_{R2}=66.6\angle-26.3^\circ\text{ V}$$
Final Sum
$$V_R=227\angle-47.9^\circ\text{ V}$$
Rooms: Full Solution

Room 1: Confirm That Both Sources Share One Phasor Frequency

  • Both sources oscillate at $$\omega=5000\text{ rad/s}.$$ That is the key superposition checkpoint.
  • At this frequency, the impedances are $$Z_{L1}=j10\,\Omega,$$ $$Z_{L2}=j30\,\Omega,$$ and $$Z_C=-j10\,\Omega.$$
  • Because the sources live on the same frequency floor, the final responses can be added as phasors.

Room 2: Turn Off Source 2 and Reduce the Right-Side Parallel Block

  • With source 2 turned off, the right voltage source becomes a short circuit.
  • The three elements attached to the output node are then in parallel, so their equivalent impedance is
  • $$Z_{EQ1}=\frac{1}{\frac{1}{20}+\frac{1}{-j10}+\frac{1}{j30}}=7.20-j9.60\,\Omega.$$

Room 3: Use Voltage Division to Find $$V_{R1}$$

  • The left inductor $$j10\,\Omega$$ is now in series with $$Z_{EQ1},$$ so use voltage division.
  • $$V_{R1}=\frac{Z_{EQ1}}{j10+Z_{EQ1}}100\angle0^\circ$$
  • This gives $$V_{R1}=92.3-j138=166\angle-56.3^\circ\text{ V}.$$

Room 4: Turn Off Source 1 and Reduce the Left-Side Parallel Block

  • Now short source 1 and let source 2 act alone.
  • The three elements connected to the output node again form a parallel block:
  • $$Z_{EQ2}=\frac{1}{\frac{1}{20}+\frac{1}{-j10}+\frac{1}{j10}}=20-j0\,\Omega.$$
  • The inductive and capacitive admittances cancel here, so the reduced block becomes purely resistive.

Room 5: Use Voltage Division to Find $$V_{R2}$$

  • The right inductor $$j30\,\Omega$$ is now the series element, so apply voltage division again.
  • $$V_{R2}=\frac{Z_{EQ2}}{j30+Z_{EQ2}}120\angle30^\circ$$
  • This gives $$V_{R2}=59.7-j29.5=66.6\angle-26.3^\circ\text{ V}.$$

Room 6: Add the Same-Frequency Phasor Responses and Validate

  • Because both responses are at the same frequency, add them directly as phasors:
  • $$V_R=V_{R1}+V_{R2}=(92.3-j138)+(59.7-j29.5)=152-j168=227\angle-47.9^\circ\text{ V}.$$
  • So the time-domain answer is $$v_R(t)=227\cos(5000t-47.9^\circ)\text{ V}.$$
  • For Multisim validation, convert $$5000\text{ rad/s}$$ to $$795.77\text{ Hz}$$ and the simulated magnitude-phase result matches the hand calculation.

Key Shortcut

Same frequency means the two partial responses can live as phasors all the way to the end. Solve each source alone, then add the phasors directly.

Why This Flow Matters

This page sets the rule that the next example will contrast. Same-frequency superposition ends with phasor addition; different-frequency superposition ends with time-domain addition.
