Example 8-10

Reduce the Mixed RLC Circuit and Split the Currents

This page now uses the same heavier memory-movie treatment as the newer Chapter 8 pages. The route is: convert the source into a phasor, let omega pull out all the element impedances, shrink the inner parallel RC branch first, add the inductor in series to make one total impedance block, let division pull out the source current, then reopen the parallel chamber so current division can stamp the capacitor and resistor currents before the coat returns every result to the time domain.

$$v_s(t)=100\cos(2000t)\text{ V},\qquad L=250\,\text{mH},\qquad C=0.5\,\mu\text{F},\qquad R=3\,\text{k}\Omega$$

Quick Data
Source Phasor
$$V_S=100\angle0^\circ\text{ V}$$
Element Impedances
$$Z_L=j500,\qquad Z_C=-j1000,\qquad Z_R=3000$$
Final Current Block
$$Z_{EQ}=300-j400,\qquad I=0.2\angle53.1^\circ\text{ A}$$
Rooms: Full Solution

Room 1: Convert the Source and Pull Out Every Element Impedance

  • The source is already in cosine form, so its phasor is read directly as $$V_S=100\angle0^\circ\text{ V}.$$
  • Now let $$\omega=2000$$ pull out the three element impedances.
  • The inductor gives $$Z_L=j\omega L=j(2000)(0.25)=j500\,\Omega.$$
  • The capacitor gives $$Z_C=\frac{1}{j\omega C}=\frac{1}{j(2000)(0.5\times10^{-6})}=-j1000\,\Omega.$$
  • The resistor stays real: $$Z_R=3000\,\Omega.$$
  • The memory cue is to see all three pieces before reducing anything: source first, omega second, impedances third.

Room 2: Shrink the Inner Parallel RC Branch

  • The resistor and capacitor share the same two nodes, so reduce that inner branch before touching the inductor.
  • Use parallel impedance: $$Z_{EQ1}=\frac{1}{\frac{1}{Z_C}+\frac{1}{Z_R}}=\frac{1}{\frac{1}{-j1000}+\frac{1}{3000}}.$$
  • Write the denominator in rectangular form: $$\frac{1}{-j1000}=j0.001,\qquad \frac{1}{3000}=0.0003333.$$ So the denominator is $$0.0003333+j0.001.$$
  • Taking the reciprocal collapses that branch to $$Z_{EQ1}=300-j900\,\Omega.$$ The branch is no longer a resistor and capacitor separately; it is now one equivalent block.

Room 3: Add the Inductor in Series and Pull Out the Source Current

  • Now the inductor is in series with the new RC block, so add impedances directly: $$Z_{EQ}=Z_L+Z_{EQ1}=j500+(300-j900)=300-j400\,\Omega.$$
  • Convert that total to polar form because division by a phasor is easiest in polar language.
  • The magnitude is $$|Z_{EQ}|=\sqrt{300^2+(-400)^2}=500\,\Omega.$$
  • The angle is $$\theta=\tan^{-1}\left(\frac{-400}{300}\right)=-53.1^\circ,$$ so $$Z_{EQ}=500\angle-53.1^\circ\,\Omega.$$
  • Now divide: $$I=\frac{V_S}{Z_{EQ}}=\frac{100\angle0^\circ}{500\angle-53.1^\circ}=0.2\angle53.1^\circ\text{ A}.$$ In rectangular form, $$I=0.12+j0.16\text{ A}.$$

Room 4: Reopen the Parallel Chamber and Split into $$I_C$$ and $$I_R$$

  • The total current $$I$$ enters the RC parallel chamber and must split between the capacitor and resistor.
  • Use current division in admittance form. The capacitor-branch current is $$I_C=\frac{Y_C}{Y_C+Y_R}I,$$ where $$Y_C=\frac{1}{-j1000}=j0.001$$ and $$Y_R=\frac{1}{3000}=0.0003333.$$
  • This gives $$I_C=-0.06+j0.18\text{ A}=0.19\angle71.6^\circ\text{ A}.$$
  • The resistor current is what remains: $$I_R=I-I_C=(0.12+j0.16)-(-0.06+j0.18)=0.06-j0.02\text{ A}=0.0632\angle-18.4^\circ\text{ A}.$$

Room 5: Coat the Final Currents Back into Time Form

  • Keep the same angular frequency $$\omega=2000$$ when you return to the time domain.
  • $$i(t)=0.2\cos(2000t+53.1^\circ)\text{ A}$$
  • $$i_C(t)=0.19\cos(2000t+71.6^\circ)\text{ A}$$
  • $$i_R(t)=0.0632\cos(2000t-18.4^\circ)\text{ A}$$

Key Shortcut

This is a nested-circuit memory problem. The parallel RC chamber must be shrunk first, because only after that can the outside series path be seen cleanly. Solve the big source current first, then reopen the inner branch and split it.

Why The Total Current Comes Before The Branch Currents

The inductor sits before the parallel split, so the source current has to pass through the series path first. That is why the movie solves $$I$$ from the total impedance block before it ever tries to find $$I_C$$ or $$I_R.$$
