Exercise 8-19

Use Voltage and Current to Identify the Element

This page is a direct impedance-ratio movie. You convert the given voltage and current waveforms into phasors, divide to get the element impedance, convert that impedance into rectangular form, and then read the sign of the imaginary part to decide whether the unknown element is inductive or capacitive. The memory emphasis is that the sign of the reactive lane tells you the device family.

$$Z=50+j37.5\,\Omega,\qquad L=37.5 ext{ mH}$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Given
You are given the voltage waveform and the current waveform of one element.
Find
Find the impedance seen by the source or across the element.
Target
Then identify what physical element it is and determine its value.
Quick Data
Voltage Phasor
$$V=12.5\angle0^\circ\text{ V}$$
Current Phasor
$$I=0.2\angle-36.9^\circ\text{ A}$$
Element Type
Positive imaginary part means the element is inductive
Rooms: Full Solution

Room 1: Convert the Given Waveforms into Phasors

  • The voltage waveform $$v(t)=12.5\cos1000t ext{ V}$$ becomes $$V=12.5\angle0^\circ ext{ V}. $$
  • The current waveform $$i(t)=0.2\cos(1000t-36.9^\circ) ext{ A}$$ becomes $$I=0.2\angle-36.9^\circ ext{ A}. $$
  • Both use the same angular frequency, so the ratio $$V/I$$ is valid immediately.

Room 2: Divide to Find the Element Impedance

  • Use $$Z=V/I=\frac{12.5\angle0^\circ}{0.2\angle-36.9^\circ}. $$
  • Divide magnitudes: $$12.5/0.2=62.5.$$
  • Subtract angles: $$0^\circ-(-36.9^\circ)=36.9^\circ.$$
  • So $$Z=62.5\angle36.9^\circ\,\Omega.$$

Room 3: Convert the Impedance into Rectangular Form

  • Use $$Z=62.5(\cos36.9^\circ+j\sin36.9^\circ).$$
  • That gives $$Z=50+j37.5\,\Omega.$$
  • Now the real and reactive lanes are visible.

Room 4: Identify the Device from the Sign of the Imaginary Part

  • The imaginary part is positive, $$+j37.5, $$ so the element is inductive.
  • If the imaginary part had been negative, the element would have been capacitive instead.

Room 5: Convert the Inductive Reactance into an Inductance

  • For an inductor, $$X_L=\omega L.$$
  • So $$L=\frac{X_L}{\omega}=\frac{37.5}{1000}=0.0375 ext{ H}. $$
  • Therefore the unknown element is a $$37.5 ext{ mH}$$ inductor.

Key Shortcut

Use the ratio $$Z=V/I$$ first, and only after that ask what kind of element the sign of the imaginary lane represents.
