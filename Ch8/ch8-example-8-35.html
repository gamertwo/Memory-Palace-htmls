Example 8-35

Find the Average Power Delivered to the Load to the Right of the Interface

This is a power page, so the final quantity of interest is the average power absorbed by the real part of the equivalent load. The reactive part shapes current and phase but does not absorb average power.

$$Z_L=36+j202~\Omega,\qquad I_L=0.683\angle-66.9^\circ\text{ A},\qquad P=8.40\text{ W}$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Source
$$150\angle0^\circ\text{ V}$$ in series with $$50\ \Omega.$$
Load to the Right
A series $$j250\ \Omega$$ branch followed by the parallel combination of $$-j75\ \Omega$$ and $$100\ \Omega.$$
Goal
Find the average power delivered across the interface into that whole load network.
Rooms: Full Solution

Room 1: Reduce the Parallel Part of the Load First

  • The shunt part of the load is $$-j75\parallel100.$$
  • Using admittance, $$Y_p=\frac{1}{-j75}+\frac{1}{100}=0.01+j0.01333.$$
  • Invert to get the parallel impedance: $$Z_p=36-j48~\Omega.$$

Room 2: Add the Series Inductor to Get the Total Load

  • The inductor $$j250\ \Omega$$ is in series with that parallel equivalent.
  • So $$Z_L=j250+(36-j48)=36+j202~\Omega.$$

Meaning

The real part $$36\ \Omega$$ is the only part that can absorb average power. The imaginary part only stores and returns energy.

Room 3: Find the Current Delivered to the Load

  • The source sees $$50+Z_L=86+j202~\Omega.$$
  • So $$I_L=\frac{150\angle0^\circ}{86+j202}=0.2676-j0.6286\text{ A}=0.683\angle-66.9^\circ\text{ A}. $$

Room 4: Use Only the Resistive Part for Average Power

  • The real part of the equivalent load is $$R_L=36\ \Omega.$$
  • Using peak phasors, average power is $$P=\frac{1}{2}R_L|I_L|^2.$$
  • So $$P=\frac{1}{2}(36)(0.683)^2=8.40\text{ W}. $$

Room 5: Final Answer

  • Equivalent load: $$Z_L=36+j202~\Omega.$$
  • Load current: $$I_L=0.683\angle-66.9^\circ\text{ A}. $$
  • Average power: $$P=8.40\text{ W}. $$
