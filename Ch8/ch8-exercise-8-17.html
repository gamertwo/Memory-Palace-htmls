Exercise 8-17

Evaluate the Equivalent Impedance Without Tuning

This page reuses the Figure 8-25 formula, but now there is no resonance tuning. You simply substitute the given values into the equivalent-impedance formula and read both lanes of the answer. The memory emphasis is that the same parent formula can produce either a tuned real answer or a general complex answer depending on the frequency.

$$Z_{EQ}=500-j300\,\Omega$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Given
The Figure 8-25 values are fixed and the frequency is $1 ext{ krad/s}.$
Find
Find the equivalent impedance $Z_{EQ}$ of the circuit.
Target
This is a direct evaluation question, not a tuning question.
Quick Data
Given Data
$$\omega=1 ext{ krad/s},quad R=1 ext{ k}\Omega,quad L=200 ext{ mH},quad C=1\,\mu ext{F}$$
Real Part
$$R_{EQ}=500\,\Omega$$
Imaginary Part
$$X_{EQ}=-300\,\Omega$$
Rooms: Full Solution

Room 1: Bring in the Figure 8-25 Equivalent Formula

  • From the application example, use $$Z_{EQ}=\frac{R}{1+(\omega RC)^2}+j\left[\omega L-\frac{\omega R^2C}{1+(\omega RC)^2}\right].$$
  • This exercise is again a substitution page, but this time you keep both the real and imaginary lanes.

Room 2: Compute the Real Lane

  • First evaluate $$\omega RC=(1000)(1000)(10^{-6})=1.$$
  • So $$R_{EQ}=\frac{R}{1+(\omega RC)^2}=\frac{1000}{1+1}=500\,\Omega.$$

Room 3: Compute the Imaginary Lane

  • Now use $$X_{EQ}=\omega L-\frac{\omega R^2C}{1+(\omega RC)^2}. $$
  • The first term is $$\omega L=(1000)(0.2)=200.$$
  • The second term is $$\frac{(1000)(1000^2)(10^{-6})}{1+1}=500.$$
  • So $$X_{EQ}=200-500=-300\,\Omega.$$

Room 4: Reassemble the Complex Answer

  • Combine the two lanes: $$Z_{EQ}=500-j300\,\Omega.$$
  • The negative imaginary part tells you the input looks net capacitive at this operating frequency.

Room 5: State the Final Result for Both Methods

  • The textbook reports the same value for the hand solution and the Multisim check.
  • So for both parts, $$Z_{EQ}=500-j300\,\Omega.$$
  • This is the untuned version of the same parent circuit.

Key Shortcut

Use the same parent formula every time, but decide whether the question wants tuning or just direct evaluation.

Why This Flow Matters

This page helps the Chapter 8 system feel unified. Once the equivalent formula is memorized, many later problems become pattern-recognition and substitution instead of fresh derivations.
