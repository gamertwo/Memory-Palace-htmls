Exercise 8-43

Calculate the Maximum Average Power Available at the Interface

The right way to think about this problem is: first reduce everything left of the interface to a Thevenin source, then use conjugate matching to determine the load that extracts the most average power.

$$V_T=3.54\angle-135^\circ\text{ V},\qquad Z_T=25-j25~\Omega,\qquad P_{MAX}=62.5\text{ mW}$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Source Network
A current source $$0.1\angle0^\circ\text{ A}$$ feeds a network with a 50-$$\Omega$$ resistor, a series $$j100\ \Omega$$ inductor, and a shunt $$-j50\ \Omega$$ capacitor at the interface.
Goal
Find the maximum average power that could be delivered to a load connected at the interface.
Method
Find $$V_T$$ and $$Z_T,$$ then use conjugate matching.
Rooms: Full Solution

Room 1: Find the Open-Circuit Interface Voltage $$V_T$$

  • The source sees the resistor $$50\ \Omega$$ in parallel with the series reactive branch $$j100+(-j50)=j50\ \Omega.$$
  • So $$Z_{eq}=50\parallel j50=25+j25~\Omega.$$
  • The left node voltage is $$V_{left}=I_S Z_{eq}=(0.1\angle0^\circ)(25+j25)=2.5+j2.5\text{ V}. $$

Room 2: Step Through the Series Reactive Branch to the Interface

  • The branch current is $$I_{branch}=\frac{V_{left}}{j50}=0.05-j0.05\text{ A}. $$
  • The interface voltage is the capacitor voltage: $$V_T=I_{branch}(-j50)=-2.5-j2.5\text{ V}. $$
  • So $$V_T=3.54\angle-135^\circ\text{ V}. $$

Room 3: Turn Off the Current Source and Find $$Z_T$$

  • Turning off an independent current source means opening it.
  • Seen from the interface, $$Z_T=(-j50)\parallel(50+j100)=25-j25~\Omega.$$

Room 4: Apply the Maximum-Power Condition

  • The conjugate-matched load is $$Z_{L,MAX}=Z_T^*=25+j25~\Omega. $$
  • The maximum average power is $$P_{MAX}=\frac{|V_T|^2}{8R_T}. $$
  • Here $$|V_T|^2=12.5$$ and $$R_T=25\ \Omega,$$ so $$P_{MAX}=\frac{12.5}{8(25)}=62.5\text{ mW}. $$

Room 5: Final Answer

  • $$V_T=3.54\angle-135^\circ\text{ V},\qquad Z_T=25-j25~\Omega.$$
  • $$Z_{L,MAX}=25+j25~\Omega,\qquad P_{MAX}=62.5\text{ mW}. $$
