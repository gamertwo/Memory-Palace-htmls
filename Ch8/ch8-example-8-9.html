Example 8-9

Solve a Parallel Circuit with Admittance

This page is now a fuller parallel-circuit movie: catch the source current, pull out the branch impedances with $$\omega,$$ flip each branch into admittance language, combine the admittances, divide to get the common voltage, then let that one voltage stamp the branch currents and finally the waveforms.

$$i_s(t)=50\cos(2000t)\text{ mA},\qquad C=1\,\mu\text{F},\qquad R=500\,\Omega,\qquad L=0.5\text{ H}$$
Major GuideOpen in Memory Builder
Quick Data
Source Current
$$I_S=0.05\angle0^\circ\text{ A}$$
Branch Admittances
$$Y_1=2\times10^{-3}\angle90^\circ,\qquad Y_2=894\times10^{-6}\angle-63.4^\circ$$
Equivalent
$$Y_{EQ}=12.6\times10^{-4}\angle71.6^\circ\text{ S}$$
Rooms: Full Solution

Room 1: Convert the Source and Branch Impedances

  • The source current waveform gives $$I_S=0.05\angle0^\circ\text{ A}.$$
  • At $$\omega=2000,$$ the capacitor impedance is $$Z_C=\dfrac{1}{j\omega C}=-j500\,\Omega.$$
  • The series RL branch impedance is $$Z_{RL}=500+j\omega L=500+j1000\,\Omega.$$
  • The key memory point is that parallel problems are often easier only after you first write each branch in impedance language and then decide whether to flip to admittance.

Room 2: Flip the Parallel Branches into Admittances

  • The capacitor branch admittance is $$Y_1=\frac{1}{Z_C}=\frac{1}{-j500}=2\times10^{-3}\angle90^\circ\text{ S}.$$
  • The RL branch impedance has magnitude-angle form $$500+j1000=1118\angle63.4^\circ\,\Omega,$$ so its admittance is $$Y_2=\frac{1}{500+j1000}=894\times10^{-6}\angle-63.4^\circ\text{ S}.$$
  • This flip matters because parallel branches add naturally in admittance form, not impedance form.

Room 3: Add the Admittances and Solve the Common Voltage

  • Parallel admittances add directly, so $$Y_{EQ}=Y_1+Y_2.$$
  • In rectangular form this becomes $$(4+j12)\times10^{-4}\text{ S},$$ and in polar form $$Y_{EQ}=12.6\times10^{-4}\angle71.6^\circ\text{ S}.$$
  • Now the common voltage comes from dividing source current by total admittance: $$V=\frac{I_S}{Y_{EQ}}=\frac{0.05\angle0^\circ}{12.6\times10^{-4}\angle71.6^\circ}=39.7\angle-71.6^\circ\text{ V}.$$

Room 4: Use the Common Voltage to Build the Branch Currents

  • Both branches share the same voltage, so each current comes from $$I=YV.$$
  • For the capacitor branch, $$I_1=Y_1V=(2\times10^{-3}\angle90^\circ)(39.7\angle-71.6^\circ)=79.4\angle18.4^\circ\text{ mA}.$$
  • For the RL branch, $$I_2=Y_2V=(894\times10^{-6}\angle-63.4^\circ)(39.7\angle-71.6^\circ)=35.5\angle-135^\circ\text{ mA}.$$

Room 5: Coat the Final Waveforms

  • Now return the phasors to the time domain with the same $$\omega=2000.$$
  • $$v(t)=39.7\cos(2000t-71.6^\circ)\text{ V}$$
  • $$i_1(t)=79.4\cos(2000t+18.4^\circ)\text{ mA}$$
  • $$i_2(t)=35.5\cos(2000t-135^\circ)\text{ mA}$$

Key Shortcut

Series branches like impedance. Parallel branches like admittance. The movie becomes much easier once you flip into the right language before adding.

Why The Common Voltage Comes from Division

In a parallel circuit with a current source, the total admittance controls how much voltage is needed to support that source current. That is why the central move is $$V=I_S/Y_{EQ}$$ instead of a direct Ohm’s-law multiplication.
