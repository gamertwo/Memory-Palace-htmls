Application Example 8-14

Build the RC Low-Pass Filter Ratio as a Memory Movie

This question starts by asking for the capacitor output-to-source ratio in an RC series circuit, then asks for its magnitude as frequency changes. The real point is not just algebra. The point is to prove, from the ratio itself, why the circuit behaves as a low-pass filter and where the important turning point occurs.

$$\left|\frac{V_C}{V_S}\right|=\frac{1}{\sqrt{1+(\omega RC)^2}},\qquad \omega_c=\frac{1}{RC}$$
Major Guide Open in Memory Builder
What You Are Asked To Find
Given
An RC series circuit from Figure 8-29, with the output taken across the capacitor.
Find
First find the phasor ratio $$V_C/V_S.$$ Then find its magnitude as a function of frequency.
Meaning
After getting the formula, explain what it says physically: which frequencies appear strongly at the output, which ones shrink, and why.
Quick Data
Transfer Ratio
$$\frac{V_C}{V_S}=\frac{1}{1+j\omega RC}$$
Magnitude
$$\left|\frac{V_C}{V_S}\right|=\frac{1}{\sqrt{1+(\omega RC)^2}}$$
Cutoff Point
$$\omega_c=\frac{1}{RC}$$ and at that point $$\left|\frac{V_C}{V_S}\right|=\frac{1}{\sqrt2}\approx0.707$$
Rooms: Full Solution

Room 1: Understand What the Question Wants

  • The circuit output is measured across the capacitor, so the quantity of interest is not the resistor voltage, but $$V_C.$$
  • The first task is mathematical: write the ratio $$V_C/V_S.$$
  • The second task is interpretive: use that ratio to explain how the output changes with frequency.
  • So the whole question is really asking: how much of the source reaches the capacitor at low, middle, and high frequency?

Room 2: Write the Voltage Divider Ratio

  • Because this is a series RC circuit, use the impedance divider rule with the capacitor impedance $$Z_C=\frac{1}{j\omega C}.$$
  • That gives $$V_C=\frac{Z_C}{R+Z_C}V_S=\frac{1/j\omega C}{R+1/j\omega C}V_S.$$
  • Now multiply numerator and denominator by $$j\omega C$$ so the complex fraction becomes simpler.
  • The clean ratio is $$\frac{V_C}{V_S}=\frac{1}{1+j\omega RC}.$$ This is the main transfer function of the circuit.

Room 3: Take the Magnitude to Study Output Size

  • The transfer ratio contains $$j,$$ which tells you phase information, but filter behavior is usually discussed using magnitude.
  • Take the magnitude of $$\frac{1}{1+j\omega RC}.$$ The denominator magnitude is $$\sqrt{1+(\omega RC)^2}.$$
  • So the output magnitude ratio becomes $$\left|\frac{V_C}{V_S}\right|=\frac{1}{\sqrt{1+(\omega RC)^2}}.$$
  • This single expression now tells the full output trend as frequency changes.

Room 4: Read the Formula at the Key Frequencies

  • At very low frequency, $$\omega\approx0,$$ so $$\omega RC\approx0.$$ Then the magnitude becomes $$1.$$ This means the output is almost the same as the source.
  • At $$\omega=\frac{1}{RC},$$ the magnitude becomes $$\frac{1}{\sqrt2}\approx0.707.$$ This is the important boundary point.
  • At very high frequency, $$\omega RC$$ becomes very large, so the denominator grows large and the magnitude approaches $$0.$$
  • These three checkpoints summarize the entire curve: start near 1, drop to 0.707 at cutoff, then continue falling toward 0.

Room 5: Explain Why the Circuit is Low-Pass

  • As frequency increases, capacitor impedance decreases because $$|Z_C|=\frac{1}{\omega C}.$$
  • When the capacitor impedance is large, a large portion of the source voltage appears across the capacitor, so low-frequency output is strong.
  • When the capacitor impedance becomes small, less voltage appears across the capacitor, so high-frequency output becomes small.
  • That is why the circuit passes low frequencies well and attenuates high frequencies: it is a low-pass filter.

Room 6: State the Final Result Clearly

  • The required ratio is $$\frac{V_C}{V_S}=\frac{1}{1+j\omega RC}.$$
  • Its magnitude is $$\left|\frac{V_C}{V_S}\right|=\frac{1}{\sqrt{1+(\omega RC)^2}}.$$
  • The cutoff angular frequency is $$\omega_c=\frac{1}{RC}.$$
  • Therefore, the circuit is a low-pass filter: low frequencies appear strongly at the capacitor output, while high frequencies are reduced.

Key Shortcut

Understand the ask, write the divider ratio, take magnitude, test the key frequencies, then state why that proves low-pass behavior.

Why This Flow Matters

If you remember only isolated formulas, the question is easy to forget. If you remember the flow from what is being asked to what the final result means, the whole problem becomes reconstructable even after many days.
