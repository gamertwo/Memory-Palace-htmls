Example 8-26

Use Node Analysis to Find the Current $$I_x$$ in Figure 8-51

The source fixes the top node voltage immediately, so the only true unknowns are the two middle node voltages $$V_A$$ and $$V_B.$$ Once those are known, the inductor current follows directly from the voltage difference across $$j200\ \Omega.$$

$$V_A=70.4-j21.4\text{ V},\qquad V_B=38.6-j4.33\text{ V},\qquad I_x=0.180\angle-118^\circ\text{ A}$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Given
The source forces the top node to $$V_C=75\angle0^\circ\text{ V}.$$ The lower node is ground.
Unknowns
The middle bridge-node voltages $$V_A$$ and $$V_B.$$
Goal
Use those node voltages to find the inductor current $$I_x$$ through $$j200\ \Omega.$$
Rooms: Full Solution

Room 1: Notice Why Only Two Node Equations Are Needed

  • The source is connected directly between node $$C$$ and ground, so it forces $$V_C=75\angle0^\circ\text{ V}.$$
  • That means we do not need to write a node equation at $$C.$$ Its voltage is already known.
  • The only unknown node voltages are therefore $$V_A$$ and $$V_B.$$

Why This Matters

Node analysis gets easier whenever an independent voltage source fixes a node voltage directly.

Room 2: Write the KCL Equation at Node $$A$$

  • Current to ground through the capacitor is $$\frac{V_A}{-j120}.$$
  • Current to node $$B$$ through the inductor is $$\frac{V_A-V_B}{j200}.$$
  • Current to node $$C$$ through the 50-$$\Omega$$ resistor is $$\frac{V_A-V_C}{50}.$$
  • KCL gives $$\frac{V_A}{-j120}+\frac{V_A-V_B}{j200}+\frac{V_A-V_C}{50}=0.$$

Room 3: Write the KCL Equation at Node $$B$$

  • Current to ground through the 60-$$\Omega$$ resistor is $$\frac{V_B}{60}.$$
  • Current to node $$A$$ through the inductor is $$\frac{V_B-V_A}{j200}.$$
  • Current to node $$C$$ through the 50-$$\Omega$$ resistor is $$\frac{V_B-V_C}{50}.$$
  • KCL gives $$\frac{V_B}{60}+\frac{V_B-V_A}{j200}+\frac{V_B-V_C}{50}=0.$$

Room 4: Solve for $$V_A$$ and $$V_B$$

  • Substituting $$V_C=75\angle0^\circ$$ and solving the two equations gives $$V_A=70.4-j21.4\text{ V},\qquad V_B=38.6-j4.33\text{ V}.$$
  • These are the actual rectangular node voltages at the two middle bridge nodes.

Room 5: Use the Voltage Difference Across $$j200\ \Omega$$ to Find $$I_x$$

  • By Ohm's law, $$I_x=\frac{V_A-V_B}{j200}.$$
  • Subtract the node voltages first: $$V_A-V_B=31.8-j17.1\text{ V}.$$
  • Then $$I_x=\frac{31.8-j17.1}{j200}=-0.0852-j0.1588\text{ A}=0.180\angle-118^\circ\text{ A}.$$

Room 6: Final Answer

  • Node voltages: $$V_A=70.4-j21.4\text{ V},\qquad V_B=38.6-j4.33\text{ V}.$$
  • Bridge current: $$I_x=0.180\angle-118^\circ\text{ A}.$$
