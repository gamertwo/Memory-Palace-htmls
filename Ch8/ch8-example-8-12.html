Example 8-12

Choose the Capacitance that Makes the Input Purely Resistive

This page is another reactance-lane movie. You write the input impedance, convert the parallel branch to rectangular form, set the imaginary part to zero, solve for the capacitance, and then read off the real part that remains. The memory emphasis is that purely resistive does not mean zero impedance. It means zero imaginary part.

$$C=2\times10^{-6}\text{ F},\qquad \Re\{Z\}=50\,\Omega$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Given
The frequency is fixed and the capacitance is the design variable.
Find
Find the value of $C$ that makes the input impedance purely resistive.
Target
After that, find the real part of the input impedance for that chosen $C.$
Quick Data
Given Frequency
$$\omega=5\text{ krad/s}$$
Solved Capacitance
$$C=2\,\mu\text{F}$$
Real Input Part
$$\Re\{Z\}=50\,\Omega$$
Rooms: Full Solution

Room 1: Write the Input Impedance at the Given Frequency

  • At the specified frequency, $$Z=j\omega L+\frac{1}{\frac{1}{100}+j\omega C}. $$
  • With $$L=10 ext{ mH}$$ and $$\omega=5000,$$ the inductor contributes $$j50.$$
  • So $$Z=j50+\frac{100}{1+j(5\times10^5)C}. $$

Room 2: Convert the Parallel Block into Rectangular Form

  • Multiply the fraction by the conjugate of its denominator.
  • That gives $$Z=j50+\frac{100}{1+(5\times10^5C)^2}-j\frac{5\times10^7C}{1+(5\times10^5C)^2}. $$
  • Now the real and imaginary parts are visible in separate lanes.

Room 3: Set the Imaginary Part to Zero

  • A purely resistive input means the imaginary part of $$Z$$ must vanish.
  • So solve $$50-\frac{5\times10^7C}{1+(5\times10^5C)^2}=0.$$
  • This reduces to a quadratic with a repeated root, giving $$C=2\times10^{-6}\text{ F}. $$

Room 4: Compute the Real Part that Survives

  • Now place $$C=2\times10^{-6}$$ into the real part formula $$\Re\{Z\}=\frac{100}{1+(5\times10^5C)^2}. $$
  • Since $$(5\times10^5C)=1,$$ the denominator becomes $$2.$$
  • So $$\Re\{Z\}=50\,\Omega.$$

Room 5: State the Final Purely Resistive Input

  • The required capacitance is $$C=2\,\mu\text{F}. $$
  • For this value, the input impedance is purely real with $$\Re\{Z\}=50\,\Omega.$$
  • The big memory line is: kill the imaginary lane first, then read the real lane.

Key Shortcut

When the question says purely resistive, head directly for the imaginary part and set it to zero before doing anything else.

Why This Flow Matters

This page trains a very common Chapter 8 habit: separate real and imaginary parts early, because design and tuning questions usually target one lane first.

Solution Flow

Use a clean tuning route: write Z, split lanes, kill the imaginary lane, then read the real lane.
