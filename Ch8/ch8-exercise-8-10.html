Exercise 8-10

Solve the Same Series RLC Circuit with a Shifted Source

This exercise reuses the same circuit skeleton as Example 8-6, but now the source already carries a phase shift. The algebra is shorter because the reactances cancel, so the memorization movie focuses on the clean series current and the three element voltages shooting out at different angles.

$$v_s(t)=100\cos(2000t-45^\circ)\text{ V}$$ $$R=50\,\Omega,\qquad C=10\,\mu\text{F},\qquad L=25\,\text{mH}$$
Major GuideOpen in Memory Builder
Quick Data
Source Phasor
$$V_s=100\angle-45^\circ\text{ V}$$
Reactances at $$\omega=2000$$
$$Z_L=j50,\qquad Z_C=-j50$$
Key Simplification
The inductor and capacitor reactances cancel, so the equivalent impedance becomes purely resistive.
Rooms: Full Solution

Room 1: Convert Source and Impedances

  • Read the source into phasor form: $$V_s=100\angle-45^\circ\text{ V}.$$
  • At $$\omega=2000,$$ the passive impedances are $$Z_R=50,\; Z_L=j(2000)(0.025)=j50,\; Z_C=\dfrac{1}{j(2000)(10^{-5})}=-j50.$$
  • The inductor and capacitor have equal and opposite reactances.

Room 2: Collapse the Series Path

  • Series impedances add: $$Z_{EQ}=50+j50-j50.$$
  • The imaginary parts cancel exactly because $$+j50$$ and $$-j50$$ are equal in size and opposite in direction, so they destroy each other.
  • That leaves only the real part: $$Z_{EQ}=50\,\Omega.$$
  • If you want polar form, this is just $$50\angle0^\circ\,\Omega,$$ because the block lies completely on the positive real axis and has no imaginary tilt left.
  • That means the whole circuit behaves like a pure resistor at this operating frequency.

Room 3: Solve the Current

  • Use $$I=\dfrac{V_s}{Z_{EQ}}.$$
  • So $$I=\dfrac{100\angle-45^\circ}{50}=2\angle-45^\circ\text{ A}.$$
  • The current has the same angle as the source because the equivalent impedance is purely real.

Room 4: Find the Element Voltages

  • Use the same series current through all three elements.
  • $$V_R=Z_RI=50(2\angle-45^\circ)=100\angle-45^\circ\text{ V}$$
  • $$V_L=Z_LI=j50(2\angle-45^\circ)=100\angle45^\circ\text{ V}$$
  • $$V_C=Z_CI=-j50(2\angle-45^\circ)=100\angle-135^\circ\text{ V}$$

Room 5: Coat the Waveforms

  • Return to the time domain with the same $$\omega=2000.$$
  • $$i(t)=2\cos(2000t-45^\circ)\text{ A}$$
  • $$v_R(t)=100\cos(2000t-45^\circ)\text{ V}$$
  • $$v_L(t)=100\cos(2000t+45^\circ)\text{ V}$$
  • $$v_C(t)=100\cos(2000t-135^\circ)\text{ V}$$

Key Shortcut

When $$X_L$$ and $$X_C$$ are equal in magnitude and opposite in sign, they cancel in series. Then the current phasor is just the source phasor divided by the resistor.

Why The Three Voltages Point 90 Degrees Apart

The resistor voltage stays aligned with the current, the inductor voltage rotates +90 degrees from the current, and the capacitor voltage rotates -90 degrees from the current. That is why the three voltage phasors spread out so neatly in the phasor diagram.

Solution Flow

Walk this as one connected memory-palace route: the source becomes a phasor, $$\omega$$ pulls out all the $$Z$$ values, the big $$Z$$ block forms, the current is pulled out from that block, then the three voltage phasors stamp out, and finally $$\omega$$ coats everything back into waveforms.
