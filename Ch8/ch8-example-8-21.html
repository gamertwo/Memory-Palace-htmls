Example 8-21

Use Source Transformations When Both Sources Share One Frequency

This example solves the same same-frequency superposition idea in a different style. Instead of turning one source off at a time, you transform each series source into a Norton form, combine the parallel current sources, reduce the passive parallel network, and then recover the output voltage in one clean phasor step.

$$V_R=227\angle-47.9^\circ\text{ V},\qquad v_R(t)=227\cos(5000t-47.9^\circ)\text{ V}$$

Quick Data
Source Currents
$$I_{eq1}=-j10\text{ A},\qquad I_{eq2}=2-j3.46\text{ A}$$
Combined Source
$$I_{eq}=2-j13.46=13.6\angle-81.5^\circ\text{ A}$$
Equivalent Impedance
$$Z_{eq}=16.6\angle33.7^\circ~\Omega$$
Rooms: Full Solution

Room 1: Transform Each Series Source into a Current Source

  • Convert the left source branch and the right source branch into Norton forms.
  • This gives $$I_{eq1}=-j10\text{ A}$$ and $$I_{eq2}=2-j3.46\text{ A}.$$
  • Now both sources live naturally in the same parallel picture.

Why This Step

Source transformation is chosen here because the circuit becomes a parallel-current-source problem, and parallel current sources combine much more easily than mixed source forms.

Room 2: Combine the Parallel Current Sources

  • Add the source currents directly because they are now on the same branch framework.
  • $$I_{eq}=I_{eq1}+I_{eq2}=2-j13.46=13.6\angle-81.5^\circ\text{ A}.$$
  • The two physical sources have collapsed into one equivalent current source.

Why This Step

Parallel current sources are one of the cleanest places to use phasor addition. The transformation was worthwhile because it created this easy combination step.

Room 3: Reduce the Four Passive Elements in Parallel

  • The resistor, capacitor, and inductive branches are all connected in parallel.
  • Reducing them gives $$Z_{eq}=16.6\angle33.7^\circ~\Omega.$$
  • This equivalent impedance now sits across the combined current source.

Why This Step

Once everything is in one parallel frame, both the source and the passive network can be compressed. That is the whole structural advantage of the transformation route.

Room 4: Recover the Output Voltage

  • The output voltage across the equivalent network equals the resistor voltage $$V_R.$$
  • Use the combined current source and equivalent impedance to get $$V_R=227\angle-47.9^\circ\text{ V}.$$
  • This matches the same-frequency superposition result found by the earlier method.

Why This Step

This is the check that both methods are equivalent. Different reduction styles should still land on the same port voltage when the algebra is done correctly.

Room 5: Write the Time-Domain Output

  • Because both sources operate at $$\omega=5000\text{ rad/s},$$ one final phasor is enough.
  • So the output waveform is $$v_R(t)=227\cos(5000t-47.9^\circ)\text{ V}.$$
  • The same frequency is what permits the single clean cosine answer.

Why This Step

This is the same big rule as Example 8-16: same-frequency responses can stay in the phasor world all the way to the end.
