Design Example 8-7

Design a Voltage Divider for a Target Output

This page turns a waveform target into a design route. The source stays in cosine-reference form, the output sine is converted into cosine-reference form first, the output phasor is built, the divider formula is locked, then the equation is rearranged until one impedance is written in terms of the other and finally converted into real components.

$$v_s(t)=15\cos(2000t)\text{ V},\qquad v_o(t)=2\sin(2000t)\text{ V}$$ $$V_O=\frac{Z_2}{Z_1+Z_2}V_S$$
Major GuideOpen in Memory Builder
Quick Data
Input Phasor
$$V_S=15\angle0^\circ=15+j0$$
Target Output
$$V_O=2\angle-90^\circ=-j2$$
Design Move
Lock the divider formula, solve for $$Z_1$$ in terms of $$Z_2,$$ then choose one practical impedance and pull out the real components.
Rooms: Full Solution

Room 1: Convert Input and Output to Phasors

  • The input is already in cosine-reference form, so it stays as it is: $$v_s(t)=15\cos(2000t)\;\longrightarrow\;V_S=15\angle0^\circ=15+j0.$$
  • The desired output is not in cosine-reference form, so convert it first using the bridge formula $$\sin(\omega t)=\cos(\omega t-90^\circ).$$
  • That gives $$2\sin(2000t)=2\cos(2000t-90^\circ).$$
  • Now the output can be read as a phasor: $$V_O=2\angle-90^\circ=-j2.$$

Room 2: Lock the Divider Formula and Substitute the Phasors

  • The formula to memorize is the divider law: $$V_O=\dfrac{Z_2}{Z_1+Z_2}V_S.$$
  • Push the phasor values into it: $$-j2=\frac{Z_2}{Z_1+Z_2}(15+j0).$$
  • This is the key design equation. From here the whole problem becomes rearranging the divider until one impedance is written in terms of the other.

Room 3: Rearrange Until $$Z_1=(\cdots)Z_2$$

  • Start from $$-j2=\dfrac{Z_2}{Z_1+Z_2}(15+j0).$$
  • Multiply both sides by $$Z_1+Z_2,$$ then divide by $$-j2,$$ so the unknown impedance block stands alone.
  • That gives $$Z_1=\frac{15+j2}{-j2}Z_2.$$
  • Simplify the coefficient: $$\frac{15+j2}{-j2}=-1+j7.5.$$
  • So the clean design condition is $$Z_1=(-1+j7.5)Z_2.$$

Room 4: Choose One $$Z_2$$ and Let It Generate $$Z_1$$

  • Pick a practical capacitive block: $$Z_2=-j1000\,\Omega.$$
  • Substitute that into the design condition: $$Z_1=(-1+j7.5)(-j1000)=7500+j1000\,\Omega.$$
  • The equation has now pulled out two physical pieces from $$Z_1$$: a real resistor part $$7500$$ and an inductive reactance part $$+j1000.$$
  • So $$Z_1$$ can be realized as a 7500-ohm resistor in series with an inductor whose reactance is $$+1000\,\Omega.$$

Room 5: Use $$\omega$$ to Pull Out the Component Values

  • Because $$\omega=2000,$$ the inductive piece $$+j1000$$ means $$\omega L=1000,$$ so $$L=1000/2000=0.5\text{ H}.$$
  • The capacitive block $$Z_2=-j1000$$ means $$\dfrac{1}{\omega C}=1000,$$ so $$C=\dfrac{1}{2000\times1000}=0.5\,\mu\text{F}.$$
  • The resistor value is already pulled directly from the real part of $$Z_1,$$ so $$R=7500\,\Omega.$$
  • So one valid design is $$Z_1=7500+j1000$$ and $$Z_2=-j1000,$$ implemented with a 7.5-kΩ resistor, a 0.5-H inductor, and a 0.5-μF capacitor.

Key Shortcut

Design problems start by turning the output requirement into a phasor target. Once the target is in phasor form, the rest is algebra on the divider ratio.

Why The Output Becomes $$-j2$$

Sine is not the default phasor reference in this chapter, so the first job is to rewrite it with the bridge formula $$\sin(\omega t)=\cos(\omega t-90^\circ).$$ That move translates the design target into the cosine-based phasor language the divider formula understands.

Solution Flow

Walk this as one connected design-palace route in the style of the memory forums: keep cosine waveforms that already fit, convert the one that does not, form the output phasor, lock the divider law, rearrange to $$Z_1=(\cdots)Z_2,$$ choose a practical $$Z_2,$$ then let $$\omega$$ pull out the resistor, inductor, and capacitor values.

Fire Hall: Feed One $$Z$$ into the Other

Omega Coat Exit: Turn Reactances into Components

The $$\omega=2000$$ wheel and the coat wrap the reactance blocks into components: $$\omega L=1000\Rightarrow L=0.5\text{ H}$$ and $$1/(\omega C)=1000\Rightarrow C=0.5\,\mu\text{F}.$$ The final worn design is $$Z_1=7500+j1000$$ and $$Z_2=-j1000.$$
