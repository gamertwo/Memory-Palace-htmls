Example 8-15

Use the Unit Output Method to Solve the Figure 8-30 Phasor Circuit

This page is a backward-solving movie. Instead of starting from the source, you assume the output node is one clean unit phasor, use that assumption to walk backward through the network, recover the source phasor and input current for that unit case, and then scale everything to the real source. The memory emphasis is that the unit output method turns a multi-step circuit into one reusable proportionality run.

$$V_C=1+j0,\qquad Z_{IN}=75+j25\,\Omega,\qquad K=\frac{V_C}{V_S}=-0.4-j0.2$$

What You Are Asked To Find
Given
Use the unit output method for the circuit in Figure 8-30 with $$V_S=10\angle0^\circ\text{ V}.$$
Find
Find the input impedance $$Z_{IN},$$ the input current $$I_1,$$ the output voltage $$V_C,$$ and the current $$I_3.$$
Method
Assume a unit output first, solve the whole network once, then use proportionality to scale to the real source.
Quick Data
Unit Output Assumption
$$V_C=1+j0\text{ V}$$
Recovered Input Pair
$$V_S=-2+j1\text{ V},\qquad I_1=-0.02+j0.02\text{ A}$$
Key Results
$$Z_{IN}=75+j25\,\Omega,\qquad K=\frac{V_C}{V_S}=-0.4-j0.2$$
Rooms: Full Solution

Room 1: Assume a Unit Output at the Target Node

  • The unit output method starts by forcing the desired output to a simple trial value: $$V_C=1+j0\text{ V}.$$
  • This is not the final answer. It is a temporary probe value that lets the whole network reveal its ratios.
  • Once the circuit is solved for this unit case, the real source can scale every result cleanly.

Simple Meaning

We are starting with a fake output on purpose. The question here is: if the output were exactly 1 V, what would the rest of the circuit have to do?

Room 2: Use the Output Node to Recover $$I_3$$ and $$V_B$$

  • At the right resistor, Ohm's law gives $$I_3=\frac{V_C}{50}=\frac{1+j0}{50}=0.02+j0\text{ A}.$$
  • Now walk backward through the branch from node $$C$$ to node $$B.$$ The book's KVL step gives $$V_B=V_C+(j100)I_3.$$
  • So $$V_B=1+j0+(j100)(0.02)=1+j2\text{ V}.$$
  • The output side has now given you both the branch current $$I_3$$ and the inner node voltage $$V_B.$$

Simple Meaning

Since we know the output voltage and the resistor value, we can get the output current immediately. Then we step one component backward to find the voltage at the previous node.

Room 3: Use $$V_B$$ to Recover $$I_2$$ and Then $$I_1$$

  • At the shunt branch, use Ohm's law again: $$I_2=\frac{V_B}{-j50}=\frac{1+j2}{-j50}=-0.04+j0.02\text{ A}.$$
  • Now apply KCL at node $$B.$$ The input current must split into the two outgoing currents.
  • So $$I_1=I_2+I_3=(-0.04+j0.02)+(0.02+j0)= -0.02+j0.02\text{ A}.$$
  • This is the input current produced by the unit-output assumption.

Simple Meaning

Node B is a split point. One current goes down, one goes right, so the current coming in from the left must be enough to feed both branches.

Room 4: Build the Source Phasor and the Input Impedance

  • Walk backward through the left series branch using KVL: $$V_S=(50+j100)I_1+V_B.$$
  • Substitute the unit-case values: $$V_S=(50+j100)(-0.02+j0.02)+(1+j2)=-2+j1\text{ V}.$$
  • Now divide the unit-case source by the unit-case input current to get the input impedance.
  • $$Z_{IN}=\frac{V_S}{I_1}=\frac{-2+j1}{-0.02+j0.02}=75+j25\,\Omega$$

Simple Meaning

Now we know what source voltage would be needed to create that trial output. Once we have both source voltage and input current, we can see what impedance the whole circuit presents at the input.

Room 5: Turn the Unit Run into a Scaling Factor

  • Because the trial run used $$V_C=1,$$ the output-to-input proportionality factor is $$K=\frac{V_C}{V_S}=\frac{1}{-2+j1}.$$
  • Rationalizing the denominator gives $$K=\frac{-2-j1}{5}=-0.4-j0.2.$$
  • This is the shortcut prize of the method: once $$K$$ and $$Z_{IN}$$ are known, every real-source answer becomes a one-step scaling problem.

Simple Meaning

This is the payoff. We solved the circuit once in a fake 1 V output case, and that gives us a reusable ratio that connects source voltage to output voltage.

Room 6: Scale Everything to the Real Source $$10\angle0^\circ$$

  • Use the actual source $$V_S=10\angle0^\circ\text{ V}.$$ Then $$V_C=KV_S=(-0.4-j0.2)(10)=-4-j2\text{ V}=4.47\angle-153^\circ\text{ V}.$$
  • The input current comes from the input impedance: $$I_1=\frac{V_S}{Z_{IN}}=\frac{10}{75+j25}=0.12-j0.04\text{ A}=0.126\angle-18.4^\circ\text{ A}.$$
  • The output-branch current is $$I_3=\frac{V_C}{50}=\frac{-4-j2}{50}=-0.08-j0.04\text{ A}=0.0894\angle-153^\circ\text{ A}.$$
  • So the required answers are $$Z_{IN}=75+j25\,\Omega,$$ $$I_1=0.126\angle-18.4^\circ\text{ A},$$ $$V_C=4.47\angle-153^\circ\text{ V},$$ and $$I_3=0.0894\angle-153^\circ\text{ A}.$$

Simple Meaning

The fake run is over here. We now plug in the real source and scale the answers, because in a linear circuit everything grows or shrinks together.

Key Shortcut

Assume unit output, walk backward to recover the source and input current, form $$Z_{IN}$$ and $$K,$$ then scale to the real source.

Why This Flow Matters

The unit output method is powerful because it turns one trial solve into a reusable map. Instead of solving the whole circuit again for every new source, you solve the structure once and then scale the answers.
