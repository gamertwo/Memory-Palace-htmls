Exercise 8-28

Repeat the Source-Transformation Movie at a New Frequency

This page uses the exact same circuit and method as Example 8-21, but the operating frequency changes from $$5000\text{ rad/s}$$ to $$20{,}000\text{ rad/s}.$$ That means the topology stays the same while every reactive impedance must be rebuilt from the element values before any source transformation is trusted.

$$v_R(t)=9.196\cos(20{,}000t-163.8^\circ)\text{ V}$$
Major GuideOpen in Memory Builder
What You Are Asked To Find
Known from Example 8-21
At $$\omega=5000\text{ rad/s},$$ the reactances were $$j10,\ j30,$$ and $$-j10\ \Omega.$$
New Condition
Now both sources operate at $$\omega=20\text{ krad/s}=20{,}000\text{ rad/s}.$$
Method
Rebuild $$L_1, L_2,$$ and $$C,$$ recompute the impedances, transform the sources again, combine currents, reduce the parallel network, and then use $$V=IZ.$$
Rooms: Full Solution

Room 1: Recover the Actual Element Values from Example 8-21

  • Example 8-21 was solved at $$\omega=5000\text{ rad/s}.$$ At that frequency the reactive impedances were $$j10,\ j30,$$ and $$-j10\ \Omega.$$
  • For an inductor, $$Z_L=j\omega L.$$ So the first inductor is $$L_1=\frac{10}{5000}=0.002\text{ H}=2\text{ mH}.$$
  • The second inductor is $$L_2=\frac{30}{5000}=0.006\text{ H}=6\text{ mH}.$$
  • For a capacitor, $$Z_C=\frac{1}{j\omega C}=-\frac{j}{\omega C}.$$ Since its magnitude was $$10\ \Omega,$$ $$\frac{1}{\omega C}=10\quad\Rightarrow\quad C=\frac{1}{5000\cdot10}=2\times10^{-5}\text{ F}=20\,\mu\text{F}.$$

Why We Do This First

The old values $$j10, j30,$$ and $$-j10$$ were not permanent component properties. They were frequency-specific impedances. To move to a new frequency, we must first recover the actual element values.

Room 2: Recompute the New Reactive Impedances at $$\omega=20{,}000\text{ rad/s}$$

  • For the first inductor, $$Z_{L1}=j\omega L_1=j(20{,}000)(0.002)=j40\ \Omega.$$
  • For the second inductor, $$Z_{L2}=j\omega L_2=j(20{,}000)(0.006)=j120\ \Omega.$$
  • For the capacitor, $$Z_C=\frac{1}{j\omega C}=-\frac{j}{\omega C}=-\frac{j}{(20{,}000)(20\times10^{-6})}=-j2.5\ \Omega.$$
  • The resistor remains unchanged at $$20\ \Omega$$ because resistance does not depend on frequency.

Where the New Numbers Come From

Each inductive reactance became four times larger because the frequency became four times larger. The capacitor reactance magnitude became four times smaller for the same reason.

Room 3: Transform the Left Voltage Source into a Norton Source

  • The left branch still uses the source-transformation rule $$I_{eq1}=\frac{V_{s1}}{Z_{s1}}.$$
  • The left source is $$100\angle0^\circ\text{ V}$$ in series with $$j40\ \Omega,$$ so $$I_{eq1}=\frac{100\angle0^\circ}{40\angle90^\circ}=2.5\angle-90^\circ\text{ A}.$$
  • In rectangular form that is $$I_{eq1}=-j2.5\text{ A}.$$

Magnitude Origin

The magnitude $$2.5\text{ A}$$ comes from $$100/40.$$ The source voltage stayed the same while the inductor reactance increased from $$10\ \Omega$$ to $$40\ \Omega,$$ so the source current became smaller.

Phase Origin

The angle is $$0^\circ-90^\circ=-90^\circ$$ because we divided by an inductive impedance with angle $$+90^\circ.$$ That is why the result points straight down on the complex plane.

Room 4: Transform the Right Voltage Source into a Norton Source

  • The right source is $$120\angle30^\circ\text{ V}$$ in series with $$j120\ \Omega.$$ So $$I_{eq2}=\frac{120\angle30^\circ}{120\angle90^\circ}=1\angle-60^\circ\text{ A}.$$
  • Convert that to rectangular form because the current sources must be added: $$I_{eq2}=1(\cos-60^\circ+j\sin-60^\circ)=0.5-j0.866\text{ A}.$$

Why the Magnitude Becomes 1 A

The magnitude is simply $$120/120=1.$$ The source magnitude and series reactance magnitude happen to match exactly at this new frequency.

Why the Phase Is $$-60^\circ$$

The source starts at $$30^\circ.$$ Dividing by an impedance at $$90^\circ$$ subtracts $$90^\circ,$$ giving $$30^\circ-90^\circ=-60^\circ.$$

Room 5: Add the Parallel Norton Currents

  • Now both sources are parallel current sources, so add them in rectangular form: $$I_{eq}=I_{eq1}+I_{eq2}=(-j2.5)+(0.5-j0.866).$$
  • Combine real parts and imaginary parts separately: $$I_{eq}=0.5-j3.366\text{ A}.$$
  • Convert to polar form for later multiplication.

Magnitude Origin

$$|I_{eq}|=\sqrt{0.5^2+(-3.366)^2}=3.403\text{ A}.$$ That is where the magnitude $$3.403$$ comes from.

Phase Origin

$$\angle I_{eq}=\tan^{-1}\left(\frac{-3.366}{0.5}\right)=-81.55^\circ.$$ The real part is positive and the imaginary part is negative, so the phasor lies in the fourth quadrant.

Combined Current

$$I_{eq}=3.403\angle-81.55^\circ\text{ A}. $$

Room 6: Reduce the Parallel Passive Network to One Equivalent Impedance

  • The four passive branches are in parallel, so it is easiest to add their admittances: $$\frac{1}{Z_{eq}}=\frac{1}{20}+\frac{1}{-j2.5}+\frac{1}{j40}+\frac{1}{j120}.$$
  • Convert each term: $$\frac{1}{20}=0.05,\qquad \frac{1}{-j2.5}=+j0.4,\qquad \frac{1}{j40}=-j0.025,\qquad \frac{1}{j120}=-j0.00833.$$
  • So the equivalent admittance is $$Y_{eq}=0.05+j0.36667\text{ S}. $$
  • Invert that admittance to get the equivalent impedance: $$Z_{eq}=\frac{1}{0.05+j0.36667}=0.365-j2.677~\Omega.$$

Why the Imaginary Part Is Negative

The capacitor contributes a much larger positive susceptance than the two inductors contribute negative susceptance, so the overall admittance is strongly positive imaginary. When that admittance is inverted, the equivalent impedance becomes strongly negative imaginary, which means the whole parallel network looks net capacitive.

Polar Form of the Equivalent Impedance

$$|Z_{eq}|=\sqrt{0.365^2+(-2.677)^2}=2.702~\Omega$$ $$\angle Z_{eq}=\tan^{-1}\left(\frac{-2.677}{0.365}\right)=-82.23^\circ$$ Therefore, $$Z_{eq}=2.702\angle-82.23^\circ~\Omega.$$

Room 7: Use $$V_R=I_{eq}Z_{eq}$$ to Get the Output Phasor

  • The resistor voltage equals the voltage across the entire parallel network, so $$V_R=I_{eq}Z_{eq}.$$
  • Substitute the polar forms: $$V_R=(3.403\angle-81.55^\circ)(2.702\angle-82.23^\circ).$$

Magnitude Origin

$$|V_R|=(3.403)(2.702)=9.196\text{ V}. $$ That is where the output magnitude comes from.

Phase Origin

$$\angle V_R=-81.55^\circ+(-82.23^\circ)=-163.78^\circ.$$ In polar multiplication, the angles add. Both factors already had negative angles, so the result rotates even farther clockwise.

Final Output Phasor

$$V_R=9.196\angle-163.8^\circ\text{ V}. $$

Room 8: Return to the Time Domain

  • The output phasor is $$V_R=9.196\angle-163.8^\circ\text{ V}.$$
  • The common angular frequency is the new operating frequency, $$\omega=20{,}000\text{ rad/s}. $$
  • So the steady-state resistor voltage is $$v_R(t)=9.196\cos(20{,}000t-163.8^\circ)\text{ V}. $$

Final Answer

$$v_R(t)=9.196\cos(20{,}000t-163.8^\circ)\text{ V}$$

Compact Exam-Style Working

$$L_1=2\text{ mH},\quad L_2=6\text{ mH},\quad C=20\,\mu\text{F}$$ $$Z_{L1}=j40,\quad Z_{L2}=j120,\quad Z_C=-j2.5$$ $$I_{eq1}=100/j40=-j2.5$$ $$I_{eq2}=120\angle30^\circ/j120=1\angle-60^\circ=0.5-j0.866$$ $$I_{eq}=0.5-j3.366=3.403\angle-81.55^\circ$$ $$Z_{eq}=\left(\frac{1}{20}+\frac{1}{-j2.5}+\frac{1}{j40}+\frac{1}{j120}\right)^{-1}=0.365-j2.677=2.702\angle-82.23^\circ$$ $$V_R=I_{eq}Z_{eq}=9.196\angle-163.8^\circ\text{ V}$$ $$v_R(t)=9.196\cos(20{,}000t-163.8^\circ)\text{ V}$$
