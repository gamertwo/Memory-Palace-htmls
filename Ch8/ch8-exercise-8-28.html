Exercise 8-28

Repeat the Source-Transformation Movie at a New Frequency

This exercise keeps the same network idea as Example 8-21 but changes the operating frequency to $$\omega=20\text{ krad/s}.$$ The memory emphasis is that all reactive values must be recomputed at the new frequency before you try to combine anything.

$$v_R(t)=9.196\cos(20{,}000t-163.8^\circ)\text{ V}$$
Major GuideOpen in Memory Builder
Rooms: Full Solution

Room 1: Recompute the Reactive Elements at the New Frequency

  • The component values are the same as in Example 8-21, but $$\omega$$ is now different.
  • That means $$j\omega L$$ and $$1/(j\omega C)$$ must be recalculated before any transformation or reduction.
  • The frequency change is the first thing to respect.

Why This Step

Reactive circuits are frequency-sensitive. If you reuse the old impedances, the whole rest of the solution becomes meaningless.

Room 2: Repeat the Same Structural Movie

  • Transform the series sources into current sources.
  • Combine the parallel source currents and reduce the passive parallel network.
  • The circuit logic is unchanged even though the numbers change.

Why This Step

This is the important memory point: a new frequency changes the values, not the method. The structural movie stays the same.

Room 3: State the New Output Waveform

  • The resulting resistor voltage phasor corresponds to the waveform
  • $$v_R(t)=9.196\cos(20{,}000t-163.8^\circ)\text{ V}.$$
  • This is the final same-frequency output at the new operating point.

Why This Step

The final waveform is smaller and shifted because the reactive network responds differently at the new frequency. That is the physical effect of recomputing the impedances correctly.
