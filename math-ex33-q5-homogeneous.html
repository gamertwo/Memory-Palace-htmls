Exercise 3.3 Question 5

Rewrite the equation in $\dfrac{dy}{dx}$ form, apply $y=vx$, then separate and integrate using partial fractions.

$$\frac{dy}{dx}+\frac{x-2y}{2x-y}=0$$
Rooms

Room 1: Put in Ratio Form

  • First isolate $\dfrac{dy}{dx}$:
  • $$\frac{dy}{dx}=-\frac{x-2y}{2x-y}=\frac{2y-x}{2x-y}.$$
  • Now express it using $\dfrac{y}{x}$:
  • $$\frac{dy}{dx}=\frac{2\left(\frac{y}{x}\right)-1}{2-\left(\frac{y}{x}\right)}.$$

Room 2: Use $y=vx$

  • Since the right side depends only on $\dfrac{y}{x}$, set
  • $$y=vx \qquad \Rightarrow \qquad \frac{dy}{dx}=v+x\frac{dv}{dx}.$$
  • Then
  • $$v+x\frac{dv}{dx}=\frac{2v-1}{2-v}.$$

Room 3: Simplify the v-Equation

  • Move $v$ across:
  • $$x\frac{dv}{dx}=\frac{2v-1}{2-v}-v=\frac{v^2-1}{2-v}.$$
  • Hence
  • $$\frac{2-v}{v^2-1}\,dv=\frac{dx}{x}.$$

Room 4: Partial Fractions

  • Resolve:
  • $$\frac{2-v}{v^2-1}=\frac{2-v}{(v-1)(v+1)}=\frac{1}{2(v-1)}-\frac{3}{2(v+1)}.$$

Room 5: Integrate

  • Integrate both sides:
  • $$\int \left[\frac{1}{2(v-1)}-\frac{3}{2(v+1)}\right]dv=\int \frac{dx}{x}.$$
  • $$\frac{1}{2}\ln|v-1|-\frac{3}{2}\ln|v+1|=\ln|x|+C.$$
  • Multiply by $2$:
  • $$\ln|v-1|-3\ln|v+1|=2\ln|x|+C.$$

Room 6: Back-Substitute

  • Compress the logarithms:
  • $$\ln\left|\frac{v-1}{(v+1)^3}\right|=\ln|Cx^2|.$$
  • So
  • $$\frac{v-1}{(v+1)^3}=Cx^2.$$
  • Put back $$v=\frac{y}{x}:$$
  • $$\frac{\frac{y}{x}-1}{\left(\frac{y}{x}+1\right)^3}=Cx^2.$$
  • Simplifying gives
  • $$\boxed{\frac{y-x}{(x+y)^3}=C} \qquad \Rightarrow \qquad \boxed{y-x=C(x+y)^3}.$$
Final Answer

The homogeneous substitution leads to $$\boxed{\frac{y-x}{(x+y)^3}=C},$$ which is usually written as $$\boxed{y-x=C(x+y)^3}.$$
