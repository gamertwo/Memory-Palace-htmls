Example 7-8

This page keeps the same palace method as the main lesson, but anchored to this exact problem so you can rehearse the move sequence without bouncing back to pattern-only notes.

$$v_C(t)=20e^{-200t}-10\text{ V}$$
Recognize

The exponential term means a first-order natural response is present. This is still the same RC story.

Flip

$k=200$, so $\tau=\frac{1}{200}=5\text{ ms}$. The exponent tells you the time constant immediately.

Freeze / Melt

At $t=0$, $v_C(0)=10\text{ V}$. As $t\to\infty$, the exponential dies and the response settles at $-10\text{ V}$.

Blueprint

The forced target is $-10\text{ V}$, so the governing form is $$\frac{1}{200}\dot v_C+v_C=-10u(t).$$

Room-By-Room Walkthrough

Room I: Recognize the Pattern

Spot the single decaying exponential. That is your signal that the response belongs to the first-order RC family.

Room II: Flip the Exponent

Read the exponent as $e^{-t/\tau}$ in disguise. Since $e^{-200t}=e^{-t/\tau}$, the only matching value is $\tau=1/200$ seconds.

Room III: Freeze and Melt

  • Freeze at $t=0$: $20(1)-10=10\text{ V}$.
  • Melt at $t\to\infty$: $20(0)-10=-10\text{ V}$.

Room IV: Split the Response

Separate the expression into destination plus decaying memory:

Forced part: $-10\text{ V}$

Natural part: $20e^{-200t}$

Room V: Rebuild the ODE

Use the standard first-order form $\tau\dot x + x = x(\infty)u(t)$ with $\tau=1/200$ and $x(\infty)=-10$.

That gives $$\frac{1}{200}\dot v_C+v_C=-10u(t).$$

Memory Cues
Cue 1

Exponent coefficient = reciprocal of time constant.

Cue 2

The constant outside the exponential is not always the final value. Only the non-decaying term survives the melt.

Cue 3

If the final value is negative, the source/forcing side of the ODE is negative too.

Active Recall
What is the first move when you see $20e^{-200t}-10$?
Identify the decaying exponential and classify it as first-order RC behavior.
Which term becomes the final value?
The standalone constant term, because the exponential collapses to zero as time grows.
What should you remember if the answer choices show $\tau$ instead of $k$?
Flip the exponent coefficient: $k=200$ means $\tau=1/200$ seconds.
