28-8 Sample Problem

Magnetic Force on a Wire Carrying Current

This page keeps the sample problem route short. Use the wire-force formula, set the magnetic force equal to the wire’s weight, and solve for the magnetic field needed to suspend the wire. The main idea is simple equilibrium: upward magnetic force balances downward gravity.

$$F_B=iLB\sin\phi,\qquad F_B=mg,\qquad B=\frac{mg}{iL}$$
Chapter GuideOpen in Memory Builder
What You Are Asked To Find
Given
A horizontal wire carries current $$i=28\,\text{A}$$ and has linear mass density $$46.6\,\text{g/m}. $$
Find
Find the magnetic field needed to suspend the wire.
Core Trick
Suspended means magnetic force balances weight.
Quick Data
Force Formula
$$F_B=iLB\sin\phi$$
Weight
$$F_g=mg$$
Linear Density
Use $$m/L$$ so the length cancels cleanly
Rooms: Full Solution

Room 1: Choose the Field Direction for Maximum Force

  • To minimize the required field magnitude, make the force as large as possible for a given $$B.$$
  • That means choose $$\phi=90^\circ,$$ so the field is perpendicular to the wire.
  • Then $$F_B=iLB.$$

Room 2: Set Magnetic Force Equal to Weight

  • For suspension, the upward magnetic force must match the downward weight.
  • So $$iLB=mg. $$
  • Solving for the field gives $$B=\dfrac{mg}{iL}. $$

Room 3: Replace Mass with Linear Density

  • Write the wire mass as $$m=(m/L)L. $$
  • Then $$B=\dfrac{(m/L)Lg}{iL}=\dfrac{(m/L)g}{i}. $$
  • This is the cleanest form for substitution because the wire length cancels.

Room 4: Substitute the Sample Values

  • Convert $$46.6\,\text{g/m}$$ to SI units: $$46.6\times10^{-3}\,\text{kg/m}. $$
  • Then $$B=\dfrac{(46.6\times10^{-3})(9.8)}{28}\,\text{T}. $$
  • This gives $$B\approx1.6\times10^{-2}\,\text{T}. $$

Room 5: State the Physical Meaning of the Result

  • The needed field is about $$1.6\times10^{-2}\,\text{T}. $$
  • That is much stronger than Earth’s magnetic field.
  • The real memory point is the equilibrium pattern: magnetic force can support a current-carrying wire against gravity.

Key Shortcut

Wire suspension problems collapse to one line: choose $$\phi=90^\circ$$ and set $$iLB=mg.$$

Main Tidbit

If the problem gives linear density instead of total mass, it is hinting that the wire length should cancel.
