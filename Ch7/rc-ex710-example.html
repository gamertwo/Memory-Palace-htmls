Example 7-10

This page follows the same simplified study order, but for the RL example where the switch changes the resistance seen by the inductor.

$$i(t)=\left[\frac{V_A}{R_1+R_2}-\frac{V_A}{R_1}\right]e^{-R_1 t/L}+\frac{V_A}{R_1},\quad t\ge 0$$
Quick Data
Clue 1
For first-order RL, always look for three things first: $i(0)$, $i(\infty)$, and $\tau=L/R_N$.
Clue 2
At DC steady state, the inductor behaves like a short circuit.
Clue 3
The resistor seen by the inductor after the switch moves is the one that controls the time constant.
Clue 4
The coefficient on the exponential is always the gap: initial value minus final value.
Rooms

Room 1: Recognize the Pattern

  • This is a first-order RL response in the standard form $$i(t)=\big[i(0)-i(\infty)\big]e^{-t/\tau}+i(\infty).$$
  • The current transitions from the initial value to the final value with one exponential term.

Room 2: Read the Initial Current

  • Before switching, the circuit has been in steady state for a long time.
  • So the inductor acts like a short circuit for the initial-condition circuit.
  • That makes the initial current $$i(0)=\frac{V_A}{R_1+R_2}.$$

Room 3: Read the Final Current

  • After the switch closes, $R_2$ is shorted out.
  • At long time, the inductor again behaves like a short circuit.
  • So the final current is $$i(\infty)=\frac{V_A}{R_1}.$$

Room 4: Extract the Time Constant $\tau$

  • For an RL circuit, $$\tau=\frac{L}{R_N}.$$
  • After switching, the inductor sees $R_N=R_1$ because $R_2$ is bypassed.
  • So $$\tau=\frac{L}{R_1}.$$
  • That means $$e^{-t/\tau}=e^{-R_1 t/L}.$$

Room 5: Build the Response

  • Use the universal first-order form $$i(t)=\big[i(0)-i(\infty)\big]e^{-t/\tau}+i(\infty).$$
  • Substitute the values:
  • $$i(t)=\left[\frac{V_A}{R_1+R_2}-\frac{V_A}{R_1}\right]e^{-R_1 t/L}+\frac{V_A}{R_1},\quad t\ge 0.$$

Room 6: Split Into Forced + Natural Parts

  • Forced part = $$\frac{V_A}{R_1}.$$
  • Natural part = $$\left[\frac{V_A}{R_1+R_2}-\frac{V_A}{R_1}\right]e^{-R_1 t/L}.$$
  • The bracket is the gap between where the current starts and where it will settle.

Room 7: Rebuild the Governing First-Order ODE

  • Standard RL form: $$\tau\frac{di}{dt}+i=i(\infty)u(t).$$
  • Substitute $$\tau=\frac{L}{R_1}\quad \text{and}\quad i(\infty)=\frac{V_A}{R_1}.$$
  • So the governing equation is $$\frac{L}{R_1}\frac{di}{dt}+i=\frac{V_A}{R_1}u(t),\quad t\ge 0.$$

Room 8: Quick Verification

  • Let $$B=\frac{V_A}{R_1+R_2}-\frac{V_A}{R_1}.$$ Then $$i(t)=Be^{-R_1 t/L}+\frac{V_A}{R_1}.$$
  • Differentiate: $$\frac{di}{dt}=B\left(-\frac{R_1}{L}\right)e^{-R_1 t/L}.$$
  • Now compute the left side:
  • $$\frac{L}{R_1}\frac{di}{dt}+i=-Be^{-R_1 t/L}+Be^{-R_1 t/L}+\frac{V_A}{R_1}=\frac{V_A}{R_1}.$$
  • So the left side matches the right side $$\frac{V_A}{R_1}u(t)$$ for $t>0$.

Fast Memory Rule

Walk the page in order: Recognize the Pattern -> Read the Initial Current -> Read the Final Current -> Extract the Time Constant $\tau$ -> Build the Response -> Split Into Forced + Natural Parts -> Rebuild the Governing First-Order ODE -> Quick Verification.
