Exercise 7-25

For a series RLC circuit with $$R=250\ \Omega,$$ $$L=10\ \text{mH},$$ $$C=1\ \mu\text{F},$$ $$V_0=0,$$ and $$I_0=30\ \text{mA},$$ find the capacitor voltage and inductor current for $$t\ge 0.$$

$$s^2+25000s+10^8=0,\qquad s_1=-5000,\ s_2=-20000$$ $$v_C(t)=2e^{-5000t}-2e^{-20000t}\ \text{V},\qquad i_L(t)=-10e^{-5000t}+40e^{-20000t}\ \text{mA}$$
Open in Memory Builder
Quick Data
Resistance
$$R=250\ \Omega$$
Inductance
$$L=10\times 10^{-3}\ \text{H}$$
Capacitance
$$C=1\times 10^{-6}\ \text{F}$$
Initial Voltage
$$v_C(0)=V_0=0$$
Initial Current
$$i_L(0)=I_0=30\ \text{mA}$$
Series Rule
$$i_L(t)=i_C(t)=C\dfrac{dv_C}{dt}$$
Rooms: Full Solution

Room 1: Write the Series Characteristic Equation

  • For a zero-input series RLC circuit, use
  • $$s^2+\frac{R}{L}s+\frac{1}{LC}=0.$$
  • Substitute the values:
  • $$s^2+\frac{250}{0.01}s+\frac{1}{0.01\times 10^{-6}}=0.$$
  • So
  • $$s^2+25000s+10^8=0.$$
  • Why: Because this step creates the fact the next step will use, so the solution stays logical instead of feeling like a jump.

Room 2: Find the Two Real Roots

  • Factoring or solving gives
  • $$s_1=-5000,\qquad s_2=-20000.$$
  • So the capacitor-voltage template is
  • $$v_C(t)=K_1e^{-5000t}+K_2e^{-20000t}.$$
  • Why: Because the roots reveal the exact decay modes, which tells you what time-domain template to write next.

Room 3: Apply the Initial Voltage

  • At $$t=0,$$
  • $$v_C(0)=K_1+K_2=0.$$
  • Therefore
  • $$K_2=-K_1.$$
  • Why: Because the initial voltage gives an immediate algebraic constraint between the unknown constants.

Room 4: Convert the Initial Current into a Slope

  • Because the current is the same through every series element,
  • $$i_L(t)=i_C(t)=C\frac{dv_C}{dt}.$$
  • Differentiate the voltage template:
  • $$\frac{dv_C}{dt}=-5000K_1e^{-5000t}-20000K_2e^{-20000t}.$$
  • At $$t=0,$$
  • $$I_0=C(-5000K_1-20000K_2).$$
  • Why: Because the current-voltage relation turns a measured current into a derivative condition, which is exactly what the exponential constants need.

Room 5: Solve for $$K_1$$ and $$K_2$$

  • Use $$C=10^{-6}\ \text{F}$$ and $$I_0=30\ \text{mA}=0.03\ \text{A}.$$
  • Then
  • $$0.03=10^{-6}(-5000K_1-20000K_2).$$
  • With $$K_2=-K_1,$$ this becomes
  • $$0.03=10^{-6}(15000K_1),$$ so $$K_1=2$$ and $$K_2=-2.$$
  • Why: Because the second constant is the last missing degree of freedom, so solving it fully pins down the response.

Room 6: Final Capacitor Voltage

  • Substitute the constants into the voltage template:
  • $$\boxed{v_C(t)=2e^{-5000t}-2e^{-20000t}\ \text{V}}.$$
  • Why: Because this is the target state variable, and writing it cleanly confirms that all earlier modeling choices were consistent.

Room 7: Differentiate to Get the Inductor Current

  • Differentiate the final voltage:
  • $$\frac{dv_C}{dt}=-10000e^{-5000t}+40000e^{-20000t}.$$
  • Multiply by $$C=10^{-6}\ \text{F}:$$
  • $$i_L(t)=10^{-6}\left(-10000e^{-5000t}+40000e^{-20000t}\right).$$
  • So
  • $$\boxed{i_L(t)=-10e^{-5000t}+40e^{-20000t}\ \text{mA}}.$$
  • Why: Because the capacitor-voltage solution is only half the story, and differentiating converts the solved state into the requested current.

Room 8: Read the Shape

  • The circuit is overdamped because the roots are two different real negatives.
  • The faster $$e^{-20000t}$$ term dies first, so the slower $$e^{-5000t}$$ term dominates later time.
  • Why: Because the final form should be interpreted physically, not just written symbolically, so you remember what dominates early and late time.

Fast Memory Rule

For a series zero-input problem with voltage as the state variable, write the two-root voltage form, use $$v_C(0)$$ to connect the constants, use $$i=C\,dv/dt$$ for the slope condition, then differentiate once more to recover the current.

Why The Order Matters

This page works best when you read it as a chain instead of as isolated formulas. The early rooms set up the model, the middle rooms use that model to solve constants or component constraints, and the last room writes the requested answer. If a room feels sudden, go back one room and ask which number or rule it is using.

What To Watch

Do not jump to the last formula too early. Read each room as the reason the next room is allowed to exist.
