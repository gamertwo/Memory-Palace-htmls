Exercise 7-28

The zero-input responses of a parallel RLC circuit are observed as $$i_L(t)=10te^{-2000t}\ \text{A}$$ and $$v_C(t)=10e^{-2000t}-20000te^{-2000t}\ \text{V}.$$ Recover the characteristic equation, the initial state values, the element values, and the resistor current.

$$i_L(t)=10te^{-2000t}\ \text{A},\qquad v_C(t)=10e^{-2000t}-20000te^{-2000t}\ \text{V}$$ $$s^2+4000s+4\times 10^6=0,\qquad L=1\ \text{H},\ C=0.25\ \mu\text{F},\ R=1\ \text{k}\Omega$$

Case
Critically damped parallel RLC
Rooms: Full Solution

Room 1: Recognize the Repeated Root

  • The current response contains $$te^{-2000t}.$$
  • That is the signature of a critically damped response with repeated root
  • $$s_1=s_2=-2000.$$
  • Why: Because the repeated-root signature immediately tells you the response family and shortens the rest of the reconstruction.

Room 2: Build the Characteristic Equation

  • The repeated root gives
  • $$\left(s+2000\right)^2=0.$$
  • Expanding yields
  • $$\boxed{s^2+4000s+4\times 10^6=0}.$$
  • Why: Because once the root structure is known, rebuilding the polynomial creates the coefficient links back to the circuit elements.

Room 3: Read the Initial State Values

  • At $$t=0,$$ the inductor current is
  • $$i_L(0)=10(0)e^0=0.$$
  • The capacitor voltage is
  • $$v_C(0)=10e^0-20000(0)e^0=10\ \text{V}. $$
  • Why: Because the initial state values carry the stored-energy information, and that information is needed before any reconstruction is valid.

Room 4: Recover the Inductance

  • Use the parallel inductor relation
  • $$v_C(0)=L\left.\frac{di_L}{dt}\right|_0.$$
  • Differentiate $$i_L(t)=10te^{-2000t}:$$
  • $$\frac{di_L}{dt}=10e^{-2000t}-20000te^{-2000t}.$$
  • At $$t=0,$$
  • $$\left.\frac{di_L}{dt}\right|_0=10.$$
  • So $$10=L(10),$$ which gives $$L=1\ \text{H}. $$
  • Why: Because the inductor relation is the shortest route from the measured current or voltage behavior back to L.

Room 5: Recover the Capacitance

  • For a parallel RLC circuit, the constant term of the normalized equation is
  • $$\frac{1}{LC}=4\times 10^6.$$
  • With $$L=1,$$
  • $$C=\frac{1}{4\times 10^6}=0.25\times 10^{-6}\ \text{F}=0.25\ \mu\text{F}. $$
  • Why: Because the waveform and state relations reveal how much capacitance is needed to support the observed dynamics.

Room 6: Recover the Resistance

  • The coefficient of $$s$$ in the normalized parallel equation is
  • $$\frac{1}{RC}=4000.$$
  • With $$C=0.25\times 10^{-6},$$
  • $$R=\frac{1}{4000(0.25\times 10^{-6})}=1000\ \Omega. $$
  • Why: Because resistance is usually the last coefficient to be identified after the energy-storage terms are already known.

Room 7: Write the Resistor Current

  • Use Ohm's law on the resistor branch:
  • $$i_R(t)=\frac{v_C(t)}{R}. $$
  • With $$R=1\ \text{k}\Omega,$$
  • $$\boxed{i_R(t)=10e^{-2000t}-20000te^{-2000t}\ \text{mA}}.$$
  • Why: Because the resistor current is the observable branch quantity that completes the recovered circuit description.

Room 8: Final Memory Pattern

  • Critical damping is the key clue here.
  • Once the repeated root is seen, the rest is a straight recovery chain: characteristic equation, initial values, element values, then resistor current.
  • Why: Because the page should end with a compact rule that helps you remember the whole solution path next time.

Fast Memory Rule

When you see $$te^{-\alpha t}$$ in a zero-input response, think repeated root first. Then use the waveform itself to read the state variables and recover the element values by coefficient matching.

Why The Order Matters

This page works best when you read it as a chain instead of as isolated formulas. The early rooms set up the model, the middle rooms use that model to solve constants or component constraints, and the last room writes the requested answer. If a room feels sudden, go back one room and ask which number or rule it is using.

What To Watch

Do not treat the branch quantities as independent. In the parallel pages, one shared voltage or one known branch current drives the rest of the solution.
