Exercise 7-26

A series RLC circuit has the zero-input responses $$v_C(t)=2000te^{-500t}\ \text{V}$$ and $$i_L(t)=3.2e^{-500t}-1600te^{-500t}\ \text{mA}.$$ Find the characteristic equation, the initial state values, and the element values $$R,$$ $$L,$$ and $$C.$$

$$v_C(t)=2000te^{-500t}\ \text{V},\qquad i_L(t)=3.2e^{-500t}-1600te^{-500t}\ \text{mA}$$ $$s^2+1000s+25\times 10^4=0,\qquad R=2.5\ \text{k}\Omega,\ L=2.5\ \text{H},\ C=1.6\ \mu\text{F}$$
Open in Memory Builder
Quick Data
Given Voltage
$$v_C(t)=2000te^{-500t}\ \text{V}$$
Given Current
$$i_L(t)=3.2e^{-500t}-1600te^{-500t}\ \text{mA}$$
Root Clue
The factor $$te^{-500t}$$ signals a repeated root at $$s=-500.$$
Series Rule
$$i_L(t)=i_C(t)=C\dfrac{dv_C}{dt}$$
Target Form
$$s^2+\frac{R}{L}s+\frac{1}{LC}=0$$
Key Move
Use the current response at $$t=0$$ to recover $$C$$ first.
Rooms: Full Solution

Room 1: Recognize the Repeated Root

  • The voltage contains the factor $$te^{-500t}.$$
  • That is the standard critical-damping signature for a repeated root.
  • So the characteristic equation must have
  • $$s_1=s_2=-500.$$
  • Why: Because the repeated-root signature immediately tells you the response family and shortens the rest of the reconstruction.

Room 2: Build the Characteristic Equation

  • A repeated root at $$-500$$ means
  • $$\left(s+500\right)^2=0.$$
  • Expand it:
  • $$s^2+1000s+250000=0.$$
  • So
  • $$\boxed{s^2+1000s+25\times 10^4=0}.$$
  • Why: Because once the root structure is known, rebuilding the polynomial creates the coefficient links back to the circuit elements.

Room 3: Read the Initial Voltage

  • Evaluate the given voltage at $$t=0.$$
  • Because of the factor $$t,$$
  • $$v_C(0)=2000(0)e^0=0.$$
  • Therefore
  • $$\boxed{V_0=0}. $$
  • Why: Because the waveform value at the switching instant is one of the cleanest constraints for the unknown constants or element values.

Room 4: Read the Initial Current

  • Evaluate the given current at $$t=0.$$
  • The exponential becomes 1 and the term with $$t$$ disappears.
  • So
  • $$i_L(0)=3.2\ \text{mA}.$$
  • Therefore
  • $$\boxed{I_0=3.2\ \text{mA}}.$$
  • Why: Because the initial current is a state constraint that lets you connect the measured waveform to the physical circuit.

Room 5: Differentiate the Voltage to Recover $$C$$

  • For a series circuit,
  • $$i_L(t)=i_C(t)=C\frac{dv_C}{dt}.$$
  • Differentiate the voltage:
  • $$\frac{dv_C}{dt}=2000e^{-500t}-10^6te^{-500t}.$$
  • At $$t=0,$$
  • $$\left.\frac{dv_C}{dt}\right|_0=2000.$$
  • So
  • $$0.0032=C(2000),\qquad C=1.6\times 10^{-6}\ \text{F}. $$
  • Why: Because the capacitor relation links voltage slope to current, so differentiation is the direct way to recover the capacitance.

Room 6: Match the Constant Term to Find $$L$$

  • For a series RLC circuit, the normalized equation is
  • $$s^2+\frac{R}{L}s+\frac{1}{LC}=0.$$
  • Match the constant term:
  • $$\frac{1}{LC}=250000.$$
  • With $$C=1.6\times 10^{-6},$$
  • $$L=\frac{1}{250000(1.6\times 10^{-6})}=2.5\ \text{H}. $$
  • Why: Because the constant term is the cleanest coefficient link to the storage-element product, so it is the natural place to recover inductance.

Room 7: Match the Linear Term to Find $$R$$

  • Match the coefficient of $$s$$:
  • $$\frac{R}{L}=1000.$$
  • With $$L=2.5\ \text{H},$$
  • $$R=1000(2.5)=2500\ \Omega=2.5\ \text{k}\Omega.$$
  • Why: Because after the storage elements are known, the linear coefficient isolates the damping contribution and makes the resistor recoverable.

Room 8: Final Check

  • The given responses are now fully consistent with the recovered circuit:
  • $$\boxed{R=2.5\ \text{k}\Omega,\ L=2.5\ \text{H},\ C=1.6\ \mu\text{F}}.$$
  • The repeated root explains the critical-damping form with the factor $$te^{-500t}.$$
  • Why: Because reconstruction problems should end with a consistency check that the recovered elements reproduce the observed behavior.

Fast Memory Rule

When a zero-input response includes $$te^{-\alpha t},$$ think repeated root first, then read initial values directly, use $$i=C\,dv/dt$$ to recover $$C,$$ and finish by matching the characteristic-equation coefficients for $$L$$ and $$R.$$

Why The Order Matters

This page works best when you read it as a chain instead of as isolated formulas. The early rooms set up the model, the middle rooms use that model to solve constants or component constraints, and the last room writes the requested answer. If a room feels sudden, go back one room and ask which number or rule it is using.
