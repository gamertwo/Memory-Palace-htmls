Pattern Palace Hub Exercise 7-11

Example 7-11

This example is an RC switching problem where the asked quantity is resistor current, so the clean move is to solve the capacitor voltage first and then convert that voltage into the current through the parallel 20-kΩ resistor.

$$i_R(t)=0.25e^{-1000t}+1.25\text{ mA},\quad t\ge 0$$
Quick Data
Clue 1
If the question asks for a branch current but there is a capacitor, first ask whether the capacitor voltage is the easier state variable.
Clue 2
For capacitor problems, voltage cannot jump. Once you know v_C(0^-), you also know v_C(0^+).
Clue 3
At DC steady state, the capacitor is an open circuit, which makes divider calculations much easier.
Clue 4
If the resistor is in parallel with the capacitor, they share the same voltage. That turns the final current step into pure Ohm's law.
Rooms

Room 1: Recognize the State Variable

  • The capacitor voltage is the natural state variable, not the resistor current.
  • So solve for v_C(t) first, then use Ohm's law to get i_R(t).

Room 2: Read the Initial Capacitor Voltage

  • Before switching, the switch has been open for a long time, so the capacitor is at DC steady state and behaves like an open circuit.
  • Use the pre-switch voltage divider:
  • $$v_C(0^-)=\frac{20k+10k}{20k+20k+10k}\cdot 50=30\text{ V}.$$
  • Capacitor voltage cannot jump, so $$v_C(0^+)=30\text{ V}.$$

Room 3: Read the Final Capacitor Voltage

  • After the switch closes, the 10-kΩ resistor is shorted out.
  • At long time, the capacitor again behaves like an open circuit.
  • So the new divider gives
  • $$v_C(\infty)=\frac{20k}{20k+20k}\cdot 50=25\text{ V}.$$

Room 4: Get the Time Constant

  • For an RC circuit, $$\tau=R_TC.$$
  • To find R_T, look back into the capacitor's terminals after switching, with the source set to zero.
  • Because the closed switch shorts the 10-kΩ branch, the capacitor sees two 20-kΩ resistors in parallel:
  • $$R_T=\frac{20k\cdot 20k}{20k+20k}=10k\Omega.$$
  • Then $$\tau=R_TC=(10k)(0.1\mu\text{F})=1\text{ ms}.$$

Room 5: Build the Capacitor Voltage

  • Use the universal first-order RC form:
  • $$v_C(t)=\big[v_C(0)-v_C(\infty)\big]e^{-t/\tau}+v_C(\infty).$$
  • Substitute the values:
  • $$v_C(t)=(30-25)e^{-1000t}+25=5e^{-1000t}+25,\quad t\ge 0.$$

Room 6: Convert Voltage to the Asked Current

  • The 20-kΩ resistor is in parallel with the capacitor, so it has the same voltage.
  • Apply Ohm's law:
  • $$i_R(t)=\frac{v_C(t)}{20k}=\frac{5e^{-1000t}+25}{20k}.$$
  • In milliamps, that becomes
  • $$i_R(t)=0.25e^{-1000t}+1.25\text{ mA},\quad t\ge 0.$$

Room 7: Rebuild the Governing ODE for the State Variable

  • The capacitor still obeys the first-order RC equation
  • $$\tau\frac{dv_C}{dt}+v_C=v_C(\infty)u(t).$$
  • Using $$\tau=0.001 \quad \text{and} \quad v_C(\infty)=25,$$
  • the governing equation is $$0.001\frac{dv_C}{dt}+v_C=25u(t),\quad t\ge 0.$$

Room 8: Quick Verification

  • Differentiate the state variable:
  • $$\frac{dv_C}{dt}=-5000e^{-1000t}.$$
  • Substitute into the left side:
  • $$0.001(-5000e^{-1000t})+\left(5e^{-1000t}+25\right)=-5e^{-1000t}+5e^{-1000t}+25=25.$$
  • So the ODE checks, and the current follows directly from dividing by 20 kΩ.
