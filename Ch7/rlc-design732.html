Design Exercise 7-32

Select the resistor value in Figure 7-47 that makes the response critically damped, then find the maximum value of $$v_o(t)$$ and the time when it occurs. Finally determine the maximum power delivered by the 60 V source.

Rooms: Full Solution

Room 1: Start from the Figure 7-47 Denominator

  • From Exercise 7-31, the output denominator for this network is
  • $$RLCs^2+Ls+R.$$
  • Divide by $$RLC$$ to get the standard form
  • $$s^2+\frac{1}{RC}s+\frac{1}{LC}. $$
  • Why: Because the denominator contains the natural dynamics, and critical-damping design always starts by shaping that denominator.

Room 2: Match the Standard Second-Order Pattern

  • Compare with
  • $$s^2+2\alpha s+\omega_0^2.$$
  • So
  • $$2\alpha=\frac{1}{RC},\qquad \omega_0=\frac{1}{\sqrt{LC}}.$$
  • Why: Because the second-order pattern translates the circuit denominator into the alpha and omega0 quantities that define critical damping.

Room 3: Impose Critical Damping

  • Critical damping means $$\alpha=\omega_0.$$
  • Therefore
  • $$\frac{1}{2RC}=\frac{1}{\sqrt{LC}}.$$
  • Solve for the design resistor:
  • $$R_{\text{crit}}=\frac{1}{2}\sqrt{\frac{L}{C}}. $$
  • Why: Because a repeated root is the defining condition for critical damping, so this is the design constraint that matters most.

Room 4: Evaluate the Resistor Value

  • With $$L=0.125\ \text{H}$$ and $$C=0.5\times10^{-6}\ \text{F},$$
  • $$R_{\text{crit}}=\frac{1}{2}\sqrt{\frac{0.125}{0.5\times10^{-6}}}=250\ \Omega. $$
  • Why: Because the symbolic critical-damping condition only becomes useful after it is converted into an actual component value.

Room 5: Write the Critical Output Response

  • At $$R=250\ \Omega,$$ the denominator becomes
  • $$s^2+8000s+1.6\times10^7=(s+4000)^2. $$
  • The step output is
  • $$V_o(s)=\frac{480000}{(s+4000)^2}.$$
  • So
  • $$v_o(t)=480000te^{-4000t}\ \text{V}. $$
  • Why: Because once the repeated-root design is fixed, the response expression shows the exact pulse shape you will optimize.

Room 6: Find the Peak Voltage

  • Differentiate:
  • $$\frac{dv_o}{dt}=480000e^{-4000t}(1-4000t). $$
  • Set the derivative to zero:
  • $$1-4000t=0\Rightarrow t=\frac{1}{4000}=250\ \mu s. $$
  • Then
  • $$v_{o,\max}=480000\left(\frac{1}{4000}\right)e^{-1}=\frac{120}{e}=44.15\ \text{V}. $$
  • Why: Because peak output is a performance target, so the waveform must be differentiated or inspected to locate its maximum.

Room 7: Find the Source Current

  • Use Ohm's law on the series resistor:
  • $$i_s(t)=\frac{v_s-v_o}{R}. $$
  • With $$v_s=60$$ and $$R=250,$$
  • $$i_s(t)=0.24-1920te^{-4000t}\ \text{A}. $$
  • This is largest at $$t=0$$ and again as $$t\to\infty,$$ where it equals 0.24 A.
  • Why: Because source power depends on source current, so this quantity must be recovered before the power calculation can happen.

Room 8: Compute the Maximum Source Power

  • The source voltage is a constant 60 V step.
  • So the maximum delivered power is
  • $$P_{s,\max}=v_s i_{s,\max}=60(0.24)=14.4\ \text{W}. $$
  • Why: Because the design question is not complete until the electrical stress or power demand is also quantified.

Fast Memory Rule

This design problem is a three-step chain: force the repeated root to get $$R,$$ use the critical-response form to get the peak output time and value, then combine the source voltage with the peak source current to get the maximum power.

Why The Order Matters

This page works best when you read it as a chain instead of as isolated formulas. The early rooms set up the model, the middle rooms use that model to solve constants or component constraints, and the last room writes the requested answer.
