Exercise 7-27

A parallel RLC circuit has $$R=1\ \text{k}\Omega,$$ $$C=1\ \mu\text{F},$$ $$L=100\ \text{mH},$$ $$I_0=100\ \text{mA},$$ and $$V_0=0.$$ Plot the zero-input responses of the inductor, resistor, and capacitor currents on one axis, then show that Kirchhoff's current law holds at every instant.

$$i_L(t)=e^{-500t}\left(100\cos 3122.5t+16.0\sin 3122.5t\right)\ \text{mA}$$ $$i_R(t)=-32.0e^{-500t}\sin 3122.5t\ \text{mA},\qquad i_C(t)=e^{-500t}\left(-100\cos 3122.5t+16.0\sin 3122.5t\right)\ \text{mA}$$

Quick Data
Resistance
$$R=1\ \text{k}\Omega$$
Capacitance
$$C=1\times 10^{-6}\ \text{F}$$
Inductance
$$L=0.1\ \text{H}$$
Initial State
$$i_L(0)=100\ \text{mA},\quad v_C(0)=0$$
Damping Data
$$\alpha=500\ \text{s}^{-1},\quad \omega_d\approx 3122.5\ \text{rad/s}$$
Parallel Facts
$$v=L\dfrac{di_L}{dt},\quad i_R=\dfrac{v}{R},\quad i_C=C\dfrac{dv}{dt}$$
Rooms: Full Solution

Room 1: Write the Parallel Characteristic Equation

  • For a zero-input parallel RLC circuit, use
  • $$LCs^2+\frac{L}{R}s+1=0.$$
  • Substitute the values:
  • $$10^{-7}s^2+10^{-4}s+1=0.$$
  • Normalized form:
  • $$s^2+1000s+10^7=0.$$
  • Why: Because the characteristic equation is the starting model for the natural behavior, and every root, range, and waveform comes from it.

Room 2: Find the Roots and Pick the Current Template

  • The roots are
  • $$s_{1,2}=-500\pm j3122.5.$$
  • So the zero-input inductor current is underdamped:
  • $$i_L(t)=e^{-500t}\left(K_1\cos 3122.5t+K_2\sin 3122.5t\right).$$
  • Why: Because the root type decides the waveform template, so this step prevents guessing the wrong current form.

Room 3: Use the Initial Current

  • At $$t=0,$$ the cosine term is 1 and the sine term is 0.
  • So
  • $$i_L(0)=K_1=100\ \text{mA}.$$
  • Why: Because the initial inductor current is a stored-energy fact, so it immediately fixes one constant in the current template.

Room 4: Convert the Initial Voltage into a Derivative Condition

  • In the parallel circuit,
  • $$v_C(0)=v_L(0)=L\left.\frac{di_L}{dt}\right|_0.$$
  • Since $$v_C(0)=0,$$ we require
  • $$\left.\frac{di_L}{dt}\right|_0=0.$$
  • This gives
  • $$-500K_1+3122.5K_2=0.$$
  • Why: Because in parallel circuits the branch voltage controls current derivatives, so this is how the initial voltage becomes a solvable constraint.

Room 5: Solve for $$K_2$$ and Finish $$i_L(t)$$

  • With $$K_1=100,$$
  • $$K_2=\frac{500(100)}{3122.5}\approx 16.0.$$
  • Therefore
  • $$\boxed{i_L(t)=e^{-500t}\left(100\cos 3122.5t+16.0\sin 3122.5t\right)\ \text{mA}}.$$
  • Why: Because the second constant is the last missing degree of freedom, so solving it fully pins down the response.

Room 6: Differentiate to Get the Branch Voltage

  • Use $$v=L\,di_L/dt.$$
  • The derivative condition cancels the cosine term at the start, leaving
  • $$v_C(t)=v_L(t)=-32.0e^{-500t}\sin 3122.5t\ \text{V}. $$
  • Why: Because the branch voltage is the shared bridge to the other branch quantities, so it has to be extracted before the rest can follow.

Room 7: Use the Voltage to Get $$i_R(t)$$

  • Apply Ohm's law on the resistor branch:
  • $$i_R(t)=\frac{v_C(t)}{R}=\frac{-32.0e^{-500t}\sin 3122.5t}{1000}. $$
  • So
  • $$\boxed{i_R(t)=-32.0e^{-500t}\sin 3122.5t\ \text{mA}}.$$
  • Why: Because resistor current is not independent here; once the shared voltage is known, Ohm's law gives it immediately.

Room 8: Differentiate the Voltage to Get $$i_C(t)$$

  • Use $$i_C=C\,dv_C/dt.$$
  • After differentiation and simplification,
  • $$\boxed{i_C(t)=e^{-500t}\left(-100\cos 3122.5t+16.0\sin 3122.5t\right)\ \text{mA}}.$$
  • Why: Because capacitor current comes from the voltage slope, so this step completes the branch-current picture from the same shared voltage.

Room 9: Validate KCL from the Three Currents

  • Add the three branch currents:
  • $$i_L+i_R+i_C=e^{-500t}\left(100\cos+16\sin-32\sin-100\cos+16\sin\right).$$
  • The cosine terms cancel and the sine terms also cancel, so
  • $$\boxed{i_L(t)+i_R(t)+i_C(t)=0}$$ for every $$t.$$
  • Why: Because conservation of current is the final consistency check that proves all three branch expressions belong to the same solution.

Fast Memory Rule

For a parallel zero-input problem, solve the current first, use the shared parallel voltage to get $$v(t),$$ then derive $$i_R$$ and $$i_C$$ from that same voltage. KCL becomes the final consistency check.

Why The Order Matters

This page works best when you read it as a chain instead of as isolated formulas. The early rooms set up the model, the middle rooms use that model to solve constants or component constraints, and the last room writes the requested answer. If a room feels sudden, go back one room and ask which number or rule it is using.

What To Watch

Do not treat the branch quantities as independent. In the parallel pages, one shared voltage or one known branch current drives the rest of the solution.
