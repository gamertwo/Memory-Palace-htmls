Example 7-22

A series RLC circuit in zero state is driven by a step input. Find the capacitor voltage for $$t\ge 0.$$ The fastest route is to separate the forced response from the underdamped natural response, then use the zero-state initial conditions to solve the constants.

$$10^{-6}\frac{d^2v_C}{dt^2}+0.5\times 10^{-3}\frac{dv_C}{dt}+v_C=10$$ $$v_C(t)=10-10e^{-250t}\cos 968t-2.58e^{-250t}\sin 968t\ \text{V}$$

Underdamped series RLC step response
Rooms: Full Solution

Room 1: Write the Differential Equation

  • For the capacitor voltage, the step-driven equation is
  • $$10^{-6}\frac{d^2v_C}{dt^2}+0.5\times 10^{-3}\frac{dv_C}{dt}+v_C(t)=10,\qquad t\ge 0.$$
  • Why: Because the differential equation is the compact model of the circuit, and every later step comes from separating or solving that model.

Room 2: Read the Forced Response

  • The input is a constant step of 10 V, so the steady forced response is simply
  • $$v_{CF}(t)=10.$$
  • Why: Because the input type tells you the long-term forced term immediately, so you can reserve the remaining work for the natural part.

Room 3: Normalize the Homogeneous Equation

  • The homogeneous part is
  • $$\frac{d^2v_{CN}}{dt^2}+500\frac{dv_{CN}}{dt}+10^6v_{CN}(t)=0.$$
  • Comparing with the standard second-order form gives
  • $$\omega_0=1000,\qquad 2\zeta\omega_0=500.$$
  • Why: Because the normalized form exposes the standard second-order coefficients, which is how you read damping data without solving blindly.

Room 4: Identify the Damping Case

  • From $$2\zeta\omega_0=500,$$ we get $$\zeta=0.25.$$
  • Since $$\zeta<1,$$ the response is underdamped.
  • So
  • $$\alpha=\zeta\omega_0=250,\qquad \omega_d=\omega_0\sqrt{1-\zeta^2}=968.$$
  • Why: Because the damping case decides the correct response template, so this step prevents using the wrong waveform form.

Room 5: Write the Natural Response

  • The underdamped natural response is
  • $$v_{CN}(t)=K_1e^{-250t}\cos 968t+K_2e^{-250t}\sin 968t.$$
  • The full solution is
  • $$v_C(t)=10+K_1e^{-250t}\cos 968t+K_2e^{-250t}\sin 968t.$$
  • Why: Because once the damping type is known, the natural-response template gives the exact shape whose constants must be locked by conditions.

Room 6: Apply the Zero-State Initial Conditions

  • Because the circuit starts in zero state,
  • $$v_C(0)=0,\qquad \left.\frac{dv_C}{dt}\right|_0=0.$$
  • From $$v_C(0)=0,$$
  • $$0=10+K_1,\qquad K_1=-10.$$
  • Why: Because initial conditions turn the general template into the specific waveform for this circuit and input.

Room 7: Solve for $$K_2$$

  • Differentiate the full response and evaluate at $$t=0.$$
  • This gives
  • $$0=-250K_1+968K_2.$$
  • With $$K_1=-10,$$
  • $$K_2=-2.58.$$
  • Why: Because the second constant is the last missing degree of freedom, so solving it fully pins down the response.

Room 8: Final Capacitor Voltage

  • Substitute the constants:
  • $$\boxed{v_C(t)=10-10e^{-250t}\cos 968t-2.58e^{-250t}\sin 968t\ \text{V}}.$$
  • This is the textbook step response with overshoot and ringing before settling to 10 V.
  • Why: Because this is the target state variable, and writing it cleanly confirms that all earlier modeling choices were consistent.

Fast Memory Rule

For this step response, the entire chain is: constant input gives the forced 10 V, the normalized homogeneous equation gives the underdamped natural part, and the zero-state conditions lock the two constants.

Why The Order Matters

This page works best when you read it as a chain instead of as isolated formulas. The early rooms set up the model, the middle rooms use that model to solve constants or component constraints, and the last room writes the requested answer. If a room feels sudden, go back one room and ask which number or rule it is using.

What To Watch

Do not jump to the last formula too early. Read each room as the reason the next room is allowed to exist.
