Exercise 7-18

This problem is really two linked tasks. First, collapse the surrounding network into the Thevenin source actually seen by the capacitor. Then treat the result as the same exponential-forcing RC problem from Example 7-15. The final derivative step matters because it forces you to connect waveform form to capacitor current, not just stop after the voltage expression.

$$v_C(t)=45.5e^{-1000t}-45.5e^{-8333t}\,\text{V},\qquad i_C(t)=-45.5e^{-1000t}+379e^{-8333t}\,\mu\text{A},\qquad t\ge 0$$
Quick Data
Source
$$v_S(t)=100e^{-1000t}u(t)\,\text{V}$$
Series Resistor
$$300\,\text{k}\Omega$$
Shunt Resistor
$$200\,\text{k}\Omega$$
Capacitor
$$0.001\,\mu\text{F}=1\,\text{nF}$$
Initial State
Zero-state capacitor, so $$v_C(0)=0.$$
Rooms

Room 1: Replace the Left Network by Its Thevenin Source

  • The capacitor sees the rest of the circuit through the top node.
  • That is why a Thevenin reduction is the natural first move: it preserves exactly what the capacitor terminal experiences.
  • The Thevenin voltage is the divider output across the $$200\,\text{k}\Omega$$ resistor:
  • $$V_{Th}(t)=100e^{-1000t}\left(\frac{200}{300+200}\right)=40e^{-1000t}\,\text{V}.$$

Room 2: Find the Thevenin Resistance

  • Turn off the independent source, so the voltage source becomes a short circuit.
  • Then the capacitor sees
  • $$R_{Th}=300\,\text{k}\Omega \parallel 200\,\text{k}\Omega=120\,\text{k}\Omega.$$

Room 3: Build the Equivalent RC Time Constant

  • With $$C=1\,\text{nF},$$ the time constant is
  • $$\tau=R_{Th}C=(120\times10^3)(10^{-9})=1.2\times10^{-4}\,\text{s}.$$
  • So
  • $$\frac{1}{\tau}=8333\,\text{s}^{-1}.$$

Room 4: Write the First-Order RC Equation

  • The equivalent circuit is a first-order RC driven by $$V_{Th}(t).$$
  • So
  • $$\tau\frac{dv_C}{dt}+v_C=40e^{-1000t},\qquad v_C(0)=0.$$

Room 5: Use the Exponential-Forcing Result

  • Compare with the Example 7-15 form:
  • $$V_0=0,\qquad V_A=40,\qquad \alpha=1000,\qquad RC=\tau=1.2\times10^{-4}.$$
  • Then
  • $$1-\alpha RC=1-(1000)(1.2\times10^{-4})=0.88.$$
  • So the forcing coefficient is
  • $$\frac{V_A}{1-\alpha RC}=\frac{40}{0.88}=45.5.$$
  • This is the payoff for doing Example 7-15 carefully: once the structure is recognized, the problem becomes substitution instead of a full re-derivation.

Room 6: Write the Capacitor Voltage

  • Since $$V_0=0,$$ the general form becomes
  • $$v_C(t)=\left[0-\frac{40}{0.88}\right]e^{-t/\tau}+\frac{40}{0.88}e^{-1000t}.$$
  • Therefore
  • $$\boxed{v_C(t)=45.5e^{-1000t}-45.5e^{-8333t}\,\text{V}},\qquad t\ge 0.$$

Room 7: Differentiate to Get the Capacitor Current

  • Using the passive sign convention shown,
  • $$i_C(t)=C\frac{dv_C}{dt}.$$
  • Differentiate:
  • $$\frac{dv_C}{dt}=-45.5(1000)e^{-1000t}+45.5(8333)e^{-8333t}.$$
  • The faster $$e^{-8333t}$$ term is large early but dies very quickly, while the slower $$e^{-1000t}$$ term controls the longer tail.
  • Multiply by $$C=10^{-9}\,\text{F}:$$
  • $$i_C(t)=-45.5e^{-1000t}+379e^{-8333t}\,\mu\text{A}.$$

Room 8: Final Answer

  • $$\boxed{v_C(t)=45.5e^{-1000t}-45.5e^{-8333t}\,\text{V}}$$
  • $$\boxed{i_C(t)=-45.5e^{-1000t}+379e^{-8333t}\,\mu\text{A}}$$
  • Both are valid for $$t\ge 0.$$

Concept Summary

This exercise is a template-stacking problem: Thevenin reduction first, first-order exponential forcing second, capacitor current law third. Once those three layers are kept separate, the algebra becomes much less intimidating.

Key Shortcut

Thevenin First

The cleanest way to solve this problem is not to attack the original network directly. Collapse the source and resistors into one Thevenin source and one Thevenin resistance as seen by the capacitor, then the whole problem becomes a direct reuse of the exponential-forcing RC template from Example 7-15.

Memory Palace Path

This path is locked in sequence: shrink the network to Thevenin form first, then read the time constant, reuse the forced-response template, and only then differentiate for current.

Station 1: Divider Gate

Start by shrinking the left network into its Thevenin voltage.

Transition 1 to 2

Once the driving voltage is known, the capacitor still needs the resistance it sees.

Station 2: Parallel Bridge

Short the source and combine $$300\,\text{k}\Omega$$ with $$200\,\text{k}\Omega$$ in parallel.

Transition 2 to 3

With $$R_{Th}$$ known, the capacitor immediately turns it into a time constant.

Station 3: Time Vault

Store $$\tau=R_{Th}C$$ and its reciprocal $$8333\,\text{s}^{-1}.$$

Transition 3 to 4

The reduced circuit is now just a first-order RC driven by an exponential.

Station 4: Template Hall

Write the standard RC ODE with $$40e^{-1000t}$$ on the right.

Transition 4 to 5

This is exactly the same forcing shape as Example 7-15, so the old template can be reused.

Station 5: Coefficient Lock

Compute $$\dfrac{V_A}{1-\alpha RC}=\dfrac{40}{0.88}=45.5.$$

Transition 5 to 6

Once the coefficient is known, the capacitor voltage is already finished because the zero-state condition fixes the natural constant automatically.

Station 6: Voltage Seal

Store $$v_C(t)=45.5e^{-1000t}-45.5e^{-8333t}.$$

Transition 6 to 7

The current arrow uses the capacitor law, so one derivative remains.

Station 7: Current Exit

Differentiate and multiply by $$C$$ to get $$i_C(t).$$
