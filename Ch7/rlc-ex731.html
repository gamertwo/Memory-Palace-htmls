Exercise 7-31

Find the zero-state response of $$v_o(t)$$ for Figure 7-47 when the source is $$v_s(t)=60u(t)\ \text{V}.$$ The circuit is a 200 ohm series resistor feeding a parallel combination of a 125 mH inductor and a 0.5 microfarad capacitor, with the output taken across the parallel branch.

$$V_o(s)=\frac{60L}{RLCs^2+Ls+R}=\frac{600000}{(s+2000)(s+8000)}$$ $$\boxed{v_o(t)=100\left(e^{-2000t}-e^{-8000t}\right)\ \text{V}}$$

Quick Data
Source
$$v_s(t)=60u(t)\ \text{V}$$
Resistance
$$R=200\ \Omega$$
Inductance
$$L=125\ \text{mH}$$
Capacitance
$$C=0.5\ \mu\text{F}$$
Parallel Branch
$$Z_p=Z_L\parallel Z_C$$
Output
Taken across the parallel LC branch
Rooms: Full Solution

Room 1: Collapse the Parallel LC Branch

  • The inductor and capacitor are in parallel, so first replace them with an equivalent impedance.
  • Use
  • $$Z_L=sL,\qquad Z_C=\frac{1}{sC}.$$
  • Why: Because reducing the subnetwork first turns a complicated circuit into a simple divider problem.

Room 2: Compute the Parallel Impedance

  • The parallel branch is
  • $$Z_p=\frac{Z_LZ_C}{Z_L+Z_C}=\frac{sL}{1+s^2LC}. $$
  • This is the impedance that sits after the 200 ohm resistor.
  • Why: Because the exact branch impedance is the ingredient the transfer function needs before you can move into s-domain algebra.

Room 3: Form the Transfer Function

  • Use the voltage divider:
  • $$\frac{V_o}{V_s}=\frac{Z_p}{R+Z_p}. $$
  • Substitute $$Z_p$$ and simplify:
  • $$\frac{V_o}{V_s}=\frac{sL}{RLCs^2+Ls+R}. $$
  • Why: Because the transfer function is the clean bridge from circuit structure to output response.

Room 4: Apply the 60 V Step Input

  • Because $$V_s(s)=60/s,$$
  • $$V_o(s)=\frac{60}{s}\cdot \frac{sL}{RLCs^2+Ls+R}=\frac{60L}{RLCs^2+Ls+R}. $$
  • Why: Because the input waveform must be inserted in the s-domain before the output expression can be solved.

Room 5: Substitute the Element Values

  • With $$R=200,$$ $$L=0.125,$$ and $$C=0.5\times10^{-6},$$
  • $$V_o(s)=\frac{7.5}{1.25\times10^{-5}s^2+0.125s+200}. $$
  • Dividing through by $$1.25\times10^{-5}$$ gives
  • $$V_o(s)=\frac{600000}{s^2+10000s+1.6\times10^7}. $$
  • Why: Because numerical substitution collapses the symbolic transfer function into a factorable expression you can actually invert.

Room 6: Factor the Denominator

  • The quadratic factors as
  • $$s^2+10000s+1.6\times10^7=(s+2000)(s+8000). $$
  • So
  • $$V_o(s)=\frac{600000}{(s+2000)(s+8000)}. $$
  • Why: Because factoring reveals the modes directly and prepares the expression for partial fractions.

Room 7: Use Partial Fractions

  • Write
  • $$\frac{600000}{(s+2000)(s+8000)}=\frac{100}{s+2000}-\frac{100}{s+8000}. $$
  • Now invert term by term.
  • Why: Because partial fractions separate the response into standard inverse-transform pieces that can be read back into time domain.

Room 8: Final Time-Domain Response

  • The inverse Laplace transform gives
  • $$\boxed{v_o(t)=100\left(e^{-2000t}-e^{-8000t}\right)\ \text{V}}.$$
  • This is a zero-state pulse response that rises from zero and decays back to zero because the inductor is a short circuit at DC.
  • Why: Because the final output waveform is the payoff of the entire s-domain reduction, factoring, and inversion chain.

Fast Memory Rule

This problem is a divider problem in disguise. Replace the parallel LC with one impedance, form the transfer function, multiply by the step input, factor the quadratic, and invert the two simple exponentials.

Why The Order Matters

This page works best when you read it as a chain instead of as isolated formulas. The early rooms set up the model, the middle rooms use that model to solve constants or component constraints, and the last room writes the requested answer. If a room feels sudden, go back one room and ask which number or rule it is using.

What To Watch

Do not treat the branch quantities as independent. In the parallel pages, one shared voltage or one known branch current drives the rest of the solution.
