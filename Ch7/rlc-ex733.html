Exercise 7-33

The step response of a series RLC circuit is observed to be $$v_C(t)=15-15e^{-1000t}\cos 1000t\ \text{V}$$ and $$i_L(t)=45e^{-1000t}\cos 1000t+45e^{-1000t}\sin 1000t\ \text{mA}.$$ Recover the characteristic equation, the initial state values, the source amplitude, the element values, and the resistor voltage.

$$v_C(t)=15-15e^{-1000t}\cos 1000t\ \text{V}$$ $$i_L(t)=45e^{-1000t}\cos 1000t+45e^{-1000t}\sin 1000t\ \text{mA}$$

Rooms: Full Solution

Room 1: Read the Root Pair

  • The damped cosine pattern shows an underdamped response.
  • From the waveform, $$\alpha=1000$$ and $$\beta=1000,$$ so the roots are $$-1000\pm j1000.$$
  • Why: Because the observed root pair gives the response type and coefficient targets before you attempt to recover any elements.

Room 2: Build the Characteristic Equation

  • Use $$s^2+2\alpha s+(\alpha^2+\beta^2)=0.$$
  • This gives $$\boxed{s^2+2000s+2\times10^6=0}.$$
  • Why: Because once the root structure is known, rebuilding the polynomial creates the coefficient links back to the circuit elements.

Room 3: Read the State Values and the Input

  • At $$t=0,$$ $$v_C(0)=15-15=0.$$
  • Also $$i_L(0)=45\ \text{mA}.$$
  • As $$t\to\infty,$$ $$v_C(\infty)=15\ \text{V},$$ so $$V_A=15\ \text{V}.$$
  • Why: Because reverse engineering starts from what the waveform already reveals, not from guessing the circuit first.

Room 4: Recover the Capacitance

  • Differentiate the voltage:
  • $$\frac{dv_C}{dt}=15000e^{-1000t}\cos1000t+15000e^{-1000t}\sin1000t.$$
  • Since $$i=C\,dv_C/dt,$$ matching the current waveform gives $$C=45\times10^{-3}/15000=3\ \mu\text{F}.$$
  • Why: Because the waveform and state relations reveal how much capacitance is needed to support the observed dynamics.

Room 5: Recover L and R

  • For series RLC, $$s^2+\frac{R}{L}s+\frac{1}{LC}=0.$$
  • So $$R/L=2000$$ and $$1/(LC)=2\times10^6.$$
  • With $$C=3\ \mu\text{F},$$ $$L=1/((3\times10^{-6})(2\times10^6))=167\ \text{mH}.$$
  • Then $$R=2000L=333\ \Omega.$$
  • Why: Because once one storage element is known, coefficient matching collapses the remaining unknowns to the final physical pair.

Room 6: Find the Resistor Voltage

  • In a series circuit, $$v_R=Ri.$$
  • Multiply $$333\ \Omega$$ by the current waveform to get
  • $$\boxed{v_R(t)=15e^{-1000t}\cos1000t+15e^{-1000t}\sin1000t\ \text{V}}.$$
  • Why: Because the resistor voltage is a derived output, so it should be computed only after the current and element values are already consistent.

Fast Memory Rule

Waveform first, coefficients second, component values third. Once the root pair and the final value are known, the rest of the circuit can be rebuilt directly.

Why The Order Matters

This page works best when you read it as a chain instead of as isolated formulas. The early rooms set up the model, the middle rooms use that model to solve constants or component constraints, and the last room writes the requested answer. If a room feels sudden, go back one room and ask which number or rule it is using.

What To Watch

Do not guess the circuit first. In recovery pages, read the waveform for roots, initial values, and final values before solving for components.
