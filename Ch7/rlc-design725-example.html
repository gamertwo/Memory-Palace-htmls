Design Example 7-25

Design a series RLC circuit whose zero-state capacitor-voltage step response is $$v_C(t)=V_A-\frac{5}{4}V_Ae^{-400t}+\frac{1}{4}V_Ae^{-2000t},\ t\ge0.$$ Read the poles from the waveform, build the required characteristic equation, and choose one valid component set.

$$v_C(t)=V_A-\frac{5}{4}V_Ae^{-400t}+\frac{1}{4}V_Ae^{-2000t}$$ $$s^2+2400s+8\times10^5=0,\qquad \frac{R}{L}=2400,\quad \frac{1}{LC}=8\times10^5$$
Open in Memory Builder
Quick Data
Final Value
$$v_C(\infty)=V_A$$
Poles
$$s_1=-400,\quad s_2=-2000$$
Series Form
$$s^2+\frac{R}{L}s+\frac{1}{LC}=0$$
One Choice
$$R=3\ \text{k}\Omega$$
Solved L
$$L=1.25\ \text{H}$$
Solved C
$$C=1\ \mu\text{F}$$
Rooms: Full Solution

Room 1: Read the Target Poles

  • The response contains two distinct exponentials.
  • Those exponentials reveal the roots directly: $$-400$$ and $$-2000.$$
  • Why: Because the target waveform already encodes the desired poles, and design is much easier once those poles are made explicit.

Room 2: Build the Numerical Polynomial

  • Multiply the factors from the roots:
  • $$(s+400)(s+2000)=s^2+2400s+8\times10^5.$$
  • Why: Because the polynomial is the link between the desired poles and the circuit coefficients you must match.

Room 3: Match the Series RLC Form

  • For a series RLC circuit, the characteristic equation is $$s^2+\frac{R}{L}s+\frac{1}{LC}=0.$$
  • Matching coefficients gives $$R/L=2400$$ and $$1/(LC)=8\times10^5.$$
  • Why: Because matching the target polynomial to the series form turns abstract poles into equations in R, L, and C.

Room 4: Choose a Convenient Component

  • There are three circuit parameters and only two constraints.
  • Choose $$R=3\ \text{k}\Omega$$ to make the arithmetic clean.
  • Why: Because if the design has more unknowns than independent equations, you should use the free choice intentionally instead of treating it as an error.

Room 5: Solve for L and C

  • From $$R/L=2400,$$ $$L=3000/2400=1.25\ \text{H}.$$
  • From $$1/(LC)=8\times10^5,$$ $$C=1/((1.25)(8\times10^5))=1\ \mu\text{F}.$$
  • Why: Because once the coefficient equations are fixed, the remaining component values should be solved in the order that uses the cleanest equations.

Room 6: Final Design Logic

  • The chosen set satisfies both coefficient conditions.
  • Many other designs are possible because one component can be selected freely.
  • Why: Because the finished design should be reduced to a portable method, not left as isolated arithmetic.

Fast Memory Rule

For design-from-waveform problems, read the poles first. The target response fixes the polynomial before the components are chosen.

Why The Order Matters

This page works best when you read it as a chain instead of as isolated formulas. The early rooms set up the model, the middle rooms use that model to solve constants or component constraints, and the last room writes the requested answer. If a room feels sudden, go back one room and ask which number or rule it is using.

What To Watch

Do not choose component values first. In design pages, the targets or poles must be converted into coefficient equations before any component is picked.
