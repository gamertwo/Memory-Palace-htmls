Exercise 7-20

Find the sinusoidal steady-state output voltage for the RL network when the source current is $$i_s(t)=I_A\cos(\omega t)\,u(t).$$ Treat the circuit in the frequency domain: convert the parallel RL branch to one equivalent impedance, multiply by the source current phasor, then return to time domain.

$$v_o(t)=\frac{I_A\omega L}{\sqrt{1+\left(\frac{\omega L}{R}\right)^2}}\cos(\omega t+\theta)\ \text{V},\qquad \theta=\tan^{-1}\!\left(\frac{R}{\omega L}\right),\qquad t\ge 0$$
Quick Data
Input Current
$$i_s(t)=I_A\cos(\omega t)\,u(t)\ \text{A}$$
Resistor Branch
Impedance $$Z_R=R$$
Inductor Branch
Impedance $$Z_L=j\omega L$$
Output
Voltage across the parallel RL pair: $$v_o(t)$$
Goal
Sinusoidal steady-state amplitude and phase
Rooms

Room 1: Move to Phasor Domain

  • For sinusoidal steady state, ignore startup transient and solve with phasors.
  • Source current phasor:
  • $$\tilde I_s=I_A\angle 0^\circ.$$

Room 2: Build the RL Equivalent Admittance

  • Parallel branches add in admittance form:
  • $$Y=\frac{1}{R}+\frac{1}{j\omega L}=\frac{1}{R}-j\frac{1}{\omega L}.$$
  • Equivalent impedance is $$Z=\frac{1}{Y}.$$

Room 3: Write the Equivalent Impedance Explicitly

  • Using parallel form directly:
  • $$Z=\frac{R(j\omega L)}{R+j\omega L}.$$
  • This is the impedance seen by the source current.

Room 4: Magnitude of the Transfer From Current to Voltage

  • Output phasor is $$\tilde V_o=\tilde I_s Z.$$
  • Magnitude:
  • $$|Z|=\frac{\omega LR}{\sqrt{R^2+(\omega L)^2}}=\frac{\omega L}{\sqrt{1+\left(\frac{\omega L}{R}\right)^2}}.$$
  • So amplitude is
  • $$|\tilde V_o|=I_A|Z|=\frac{I_A\omega L}{\sqrt{1+\left(\frac{\omega L}{R}\right)^2}}.$$

Room 5: Phase Angle

  • For $$Z=\frac{R(j\omega L)}{R+j\omega L},$$ its phase is
  • $$\angle Z=\tan^{-1}\!\left(\frac{R}{\omega L}\right)=\theta.$$
  • Since the source phasor angle is zero, output phase is also $$+\theta.$$

Room 6: Return to Time Domain

  • Convert phasor back to cosine form:
  • $$v_o(t)=|\tilde V_o|\cos(\omega t+\theta).$$
  • Therefore
  • $$\boxed{v_o(t)=\frac{I_A\omega L}{\sqrt{1+\left(\frac{\omega L}{R}\right)^2}}\cos(\omega t+\theta)\ \text{V}},\quad t\ge 0,$$
  • with $$\theta=\tan^{-1}\!\left(\frac{R}{\omega L}\right).$$

Frequency Check

Low frequency: $$\omega\to 0$$ makes amplitude approach 0 V (inductor branch nearly short, little output voltage). High frequency: $$\omega\to\infty$$ makes amplitude approach $$I_AR$$ (inductor branch opens, current effectively through resistor branch).

Key Shortcut

Current Source Into Parallel Network

When the input is current and the output is voltage across a linear network, first find the equivalent impedance at that frequency, then use $$\tilde V=\tilde I Z.$$ Magnitude gives amplitude, angle gives phase.

Memory Palace Path

Start from phasors, not differential equations. The path is impedance-first, then amplitude, then phase.

Station 1: Source Gate

Store $$\tilde I_s=I_A\angle 0^\circ.$$

Transition 1 to 2

The source alone does nothing until the RL branch is collapsed to one equivalent value.

Station 2: Admittance Bridge

Build $$Y=\frac{1}{R}+\frac{1}{j\omega L}.$$

Transition 2 to 3

Invert admittance to reach impedance so voltage can be found by $$V=IZ.$$

Station 3: Impedance Hall

Lock $$Z=\frac{R(j\omega L)}{R+j\omega L}.$$

Transition 3 to 4

Now split the same impedance into two outputs: size and angle.

Station 4: Magnitude Vault

Keep $$|V_o|=\frac{I_A\omega L}{\sqrt{1+(\omega L/R)^2}}.$$

Transition 4 to 5

After amplitude, only phase remains to complete the waveform.

Station 5: Phase Door

Set $$\theta=\tan^{-1}\!\left(\frac{R}{\omega L}\right).$$

Transition 5 to 6

Combine amplitude and phase into one cosine for final steady-state output.

Station 6: Final Seal

Write $$v_o(t)=|V_o|\cos(\omega t+\theta).$$
