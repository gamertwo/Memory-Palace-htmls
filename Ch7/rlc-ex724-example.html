Example 7-24

The circuit in Figure 7-45 is in the zero state. Find the current through the resistor for $$t\ge 0.$$ The clean route is to solve the inductor current first, then derive the voltage and the capacitor current before applying KCL for the resistor branch.

$$s^2+21276.6s+10^8=0,\qquad s_1=-14300,\ s_2=-7000$$ $$i_R(t)=-73e^{-14300t}+73e^{-7000t}\ \text{mA}$$

Rooms: Full Solution

Room 1: Write the Parallel Characteristic Equation

  • For a parallel RLC circuit, use
  • $$s^2+\frac{1}{RC}s+\frac{1}{LC}=0.$$
  • With $$R=470,\ L=0.1,\ C=10^{-7},$$
  • $$s^2+21276.6s+10^8=0.$$
  • Why: Because the characteristic equation is the starting model for the natural behavior, and every root, range, and waveform comes from it.

Room 2: Find the Two Real Roots

  • The roots are
  • $$s_1=-14300,\qquad s_2=-7000.$$
  • So the inductor-current response is overdamped.
  • Why: Because the roots reveal the exact decay modes, which tells you what time-domain template to write next.

Room 3: Write the Inductor-Current Form

  • Because the source is a 25 mA step current, the inductor current has a forced constant term.
  • Use
  • $$i_L(t)=K_1e^{-14300t}+K_2e^{-7000t}+25.$$
  • Why: Because choosing the right current template gives you the structure of the answer before you spend effort on constants.

Room 4: Apply the Zero-State Current Condition

  • At $$t=0,$$ the inductor current cannot jump from zero.
  • So
  • $$0=K_1+K_2+25.$$
  • Why: Because zero-state current removes one free constant right away and keeps the rest of the algebra simple.

Room 5: Use the Zero Initial Voltage

  • The capacitor voltage starts at zero, and the parallel branch voltage equals the inductor voltage.
  • So
  • $$v(0)=L\left.\frac{di_L}{dt}\right|_0=0.$$
  • That gives
  • $$-14300K_1-7000K_2=0.$$
  • Why: Because the branch voltage at the switching instant gives the derivative relation that unlocks the remaining constants.

Room 6: Solve for $$K_1$$ and $$K_2$$

  • Solving the two equations gives
  • $$K_1=24,\qquad K_2=-49.$$
  • Therefore
  • $$i_L(t)=24e^{-14300t}-49e^{-7000t}+25\ \text{mA}. $$
  • Why: Because the second constant is the last missing degree of freedom, so solving it fully pins down the response.

Room 7: Differentiate to Get the Voltage and Capacitor Current

  • Use $$v=L\,di_L/dt$$ to get
  • $$v(t)=-34.3e^{-14300t}+34.3e^{-7000t}\ \text{V}. $$
  • Then use $$i_C=C\,dv/dt$$ to get
  • $$i_C(t)=49e^{-14300t}-24e^{-7000t}\ \text{mA}. $$
  • Why: Because once the inductor current is known, differentiation gives the shared voltage and then the capacitor branch current without restarting the problem.

Room 8: Apply KCL for the Resistor Current

  • At the top node,
  • $$i_R(t)=i_s(t)-i_L(t)-i_C(t).$$
  • Substitute the known expressions and simplify:
  • $$\boxed{i_R(t)=-73e^{-14300t}+73e^{-7000t}\ \text{mA}}.$$
  • Why: Because KCL is the cleanest way to isolate the remaining branch current after the other two branch quantities are known.

Fast Memory Rule

This page is a KCL chain: solve $$i_L$$ first, derive the common voltage, convert it into $$i_C,$$ and use the source-current split to recover $$i_R.$$

Why The Order Matters

This page works best when you read it as a chain instead of as isolated formulas. The early rooms set up the model, the middle rooms use that model to solve constants or component constraints, and the last room writes the requested answer. If a room feels sudden, go back one room and ask which number or rule it is using.

What To Watch

Do not solve the missing branch first. Use the branches that are easiest to derive, then let KCL recover the last one cleanly.
