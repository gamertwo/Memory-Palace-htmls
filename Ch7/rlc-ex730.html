Rooms: Full Solution

Room 1: Start from the Solved Branch Currents

  • Example 7-24 already gives the three branch currents.
  • This exercise is about plotting them together and reading the node law directly from the graph.
  • Why: Because this plotting problem depends on previously derived expressions, so the first move is to bring those exact formulas back into view.

Room 2: Recall the Inductor Current

  • The inductor current is
  • $$i_L(t)=24e^{-14300t}-49e^{-7000t}+25\ \text{mA}. $$
  • It starts at zero and settles to 25 mA.
  • Why: Because the inductor branch carries the long-term current, so it anchors how the plot should behave.

Room 3: Recall the Capacitor Current

  • The capacitor current is
  • $$i_C(t)=49e^{-14300t}-24e^{-7000t}\ \text{mA}. $$
  • It is purely transient and decays to zero.
  • Why: Because the capacitor branch is purely transient here, and remembering that helps you predict its plot before adding anything.

Room 4: Recall the Resistor Current

  • The resistor current is
  • $$i_R(t)=-73e^{-14300t}+73e^{-7000t}\ \text{mA}. $$
  • It also decays to zero because the final branch voltage goes to zero.
  • Why: Because the resistor branch completes the KCL picture, so it must be plotted alongside the other two for the cancellation to be visible.

Room 5: Add the Three Expressions

  • Sum the currents term by term:
  • $$i_L+i_C+i_R$$
  • $$=(24+49-73)e^{-14300t}+(-49-24+73)e^{-7000t}+25.$$
  • All transient terms cancel, leaving only 25 mA.
  • Why: Because the whole point of the plot set is to show that the branch currents satisfy KCL at every instant, not only at the endpoints.

Room 6: Interpret the Plot

  • The inductor branch rises toward the source current.
  • The resistor and capacitor currents are transient redistribution currents.
  • Their combined effect never violates KCL.
  • Why: Because the graph should confirm the physics: one branch survives at DC while the others fade away.

Room 7: Final Memory Pattern

  • This graph is a conservation picture.
  • The source current is constant, and the branch currents reshuffle that fixed 25 mA until the transients die out.
  • Why: Because the page should end with a compact rule that helps you remember the whole solution path next time.

Fast Memory Rule

Whenever the branch currents all come from one KCL derivation, the plot should show a stable total. Here the algebra predicts it and the graph confirms it: the three branches always sum to the source current.

Why The Order Matters

This page works best when you read it as a chain instead of as isolated formulas. The early rooms set up the model, the middle rooms use that model to solve constants or component constraints, and the last room writes the requested answer. If a room feels sudden, go back one room and ask which number or rule it is using.

What To Watch

Do not treat the branch quantities as independent. In the parallel pages, one shared voltage or one known branch current drives the rest of the solution.
