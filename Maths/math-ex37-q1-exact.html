Exercise 3.7

Exercise 3.7 Question 1

This page trains the exact-equation method in the same memory-builder format as the physics set. The key route never changes: identify $M$ and $N$, verify exactness, integrate $M$ with respect to $x$, recover the missing $g(y)$ term, and write the final potential function equal to a constant.

$$(x+y-10)\,dx+(x-y-2)\,dy=0$$

$$\frac{x^2}{2}+xy-10x-\frac{y^2}{2}-2y=C$$
Exact GuideOpen in Memory Builder
Quick Data
M(x,y)
$$M=x+y-10$$
N(x,y)
$$N=x-y-2$$
Exactness Check
$$M_y=1,\qquad N_x=1$$
Rooms: Full Solution

Room 1: Identify $M$ and $N$

  • Write the equation in the standard form $$M(x,y)\,dx+N(x,y)\,dy=0.$$
  • Here $$M=x+y-10$$ and $$N=x-y-2.$$
  • The exact-equation method starts only after that identification is clean.

Room 2: Verify Exactness

  • Differentiate $$M$$ with respect to $$y$$ and $$N$$ with respect to $$x.$$
  • We get $$M_y=1$$ and $$N_x=1.$$
  • Since these match, the equation is exact.

Room 3: Integrate $M$ with Respect to $x$

  • Build the potential function by integrating $$M$$ with respect to $$x,$$ treating $$y$$ as a constant.
  • That gives $$F(x,y)=\int (x+y-10)\,dx=\frac{x^2}{2}+xy-10x+g(y)$$.
  • Why do we add $$g(y)$$? Because when we integrate with respect to $$x,$$ we only recover terms that actually change when x changes.
  • Any part of the answer made only of $$y$$ behaves like a constant during x-integration, so ordinary integration in $$x$$ cannot detect it.
  • That invisible leftover is written as $$g(y).$$ It stands for an unknown function of $$y$$ only that still has to be recovered later.

Room 4: Recover the Missing $g(y)$ Term

  • Now differentiate the candidate potential with respect to $$y.$$ This is the step that exposes the hidden $$g(y)$$ term.
  • Since $$\frac{d}{dy}[g(y)]=g'(y),$$ the unknown function reappears as a visible derivative when we compute $$F_y.$$
  • Matching with $$N$$ gives $$F_y=x+g'(y)=x-y-2$$ and therefore $$g'(y)=-y-2$$.
  • Integrating that derivative with respect to $$y$$ gives the missing correction: $$g(y)=-\frac{y^2}{2}-2y$$.
  • So Room 3 hides the y-only piece as $$g(y),$$ and Room 4 brings it back by differentiating with respect to $$y.$$

Room 5: Write the Final Potential Function

  • Substitute the recovered correction back into the potential function.
  • The final potential is $$F(x,y)=\frac{x^2}{2}+xy-10x-\frac{y^2}{2}-2y$$.
  • So the required answer is $$\frac{x^2}{2}+xy-10x-\frac{y^2}{2}-2y=C$$.

Key Shortcut

For simple polynomial exact equations, exactness check plus one integration is usually the entire job.

Why This Flow Matters

This is the cleanest possible exact-equation template: identify M and N, match mixed partials, integrate once, then repair the missing y-part.

Solution Flow

Run the same five-stop exact-equation route every time: identify, verify, integrate, repair the missing function, then finish the potential.
