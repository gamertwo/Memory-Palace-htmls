Exercise 3.10 Guide

Special Integrating Factors

These questions are built around a guessed integrating factor of the form $$\mu=x^h y^k.$$ The job is to choose $$h$$ and $$k$$ so that the multiplied equation becomes exact.

Exercise 3.10 Index Math Hub
Core Formula

Assume the I.F.

  • Try $$\mu=x^h y^k.$$
  • Then force exactness by using $$\frac{\partial(\mu M)}{\partial y}=\frac{\partial(\mu N)}{\partial x}.$$

Rule IV Shortcut

  • If the equation looks like $$x^m y^n(ay\,dx+bx\,dy)+x^{m'}y^{n'}(a'y\,dx+b'x\,dy)=0,$$ then the integrating factor is still taken as $$x^h y^k.$$
  • Use coefficient matching, or the textbook shortcut relations, to solve for $$h$$ and $$k.$$
Stable Route
Write $$Mdx+Ndy=0$$ → Guess $$x^h y^k$$ → Solve for $$h,k$$ → Multiply through → Finish as exact
