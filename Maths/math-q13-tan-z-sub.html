Solve the Following Differential Equation

Direct solution only.

$$\frac{dy}{dx}=1+\tan(y-x) \qquad [\text{Put } y-x=z]$$
Rooms

Room 1: Start

  • Write the equation as given:
  • $$\frac{dy}{dx}=1+\tan(y-x).$$

Room 2: Substitute

  • Let $$z=y-x.$$
  • Then $$\frac{dz}{dx}=\frac{dy}{dx}-1.$$

Room 3: Rewrite

  • Using the given equation,
  • $$\frac{dz}{dx}=\tan z.$$

Room 4: Separate

  • $$\frac{dz}{\tan z}=dx.$$
  • That is
  • $$\cot z\,dz=dx.$$

Room 5: Integrate

  • $$\int \cot z\,dz=\int dx.$$
  • $$\ln|\sin z|=x+C.$$

Room 6: Exponentiate

  • $$\sin z=Ce^x.$$

Room 7: Back-Substitute

  • Put back $$z=y-x:$$
  • $$\boxed{\sin(y-x)=Ce^x}$$
Memory Clues

Clue 1

If the question says put $y-x=z$, do it immediately.

Clue 2

$\dfrac{dz}{dx}= \dfrac{dy}{dx}-1$ is the key simplification here.

Clue 3

$1/\tan z=\cot z$, so the integral becomes standard.

Clue 4

After integrating, exponentiate and substitute back.
