Exact Differential Equations

Question 5

This page trains the exact-equation method in the same memory-builder format as the physics set. The key route never changes: identify $M$ and $N$, verify exactness, integrate $M$ with respect to $x$, recover the missing $g(y)$ term, and write the final potential function equal to a constant.

$$(y\sec^2 x+\sec x\tan x)\,dx+(\tan x+2y)\,dy=0$$

$$y\tan x+\sec x+y^2=C$$
Exact GuideOpen in Memory Builder
Quick Data
M(x,y)
$$M=y\sec^2 x+\sec x\tan x$$
N(x,y)
$$N=\tan x+2y$$
Exactness Check
$$M_y=\sec^2 x,\qquad N_x=\sec^2 x$$
Rooms: Full Solution

Room 1: Identify $M$ and $N$

  • Write the equation in the standard form $$M(x,y)\,dx+N(x,y)\,dy=0.$$
  • Here $$M=y\sec^2 x+\sec x\tan x$$ and $$N=\tan x+2y.$$
  • The exact-equation method starts only after that identification is clean.

Room 2: Verify Exactness

  • Differentiate $$M$$ with respect to $$y$$ and $$N$$ with respect to $$x.$$
  • We get $$M_y=\sec^2 x$$ and $$N_x=\sec^2 x.$$
  • Since these match, the equation is exact.

Room 3: Integrate $M$ with Respect to $x$

  • Build the potential function by integrating $$M$$ with respect to $$x,$$ treating $$y$$ as a constant.
  • That gives $$F(x,y)=\int \left(y\sec^2 x+\sec x\tan x\right)dx=y\tan x+\sec x+g(y)$$.
  • The unknown correction $$g(y)$$ collects everything lost during the x-integration.

Room 4: Recover the Missing $g(y)$ Term

  • Differentiate the candidate potential with respect to $$y.$$
  • Matching with $$N$$ gives $$F_y=\tan x+g'(y)=\tan x+2y$$ and therefore $$g'(y)=2y$$.
  • Integrating once more gives $$g(y)=y^2$$.

Room 5: Write the Final Potential Function

  • Substitute the recovered correction back into the potential function.
  • The final potential is $$F(x,y)=y\tan x+\sec x+y^2$$.
  • So the required answer is $$y\tan x+\sec x+y^2=C$$.

Key Shortcut

Separate the x-integration mentally: integrate the y-multiple first, then the pure trig term.

Why This Flow Matters

This question is useful because the exact method stays the same even when the x-integration is trigonometric.

Solution Flow

Run the same five-stop exact-equation route every time: identify, verify, integrate, repair the missing function, then finish the potential.
