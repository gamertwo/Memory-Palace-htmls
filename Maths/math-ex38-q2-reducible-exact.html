Exercise 3.8

Exercise 3.8 Question 2

This one uses Rule I. The ratio collapses to $$3/x,$$ so multiplying by $$x^3$$ turns the equation into an exact polynomial form.

$$\left(y+\frac{y^3}{3}+\frac{x^2}{2}\right)dx+\frac{x}{4}(1+y^2)\,dy=0$$

$$\frac{x^4y}{4}+\frac{x^4y^3}{12}+\frac{x^6}{12}=C$$
Ex 3.8 GuideOpen in Memory Builder
Quick Data
M(x,y)
$$M=y+\frac{y^3}{3}+\frac{x^2}{2}$$
N(x,y)
$$N=\frac{x}{4}(1+y^2)$$
Rule Test
$$\frac{M_y-N_x}{N}=\frac{(1+y^2)-\frac14(1+y^2)}{\frac{x}{4}(1+y^2)}=\frac3x$$
Integrating Factor
$$\text{I.F.}=e^{\int 3/x\,dx}=x^3$$
Rooms: Full Solution

Room 1: Identify $M$ and $N$

  • Take $$M=y+\dfrac{y^3}{3}+\dfrac{x^2}{2}$$ and $$N=\dfrac{x}{4}(1+y^2).$$
  • This is the non-exact starting form.

Room 2: Show It Is Not Exact

  • Compute $$M_y=1+y^2$$ and $$N_x=\dfrac14(1+y^2).$$
  • They are not equal, so we need an integrating factor.

Room 3: Apply Rule I

  • Use $$\dfrac{M_y-N_x}{N}$$ because it becomes a function of $$x$$ only.
  • That ratio simplifies to $$\dfrac3x.$$
  • Hence $$\text{I.F.}=e^{\int 3/x\,dx}=x^3.$$

Room 4: Multiply Through

  • After multiplying by $$x^3,$$ the equation becomes exact:
  • $$\left(x^3y+\frac{x^3y^3}{3}+\frac{x^5}{2}\right)dx+\frac{x^4}{4}(1+y^2)\,dy=0.$$

Room 5: Solve the Exact Equation

  • Integrate the new $$M$$ with respect to $$x$$:
  • $$F=\frac{x^4y}{4}+\frac{x^4y^3}{12}+\frac{x^6}{12}+g(y).$$
  • Comparing $$F_y$$ with the new $$N$$ gives $$g'(y)=0.$$

Room 6: Final Answer

  • The potential function is $$F=\dfrac{x^4y}{4}+\dfrac{x^4y^3}{12}+\dfrac{x^6}{12}.$$
  • So $$\dfrac{x^4y}{4}+\dfrac{x^4y^3}{12}+\dfrac{x^6}{12}=C.$$

Key Shortcut

When the common factor $1+y^2$ cancels out, the Rule I test becomes much easier.

Why This Flow Matters

This question shows how an ugly-looking polynomial can collapse to a very simple integrating-factor ratio.

Solution Flow

Spot the x-only ratio, build $$x^3,$$ and then finish with the usual exact routine.

Identify→Not exact→Rule I gives $$3/x$$→Multiply by $$x^3$$→Solve exact form
