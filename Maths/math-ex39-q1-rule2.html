Exercise 3.9 Question 1

This one is a clean Rule II example. The ratio $$\dfrac{N_x-M_y}{M}$$ collapses to $$-2/y,$$ so the integrating factor depends only on $$y.$$

$$(3x^2y^4+2xy)\,dx+(2x^3y^3-x^2)\,dy=0$$

$$x^3y^2+\frac{x^2}{y}=C$$
Ex 3.9 GuideOpen in Memory Builder
Quick Data
Rule II Ratio
$$\frac{N_x-M_y}{M}=-\frac2y$$
Integrating Factor
$$e^{\int -2/y\,dy}=\frac1{y^2}$$
Formula Used
$$\text{I.F.}=e^{\int f(y)\,dy}$$
Rooms: Full Solution

Room 1: Check Rule II

  • Here $$M=3x^2y^4+2xy$$ and $$N=2x^3y^3-x^2.$$
  • Compute $$M_y=12x^2y^3+2x$$ and $$N_x=6x^2y^3-2x.$$
  • Then $$\dfrac{N_x-M_y}{M}=-\dfrac2y.$$

Room 2: Build the I.F.

  • Since the ratio is a function of $$y$$ only, Rule II applies.
  • $$\text{I.F.}=e^{\int -2/y\,dy}=y^{-2}.$$

Room 3: Multiply Through

  • The exact equation becomes
  • $$\left(3x^2y^2+\frac{2x}{y}\right)dx+\left(2x^3y-\frac{x^2}{y^2}\right)dy=0.$$

Room 4: Solve the Exact Equation

  • Integrate the new $$M$$ with respect to $$x$$:
  • $$F=x^3y^2+\frac{x^2}{y}+g(y).$$
  • Matching $$F_y$$ with the new $$N$$ gives $$g'(y)=0.$$

Room 5: Final Answer

  • So $$x^3y^2+\dfrac{x^2}{y}=C.$$
