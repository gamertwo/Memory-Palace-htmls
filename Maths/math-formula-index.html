Main Differentiation / Integration Formula Rule

  • Differentiate = break, reduce, extract change.
  • Integrate = rebuild, recover, reverse.
  • Exact equation step = check, fix, then solve.

Fast Recall Formula

Derivative: “power down, coefficient comes out.”
Integral: “power up, divide, add $C$.”
Exact: “first compare, then integrating factor, then solve.”

Core Trigger

$\frac{1}{x}$

Think log. This is the strongest quick-match pattern.

Core Trigger

$x^n$

Derivative: down. Integral: up then divide.

Core Trigger

$e^x$

Stays the same in both differentiation and integration.

Core Trigger

$M_y$ vs $N_x$

If same: exact. If not: look for integrating factor.

Palace 1 — FMAB Memory Line

Connected rooms: Broken Circle → Truth Gate → Cost → Reconstruction. This palace carries the main difference between differentiation and integration.

Linear Connected Palace
Room
1

Broken Circle

Cue: half-drawn transmutation circle

The circle is incomplete. Something is missing. That missing piece is your signal that the function is about to be broken into change.

Memory: Differentiate = take apart the function.
Fast line: “Incomplete shape means extract change.”
Room
2

Truth Gate

Cue: gate opens instantly and reveals knowledge

The gate gives an answer immediately. This is how you remember differentiation: it gives the direct rate or direct output pattern fast.

$$\frac{d}{dx}(x^n)=nx^{n-1}$$
Memory: Power goes down. Coefficient comes out.
Fast line: “Gate opens fast → answer comes out fast.”
Room
3

Cost / Loss

Cue: something is lost in exchange

Differentiation often feels like loss: one power is removed, one degree is reduced, something becomes smaller or simpler.

$$\frac{d}{dx}(\log x)=\frac{1}{x} \qquad \frac{d}{dx}(e^x)=e^x$$
Memory: $\log x$ opens into $\frac{1}{x}$.
Memory: $e^x$ does not change.
Fast line: “Loss room: log becomes fraction, exponential stays itself.”
Room
4

Reconstruction

Cue: the circle is used again to rebuild

This room is integration. The idea is recovery. You reverse the breaking process and rebuild the original form.

$$\int x^n\,dx=\frac{x^{n+1}}{n+1}+C$$ $$\int \frac{1}{x}\,dx=\log|x|+C \qquad \int e^x\,dx=e^x+C$$
Memory: Power goes up, then divide, then add $C$.
Memory: $\frac{1}{x}$ rebuilds log.
Fast line: “Rebuild room: add one, divide, add constant.”

Palace 2 — Steins;Gate Memory Line

Connected rooms: Phone Microwave → Timeline Shift → Pattern Loop. This palace supports reverse-thinking, chain patterns, and exact-equation checking.

Loop Connected Palace
Room
1

Phone Microwave

Cue: message sent backward

Sending something backward is your clean cue for integration: you are going back toward the original source.

$$\int \cos x\,dx=\sin x + C \qquad \int \sin x\,dx=-\cos x + C$$
Memory: Integration goes backward to restore the source.
Fast line: “Backward message = reverse process.”
Room
2

Timeline Shift

Cue: one small change changes the whole line

This is the derivative idea: a small change carries important meaning. It also helps you remember inverse-trig trigger forms.

$$\frac{d}{dx}(\tan x)=\sec^2 x \qquad \frac{d}{dx}(\sec x)=\sec x\tan x$$ $$\frac{d}{dx}(\tan^{-1}x)=\frac{1}{1+x^2} \qquad \frac{d}{dx}(\sin^{-1}x)=\frac{1}{\sqrt{1-x^2}}$$
Memory: $\sec^2 x$ points to $\tan x$.
Memory: $\sec x\tan x$ points to $\sec x$.
Memory: $\frac{1}{1+x^2}$ points to $\tan^{-1}x$.
Memory: $\frac{1}{\sqrt{1-x^2}}$ points to $\sin^{-1}x$.
Room
3

Pattern Loop

Cue: repeated events show a hidden structure

This room is for recognition. When the same pattern keeps appearing, stop doing random work and match the structure directly.

$$\int \sec^2 x\,dx=\tan x + C \qquad \int \sec x\tan x\,dx=\sec x + C$$ $$\int \frac{1}{1+x^2}\,dx=\tan^{-1}x + C \qquad \int \frac{1}{\sqrt{1-x^2}}\,dx=\sin^{-1}x + C$$
Memory: repeated trigger = direct formula match.
Fast line: “If the form is familiar, do not overthink it.”

Exact Equation Bridge Palace

This part merges your room-based exact-equation structure into the same palace logic: first identify, then compare, then fix, then solve.

Bridge from Calculus to DE

Main Flow

Identify $M$ and $N$ → Check $M_y$ and $N_x$ → If not exact, find integrating factor → Multiply through → Solve as exact

Bridge
1

Identify the Pieces

Cue: split the equation into two parts
$$M\,dx + N\,dy = 0$$
Memory: Before solving, first label the equation correctly.
Fast line: “Name both sides first.”
Bridge
2

Check Exactness

Cue: compare the two cross-derivatives
$$M_y \stackrel{?}{=} N_x$$
Memory: If equal, it is exact. If not equal, do not force it.
Fast line: “Compare first, conclude second.”
Bridge
3

Find Integrating Factor

Cue: one clean ratio collapses to one variable
$$\frac{N_x - M_y}{M} \quad \text{or} \quad \frac{M_y - N_x}{N}$$
Memory: If the ratio becomes only $x$ or only $y$, that gives the integrating factor path.
Fast line: “One-variable collapse means integrating factor.”
Bridge
4

Multiply Through

Cue: equation changes form and becomes exact

After multiplying by the integrating factor, the equation becomes a new exact equation.

Memory: integrating factor is not the final answer, it is the fixer.
Fast line: “Fix first, solve after.”
Bridge
5

Solve the Exact Equation

Cue: rebuild one combined potential function
$$F_x = M,\qquad F_y = N \qquad \Rightarrow \qquad F(x,y)=C$$
Memory: integrate one side, then use the other side to complete the missing part.
Fast line: “Build $F$, then write $F=C$.”
