Exercise 3.8 Guide

Reducible to Exact Equations

These questions are not exact at first. The move is to test the integrating-factor rule, multiply the whole equation by that factor, and then finish with the usual exact-equation method.

Rule Test

Rule I

  • If $$\dfrac{M_y-N_x}{N}$$ is a function of $$x$$ alone, say $$f(x),$$ then $$\text{I.F.}=e^{\int f(x)\,dx}.$$
  • This is the rule used in Exercise 3.8 Questions 2, 3, 4, and 5 in this set.

Rule II

  • If $$\dfrac{N_x-M_y}{M}$$ is a function of $$y$$ alone, say $$f(y),$$ then $$\text{I.F.}=e^{\int f(y)\,dy}.$$
  • This is the rule used in Exercise 3.8 Question 1 in this set.
Stable Route
Write $$Mdx+Ndy=0$$ → Show it is not exact → Test Rule I / Rule II → Multiply by integrating factor → Solve as exact

The memory trick is simple: the integrating factor is not the final answer. It is only the door that turns the equation into an exact one.
