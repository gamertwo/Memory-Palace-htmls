Exercise 3.13 Question 2

This one is already solved for $$p^2,$$ so we take square roots, integrate each branch, and absorb the sign into the constant.

$$x(1+p^2)=1$$

$$y=c-\sqrt{x-x^2}-\tan^{-1}\sqrt{\frac{1-x}{x}}$$
Ex 3.13 GuideOpen in Memory Builder
Quick Data
Solve For $$p$$
$$p=\pm\sqrt{\frac{1-x}{x}}$$
Integral
$$y=\int \pm\sqrt{\frac{1-x}{x}}\,dx$$
Convenient Form
$$\sin^{-1}\sqrt{x}=\frac\pi2-\tan^{-1}\sqrt{\frac{1-x}{x}}$$
Rooms: Full Solution

Room 1: Solve for $$p$$

  • From $$x(1+p^2)=1,$$ we get
  • $$p^2=\frac{1-x}{x},\qquad p=\pm\sqrt{\frac{1-x}{x}}.$$

Room 2: Integrate the Branch

  • So $$\dfrac{dy}{dx}=\pm\sqrt{\dfrac{1-x}{x}}.$$
  • Integrating gives
  • $$y=\pm\left(\sqrt{x-x^2}+\sin^{-1}\sqrt{x}\right)+c.$$

Room 3: Match the Textbook Form

  • Using $$\sin^{-1}\sqrt{x}=\dfrac\pi2-\tan^{-1}\sqrt{\dfrac{1-x}{x}},$$ the answer can be written as
  • $$y=c-\sqrt{x-x^2}-\tan^{-1}\sqrt{\frac{1-x}{x}}.$$
Solution Flow

Solve directly for $$p,$$ integrate the square-root branch, then rewrite the inverse-trig term into the textbook form.

Isolate $$p^2$$→Take square root→Integrate→Rewrite the trig term
