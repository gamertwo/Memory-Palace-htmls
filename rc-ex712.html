Foundation: What a Memory Palace Is Here

A memory palace is a familiar structure used to store and retrieve information in a fixed order. For this page, the palace is the solving route itself. Each station stores one part of the RL idea so you can mentally walk the same route every time.

Terminal room → switch action → initial current → final current → time constant → response → ODE

Principle 1: Do Not Trap Yourself

  • Start in a terminal location: the first question is always the switch action at t = 0.
  • From there, move outward in one direction only: pre-switch state, post-switch state, then equations.
  • That prevents you from jumping randomly between current, resistance, and formulas.

Principle 2: Do Not Cross Your Own Path

  • Never solve by bouncing back and forth between the old circuit and the new circuit.
  • First freeze the pre-switch circuit and get i(0).
  • Then move once into the post-switch circuit and get i(infinity) and R_N.
  • Only after that do you build the response and the ODE.

Principle 3: Peer Versus Enter

Instead of mentally “walking all over” the circuit, peer into each state as a snapshot.

  • Snapshot A: switch closed for a long time. Inductor is a short. Read i(0).
  • Snapshot B: switch open for a long time. Inductor is a short again. Read i(infinity).
  • Snapshot C: post-switch resistance seen by the inductor. Read R_N and then tau.

Principle 4: Select Stations With Care

Use fixed stations so each one stores exactly one piece of the solution. For this page, the best stations are:

  • Station 1: Switch action. What changed?
  • Station 2: Pre-switch steady state. What is i(0)?
  • Station 3: Post-switch steady state. What is i(infinity)?
  • Station 4: Resistance seen after switching. What is R_N?
  • Station 5: Time constant. What is tau = L / R_N?
  • Station 6: Universal response formula.
  • Station 7: Governing ODE.

Apply the Palace to This Circuit

Exercise 7-12

This page follows the same simplified study order for the RL switching case where the switch opens at $t=0$ after being closed for a long time.

$$i(t)=\left[\frac{V_A}{R_1}-\frac{V_A}{R_1+R_2}\right]e^{-(R_1+R_2)t/L}+\frac{V_A}{R_1+R_2},\quad t\ge 0$$
Rooms

Room 1: Recognize the Pattern

  • This is a first-order RL response in the standard form $$i(t)=\big[i(0)-i(\infty)\big]e^{-t/\tau}+i(\infty).$$
  • The current moves from the old steady state to the new steady state after the switch changes the circuit.

Room 2: Read the Initial Current

  • Before opening, the switch has been closed for a long time.
  • So the inductor is in DC steady state and behaves like a short circuit.
  • With the switch closed, $R_2$ is bypassed, so $$i(0)=\frac{V_A}{R_1}.$$

Room 3: Read the Final Current

  • After the switch opens, current must flow through both $R_1$ and $R_2$.
  • At long time, the inductor again behaves like a short circuit.
  • So the new DC current is $$i(\infty)=\frac{V_A}{R_1+R_2}.$$

Room 4: Extract the Time Constant $\tau$

  • For an RL circuit, $$\tau=\frac{L}{R_N}.$$
  • After the switch opens, the inductor sees $R_N=R_1+R_2$.
  • So $$\tau=\frac{L}{R_1+R_2}.$$
  • That makes the exponential $$e^{-t/\tau}=e^{-(R_1+R_2)t/L}.$$

Room 5: Build the Response

  • Use the universal first-order form $$i(t)=\big[i(0)-i(\infty)\big]e^{-t/\tau}+i(\infty).$$
  • Substitute the values:
  • $$i(t)=\left[\frac{V_A}{R_1}-\frac{V_A}{R_1+R_2}\right]e^{-(R_1+R_2)t/L}+\frac{V_A}{R_1+R_2},\quad t\ge 0.$$

Room 6: Split Into Forced + Natural Parts

  • Forced part = $$\frac{V_A}{R_1+R_2}.$$
  • Natural part = $$\left[\frac{V_A}{R_1}-\frac{V_A}{R_1+R_2}\right]e^{-(R_1+R_2)t/L}.$$
  • The bracket is the gap between the old steady current and the new steady current.

Room 7: Rebuild the Governing First-Order ODE

  • Standard RL form: $$\tau\frac{di}{dt}+i=i(\infty)u(t).$$
  • Substitute $$\tau=\frac{L}{R_1+R_2}\quad \text{and}\quad i(\infty)=\frac{V_A}{R_1+R_2}.$$
  • So the governing equation is $$\frac{L}{R_1+R_2}\frac{di}{dt}+i=\frac{V_A}{R_1+R_2}u(t),\quad t\ge 0.$$

Room 8: Quick Verification

  • Let $$B=\frac{V_A}{R_1}-\frac{V_A}{R_1+R_2}.$$ Then $$i(t)=Be^{-(R_1+R_2)t/L}+\frac{V_A}{R_1+R_2}.$$
  • Differentiate: $$\frac{di}{dt}=B\left(-\frac{R_1+R_2}{L}\right)e^{-(R_1+R_2)t/L}.$$
  • Now compute the left side:
  • $$\frac{L}{R_1+R_2}\frac{di}{dt}+i=-Be^{-(R_1+R_2)t/L}+Be^{-(R_1+R_2)t/L}+\frac{V_A}{R_1+R_2}=\frac{V_A}{R_1+R_2}.$$
  • So the left side matches the right side $$\frac{V_A}{R_1+R_2}u(t)$$ for $t>0$.
Memory Clues

Clue 1

For first-order RL, always lock in $i(0)$, $i(\infty)$, and $\tau=L/R_N$ before writing anything else.

Clue 2

Closed switch here means $R_2$ is bypassed. Open switch means $R_2$ is back in the path.

Clue 3

The resistor seen after the switch action sets the time constant.

Clue 4

The exponential coefficient is always the gap: initial steady value minus final steady value.
