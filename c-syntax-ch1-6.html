Rooms

Room 1: Program Skeleton

  • Start with preprocessor directives like #include <stdio.h>.
  • Every C program begins execution in int main(void).
  • Statements end with semicolons, but #define lines do not.
  • Braces group blocks of statements, and comments use // or /* ... */.
#include <stdio.h>
#define PI 3.14159

int main(void) {
  /* program starts here */
  return 0;
}

Room 2: Standard I/O

  • printf prints formatted output.
  • scanf reads input, and non-array variables need the address operator.
  • puts prints a string with a newline.
  • getchar reads one character, putchar writes one character, and fgets safely reads a full line.
int age;
char name[40];

printf("Enter age: ");
scanf("%d", &age);
fgets(name, 40, stdin);

Room 3: Operators and Expressions

  • Arithmetic uses +, -, *, /, and %.
  • Assignments include =, +=, -=, *=, /=, and %=.
  • Comparisons use >, <, >=, <=, ==, and !=.
  • Logic uses &&, ||, and !. Increment and decrement use ++ and --.
  • The ternary operator is (condition) ? true_value : false_value, and sizeof(type) returns byte size.

Room 4: Selection Statements

  • Use if for one-way decisions and if ... else for two-way decisions.
  • Use switch when testing one integer or character expression against many constant cases.
  • break usually ends each case so execution does not fall through accidentally.
if (score >= 50) {
  puts("Pass");
} else {
  puts("Fail");
}

switch (grade) {
  case 'A':
    puts("Excellent");
    break;
  default:
    puts("Keep working");
}

Room 5: Loops and Flow Control

  • while checks first, then repeats.
  • for (init; cond; inc) is strongest when counting.
  • do ... while runs at least once because the test comes last.
  • break exits a loop immediately, while continue skips to the next iteration.
for (i = 0; i < 10; i++) {
  if (i == 4) {
    continue;
  }
  if (i == 8) {
    break;
  }
}

Room 6: Functions

  • A prototype declares the function before use.
  • The definition gives the parameter names and the body.
  • The return statement sends a value back for non-void functions.
int square(int number);

int square(int number) {
  return number * number;
}

Room 7: Random Numbers and Libraries

  • #include <stdlib.h> gives access to rand() and srand().
  • rand() returns a pseudo-random integer.
  • srand(seed) initializes the generator, often with time(NULL).
#include <stdlib.h>
#include <time.h>

srand((unsigned int) time(NULL));
value = rand();

Room 8: Math Functions

  • #include <math.h> exposes core math helpers.
  • pow(x, y) raises x to the power y.
  • sqrt(x), fabs(x), ceil(x), and floor(x) handle roots, absolute values, and rounding.
double a = pow(2.0, 3.0);
double b = sqrt(49.0);
double c = fabs(-7.25);
double d = ceil(3.14);
double e = floor(3.14);

Room 9: Arrays and Strings

  • An array declaration reserves contiguous storage, for example int values[5];.
  • Initialization can set every element explicitly or zero the whole array with {0}.
  • Subscripts begin at 0, so the last valid index is size - 1.
  • Two-dimensional arrays use row and column brackets.
  • A string is a character array that ends with the null character '\0'.
int values[5] = {1, 2, 3, 4, 5};
int zeros[5] = {0};
int table[3][4];
char word[6] = "Hello";

Room 10: Format Specifiers and Escapes

  • Core specifiers include %d, %f, %lf, %c, %s, and %zu.
  • Escape sequences include \n, \t, \a, \\, and \".
  • These are essential for correct formatted input, output, and readable text layout.
printf("Name:\t%s\n", name);
printf("Path: C:\\\\temp\\\\file.txt\n");
printf("Quote: \"C syntax\"\n");

High-Frequency Mistakes

Keep four traps active in memory: missing semicolons, writing = when you meant ==, forgetting & in scanf, and reading outside valid array indexes.

One-Pass Recall

Compressed Memory Rule

Think in one chain: the program starts with #include and main, talks through printf and scanf, decides with if or switch, repeats with loops, organizes work into functions, pulls helpers from stdlib.h and math.h, stores data in arrays, and prints everything correctly with format specifiers and escapes.

Memory Palace Path

Walk the language from the front door of a program to the last console print. Each station exists because the previous one forces it.

Station 1: Program Gate

Store #include, main, semicolons, braces, constants, and comments.

Transition 1 to 2

Once a program exists, it has to talk to the user through the console.

Station 2: Console Desk

Hold printf, scanf, puts, getchar, putchar, and fgets.

Transition 2 to 3

After input and output, expressions must be built from operators.

Station 3: Operator Bench

Keep arithmetic, assignment, comparison, logical, increment, ternary, and sizeof.

Transition 3 to 4

Once conditions exist, the next question is how the program decides where to go.

Station 4: Decision Fork

Choose between if, if ... else, and switch.

Transition 4 to 5

After decisions, the code often needs repetition.

Station 5: Loop Track

Walk through while, for, do ... while, break, and continue.

Transition 5 to 6

Repeated logic should be packaged, so functions become the next stop.

Station 6: Function Office

Prototype first, define second, return a value if needed.

Transition 6 to 7

Functions often depend on libraries, so the route moves to helper shelves.

Station 7: Library Shelf

Put random-number tools in stdlib.h and math tools in math.h.

Transition 7 to 8

Once helpers are available, data needs a place to live.

Station 8: Array Warehouse

Store one-dimensional arrays, two-dimensional tables, and null-terminated strings.

Transition 8 to 9

The last step is presenting and reading data correctly.

Station 9: Format Terminal

Keep specifiers like %d and escapes like \n ready for final output.
