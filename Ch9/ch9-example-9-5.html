Example 9-5: Derive The Sine Transform From Euler Form

Start with the Euler identity for sine:

$$\sin(\beta t)=\frac{e^{j\beta t}-e^{-j\beta t}}{2j}$$

Multiply by $$A$$ and include the causal support:

$$f(t)=A\sin(\beta t)u(t)=A\frac{e^{j\beta t}-e^{-j\beta t}}{2j}u(t)$$

Apply linearity:

$$\mathcal{L}\{A\sin(\beta t)u(t)\}=\frac{A}{2j}\left[\mathcal{L}\{e^{j\beta t}u(t)\}-\mathcal{L}\{e^{-j\beta t}u(t)\}\right]$$

Transform each exponential:

$$\mathcal{L}\{e^{j\beta t}u(t)\}=\frac{1}{s-j\beta},\qquad \mathcal{L}\{e^{-j\beta t}u(t)\}=\frac{1}{s+j\beta}$$

So

$$F(s)=\frac{A}{2j}\left[\frac{1}{s-j\beta}-\frac{1}{s+j\beta}\right]$$

Use the common denominator:

$$\frac{1}{s-j\beta}-\frac{1}{s+j\beta}=\frac{(s+j\beta)-(s-j\beta)}{(s-j\beta)(s+j\beta)}=\frac{2j\beta}{s^2+\beta^2}$$

Now cancel $$2j$$:

$$F(s)=\frac{A}{2j}\cdot\frac{2j\beta}{s^2+\beta^2}=\frac{A\beta}{s^2+\beta^2}$$

Exercise 9-5: Substitute The Numbers Directly

The known pattern is

$$\mathcal{L}\{A\sin(\beta t)u(t)\}=\frac{A\beta}{s^2+\beta^2}$$

For $$i(t)=100\sin(200t)u(t),$$ identify

$$A=100,\qquad \beta=200$$

Substitute into the numerator:

$$A\beta=100\times200=20000$$

Substitute into the denominator:

$$\beta^2=200^2=40000$$

So

$$I(s)=\frac{20000}{s^2+40000}$$

Exercise 9-6: Derive The Cosine Transform Carefully

Use Euler form for cosine:

$$\cos(\beta t)=\frac{e^{j\beta t}+e^{-j\beta t}}{2}$$

Multiply by $$A$$ and transform:

$$\mathcal{L}\{A\cos(\beta t)u(t)\}=\frac{A}{2}\left[\mathcal{L}\{e^{j\beta t}u(t)\}+\mathcal{L}\{e^{-j\beta t}u(t)\}\right]$$

Replace each exponential transform:

$$F(s)=\frac{A}{2}\left[\frac{1}{s-j\beta}+\frac{1}{s+j\beta}\right]$$

Use the common denominator:

$$\frac{1}{s-j\beta}+\frac{1}{s+j\beta}=\frac{(s+j\beta)+(s-j\beta)}{(s-j\beta)(s+j\beta)}=\frac{2s}{s^2+\beta^2}$$

Now cancel the 2:

$$F(s)=\frac{A}{2}\cdot\frac{2s}{s^2+\beta^2}=\frac{As}{s^2+\beta^2}$$

A glowing oscillation orb swings across the timeline road. It splits into two opposite rotation streams, one clockwise and one counterclockwise. When the two transformed streams recombine, the top becomes a pure beta-frequency core and the base locks into the twin rotation denominator.

Exercise 9-6: Cosine Keeps The Same Base But Leaves s On Top

The cosine orb starts at maximum displacement. It splits into the same opposite rotations, but this time the branches add instead of subtracting. The shared center pull survives as an $$s$$ vortex core, while the denominator base stays the same twin-rotation platform.

  • Cosine uses the same denominator as sine.
  • Cosine leaves $$s$$ on top instead of $$\beta.$$
