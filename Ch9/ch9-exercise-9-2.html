Exercise 9-2

Eight Glowing Bands Wrap The Five-Mark Pillar

This is the direct practice version of the collared-vortex transform. Set $$\alpha=5,$$ keep the same denominator structure, then wrap eight bright bands around the top pillar to store the multiplier 8.

$$v(t)=8e^{-5t}u(t), \qquad V(s)=\mathcal{L}\{8e^{-5t}u(t)\}=\frac{8}{s+5}$$
Shape Guide Open In Builder
Quick Result
Base fact
$$\mathcal{L}\{e^{-\alpha t}u(t)\}=\dfrac{1}{s+\alpha}$$
Substitute
Here $$\alpha=5,$$ so the base becomes $$1/(s+5).$$
Answer
$$V(s)=\dfrac{8}{s+5}$$
Linear Review: Actual Concept First
Linear Room 1

Start From The Exponential-Decay Form

From Example 9-2, we know

$$\mathcal{L}\{e^{-\alpha t}u(t)\}=\frac{1}{s+\alpha}$$

Linear Room 2

Insert The Specific Value Of $$\alpha$$

In this problem, $$\alpha=5.$$ So

$$\mathcal{L}\{e^{-5t}u(t)\}=\frac{1}{s+5}$$

Linear Room 3

Apply Linearity For The Multiplier 8

The full signal is $$8e^{-5t}u(t).$$

Use the constant-multiple rule:

$$V(s)=8\mathcal{L}\{e^{-5t}u(t)\}$$

Linear Room 4

Freeze The Final Fraction

Substitute the known transform:

$$V(s)=8\left(\frac{1}{s+5}\right)$$

Therefore,

$$V(s)=\frac{8}{s+5}$$

Concept Summary

This is the clean parameter-substitution exercise. First change $$\alpha$$ into 5, then let the top multiplier 8 scale the result.
