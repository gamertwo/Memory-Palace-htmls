Example 9-7: Get Cosine By Differentiating Sine

Start from the identity

$$\cos\beta t=\frac{1}{\beta}\frac{d}{dt}\sin\beta t$$

You already know

$$\mathcal{L}\{\sin\beta t\,u(t)\}=\frac{\beta}{s^2+\beta^2}$$

Apply the differentiation property:

$$\mathcal{L}\left\{\frac{d}{dt}\sin\beta t\right\}=s\frac{\beta}{s^2+\beta^2}-\sin(0^-)$$

The pre-zero value is zero:

$$\sin(0^-)=0$$

Now include the factor $$1/\beta$$:

$$\mathcal{L}\{\cos\beta t\,u(t)\}=\frac{1}{\beta}\left[s\frac{\beta}{s^2+\beta^2}-0\right]=\frac{s}{s^2+\beta^2}$$

Exercise 9-9: Differentiate The Ramp Back Into A Step

Because $$r(t)=tu(t),$$ the first signal is

$$v_1(t)=V_Ar(t)=V_Atu(t)$$

Its Laplace transform is

$$V_1(s)=\frac{V_A}{s^2}$$

Now differentiate in time:

$$v_2(t)=\frac{d}{dt}[V_Atu(t)]=V_Au(t)$$

So directly,

$$\mathcal{L}\{v_2(t)\}=\mathcal{L}\{V_Au(t)\}=\frac{V_A}{s}$$

Check with the derivative property:

$$sV_1(s)-v_1(0^-)=s\frac{V_A}{s^2}-0=\frac{V_A}{s}$$

Exercise 9-10: Differentiate The Exponential Then Apply The Scale

Given

$$i(t)=30e^{-1200t}u(t),\qquad v(t)=0.1\frac{di(t)}{dt}$$

First transform the current:

$$I(s)=\frac{30}{s+1200}$$

Apply the differentiation property:

$$\mathcal{L}\left\{\frac{di(t)}{dt}\right\}=sI(s)-i(0^-)$$

Because the signal is causal, the pre-zero value is

$$i(0^-)=0$$

So

$$\mathcal{L}\left\{\frac{di(t)}{dt}\right\}=s\frac{30}{s+1200}$$

Now multiply by 0.1:

$$V(s)=0.1\cdot s\frac{30}{s+1200}=\frac{3s}{s+1200}$$
