Example 9-6: Build The Ramp By Integrating The Step

The ramp can be produced from the unit step by integration:

$$r(t)=tu(t)=\int_0^t u(\tau)\,d\tau$$

You already know

$$\mathcal{L}\{u(t)\}=\frac{1}{s}$$

Use the integration property:

$$\mathcal{L}\left\{\int_0^t f(\tau)\,d\tau\right\}=\frac{F(s)}{s}$$

Here $$f(\tau)=u(\tau),$$ so

$$\mathcal{L}\{r(t)\}=\frac{1}{s}\mathcal{L}\{u(t)\}=\frac{1}{s}\cdot\frac{1}{s}=\frac{1}{s^2}$$

Exercise 9-7: Integrate The Exponential Signal First, Then Transform

Start from

$$v_1(t)=V_Ae^{-\alpha t}u(t),\qquad v_2(t)=\int_0^t V_Ae^{-\alpha x}\,dx$$

Evaluate the integral in time:

$$v_2(t)=V_A\int_0^t e^{-\alpha x}\,dx=V_A\left[\frac{-1}{\alpha}e^{-\alpha x}\right]_0^t=\frac{V_A}{\alpha}(1-e^{-\alpha t})$$

Now transform:

$$\mathcal{L}\{v_2(t)\}=\frac{V_A}{\alpha}\left[\frac{1}{s}-\frac{1}{s+\alpha}\right]$$

Use a common denominator:

$$\frac{1}{s}-\frac{1}{s+\alpha}=\frac{(s+\alpha)-s}{s(s+\alpha)}=\frac{\alpha}{s(s+\alpha)}$$

So

$$\mathcal{L}\{v_2(t)\}=\frac{V_A}{\alpha}\cdot\frac{\alpha}{s(s+\alpha)}=\frac{V_A}{s(s+\alpha)}$$

Since $$V_1(s)=\frac{V_A}{s+\alpha},$$ it follows that

$$\frac{V_1(s)}{s}=\frac{V_A}{s(s+\alpha)}$$

Exercise 9-8: Integrate Then Apply The Scale Factor Carefully

Given

$$i(t)=6e^{-1000t}u(t),\qquad v(t)=\frac{1}{10^{-6}}\int_0^t i(x)\,dx$$

First transform the current:

$$I(s)=\frac{6}{s+1000}$$

Integrating once divides by $$s$$:

$$\mathcal{L}\left\{\int_0^t i(x)\,dx\right\}=\frac{I(s)}{s}=\frac{6}{s(s+1000)}$$

Now include the scale factor. In the book's unit handling, the final result is written as

$$V(s)=\frac{I(s)}{10^{-6}s}=\frac{6}{s+1000}\cdot\frac{1}{10^{-6}s}=\frac{6000}{s(s+1000)}$$

Example 9-6: Integrate The Step Once To Get The Ramp

Begin on the flat white ground of $$u(t).$$ Sweep forward with the curved integration blade. The flat ground accumulates height as you walk and turns into a rising ramp road. In transform space the old $$1/s$$ image drops onto one extra vortex layer and becomes $$1/s^2.$$

Exercise 9-7: Drop The Exponential Structure Onto One More Layer

Start from the old exponential form $$V_A/(s+\alpha).$$ Use the integration sweep once more and the whole structure drops onto a plain vortex layer under the collared vortex. The top VA core stays the same, but the base becomes $$s(s+\alpha).$$

  • Integrating an exponential adds one plain $$s$$ layer below the old base.
  • The top VA core does not change.
  • The final image is $$V_A$$ over $$s(s+\alpha).$$

Exercise 9-8: The Integrated Exponential Passes Through An Amplifier

  • Same integration move as before.
  • The large scale factor changes only the top.
  • The final image is $$6000$$ over $$s(s+1000).$$
