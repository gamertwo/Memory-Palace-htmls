Example 9-2

A Gold Decay Ring Locks Onto The Old Vortex

This page reuses the step-ground story but adds one new object: a gold decay ring labeled $$\alpha.$$ Once that ring fuses with the old $$s$$-vortex, the denominator shifts from $$s$$ to $$s+\alpha.$$

$$f(t)=e^{-\alpha t}u(t), \qquad F(s)=\mathcal{L}\{e^{-\alpha t}u(t)\}=\frac{1}{s+\alpha}$$

Linear Review: Actual Concept First
Linear Room 1

Insert The Signal Into The Definition

Start from

$$F(s)=\int_0^{\infty} f(t)e^{-st}\,dt$$

Now substitute $$f(t)=e^{-\alpha t}u(t).$$ Because $$u(t)=1$$ for $$t\ge0,$$

$$F(s)=\int_0^{\infty} e^{-\alpha t}e^{-st}\,dt$$

Linear Room 2

Combine The Exponentials

Since both factors are exponentials in $$t,$$ combine them:

$$e^{-\alpha t}e^{-st}=e^{-(s+\alpha)t}$$

So the integral becomes

$$F(s)=\int_0^{\infty} e^{-(s+\alpha)t}\,dt$$

Linear Room 3

Integrate And Apply The Limits

The antiderivative is

$$\int e^{-(s+\alpha)t}\,dt=-\frac{e^{-(s+\alpha)t}}{s+\alpha}$$

Therefore,

$$F(s)=\left[-\frac{e^{-(s+\alpha)t}}{s+\alpha}\right]_0^{\infty}$$

Linear Room 4

Use The Same Infinity And Zero Logic

At $$t\to\infty,$$ the exponential term goes to zero provided $$\Re\{s\}>-\alpha.$$

At $$t=0,$$ the exponential becomes 1.

So

$$F(s)=0-\left(-\frac{1}{s+\alpha}\right)=\frac{1}{s+\alpha}$$

Concept Summary

This example keeps the unit-step skeleton but strengthens the decay. The only real upgrade is that the denominator now carries the combined pull $$s+\alpha.$$
