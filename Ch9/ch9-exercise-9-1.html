Exercise 9-1

Seven Chains Drag The Old Pillar Down

This exercise is the same unit-step base image with one clean change: seven heavy chains pull the pillar downward. The denominator stays the same, so the whole memory cue is about scale and sign, not a new transform structure.

$$v(t)=-7u(t), \qquad V(s)=\mathcal{L}\{-7u(t)\}=-\frac{7}{s}$$

Quick Result

$$\mathcal{L}\{u(t)\}=\dfrac{1}{s}$$
Linearity
$$\mathcal{L}\{Kf(t)\}=K F(s)$$

$$V(s)=-\dfrac{7}{s}$$
Linear Review: Actual Concept First
Linear Room 1

Start From The Known Step Transform

From Example 9-1, we already know

$$\mathcal{L}\{u(t)\}=\frac{1}{s}$$

Linear Room 2

Use The Constant-Multiple Rule

The signal is not just $$u(t).$$ It is $$-7u(t).$$

Use linearity:

$$\mathcal{L}\{Kf(t)\}=K\mathcal{L}\{f(t)\}$$

Linear Room 3

Apply The Multiplier Directly

So

$$V(s)=\mathcal{L}\{-7u(t)\}=-7\mathcal{L}\{u(t)\}$$

Then substitute the known result:

$$V(s)=-7\left(\frac{1}{s}\right)$$

Linear Room 4

Freeze The Final Fraction

Therefore,

$$V(s)=-\frac{7}{s}$$

The denominator stays $$s$$ because the underlying step transform did not change. Only the sign and magnitude changed.

Concept Summary

This is the fastest possible linearity exercise. Start from $$1/s,$$ then let the multiplier $$-7$$ act on the whole transform at once.

Rooms: Same Ground, Heavier Result

Room 1: Start From The Old $$1/s$$ Picture

Begin with the final picture from Example 9-1: the white pillar standing above the spiral vortex. Nothing about the base transform has changed yet.

  • Same unit-step denominator.
  • Same pillar-over-vortex structure.
  • Reuse the old image before adding the multiplier.

Room 2: Seven Black Chains Fall From Above

Seven heavy black chains hook onto the pillar. Those chains are the multiplier 7 and they make the magnitude feel much heavier than the plain unit pillar.

  • Seven chains means 7.
  • The chains attach to the top object, not the denominator.
  • This is a scale change, not a structural change.

Room 3: The Chains Drag The Pillar Downward

The whole pillar is pulled downward, flipping the emotional direction of the result. That downward drag stores the minus sign.

  • Downward pull means negative.
  • The sign changes the feeling of the top object.
  • The vortex below does not move.

Room 4: The Vortex Stays The Same

The denominator is still the same dark $$s$$-vortex because the signal type is still just a scaled unit step. The final frozen image is the chain-dragged pillar over the vortex, which is $$-7/s.$$

  • Same denominator, new top value.
  • Think scale-and-sign only.
  • The result is $$-7/s.$$
