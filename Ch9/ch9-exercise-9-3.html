Linear Review: Actual Concept First
Linear Room 1

Start From The Basic Impulse Transform

From Example 9-3, we already know

$$\mathcal{L}\{\delta(t)\}=1$$

Linear Room 2

Use The Constant-Multiple Rule

The actual signal is $$0.5\delta(t).$$

So apply linearity:

$$I(s)=\mathcal{L}\{0.5\delta(t)\}=0.5\mathcal{L}\{\delta(t)\}$$

Linear Room 3

Substitute The Known Result

Now insert the base transform:

$$I(s)=0.5(1)$$

Linear Room 4

Freeze The Final Number

Therefore,

$$I(s)=0.5$$

There is no denominator because the impulse transform itself is already just a constant.
