Design Example 7-25

Design a series RLC circuit whose zero-state capacitor-voltage step response is $$v_C(t)=V_A-\frac{5}{4}V_Ae^{-400t}+\frac{1}{4}V_Ae^{-2000t},\ t\ge0.$$ Read the poles from the waveform, build the required characteristic equation, and choose one valid component set.

$$v_C(t)=V_A-\frac{5}{4}V_Ae^{-400t}+\frac{1}{4}V_Ae^{-2000t}$$ $$s^2+2400s+8\times10^5=0,\qquad \frac{R}{L}=2400,\quad \frac{1}{LC}=8\times10^5$$
Quick Data
Final Value
$$v_C(\infty)=V_A$$
Poles
$$s_1=-400,\quad s_2=-2000$$
Series Form
$$s^2+\frac{R}{L}s+\frac{1}{LC}=0$$
One Choice
$$R=3\ \text{k}\Omega$$
Solved L
$$L=1.25\ \text{H}$$
Solved C
$$C=1\ \mu\text{F}$$
Answer Board
Required Equation
$$\boxed{s^2+2400s+8\times10^5=0}$$
Constraint 1
$$\frac{R}{L}=2400$$
Constraint 2
$$\frac{1}{LC}=8\times10^5$$
One Valid Design
$$\boxed{R=3\ \text{k}\Omega,\ L=1.25\ \text{H},\ C=1\ \mu\text{F}}$$
Rooms

Room 1: Read the Target Poles

  • The response contains two distinct exponentials.
  • Those exponentials reveal the roots directly: $$-400$$ and $$-2000.$$

Room 2: Build the Numerical Polynomial

  • Multiply the factors from the roots:
  • $$(s+400)(s+2000)=s^2+2400s+8\times10^5.$$

Room 3: Match the Series RLC Form

  • For a series RLC circuit, the characteristic equation is $$s^2+\frac{R}{L}s+\frac{1}{LC}=0.$$
  • Matching coefficients gives $$R/L=2400$$ and $$1/(LC)=8\times10^5.$$

Room 4: Choose a Convenient Component

  • There are three circuit parameters and only two constraints.
  • Choose $$R=3\ \text{k}\Omega$$ to make the arithmetic clean.

Room 5: Solve for L and C

  • From $$R/L=2400,$$ $$L=3000/2400=1.25\ \text{H}.$$
  • From $$1/(LC)=8\times10^5,$$ $$C=1/((1.25)(8\times10^5))=1\ \mu\text{F}.$$

Room 6: Final Design Logic

  • The chosen set satisfies both coefficient conditions.
  • Many other designs are possible because one component can be selected freely.

Fast Memory Rule

For design-from-waveform problems, read the poles first. The target response fixes the polynomial before the components are chosen.
