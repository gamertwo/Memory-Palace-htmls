Exercise 7-29

Keep the series RLC step-response setup from Example 7-22, but vary the capacitor instead of the resistor. The goal is to track how the capacitor sweep changes the capacitor voltage waveform, the damping ratio, and the natural frequency.

$$\omega_n=\frac{1}{\sqrt{LC}},\qquad \zeta=\frac{R}{2}\sqrt{\frac{C}{L}}$$ $$R=1\ \text{k}\Omega,\quad L=2\ \text{H},\quad V_A=10\ \text{V},\quad v_C(0)=-5\ \text{V},\quad i(0)=0$$
Quick Data
Fixed Resistance
$$R=1\ \text{k}\Omega$$
Fixed Inductance
$$L=2\ \text{H}$$
Nominal Capacitance
$$C=0.5\ \mu\text{F}$$
Critical Capacitance
$$C_{\text{crit}}=\frac{4L}{R^2}=8\ \mu\text{F}$$
Natural Frequency Trend
Increasing $$C$$ decreases $$\omega_n.$$
Damping Trend
Increasing $$C$$ increases $$\zeta.$$
Answer Board
Case C
If $$C<8\ \mu\text{F},$$ the response is underdamped and oscillatory.
Case B
If $$C=8\ \mu\text{F},$$ the response is critically damped.
Case A
If $$C>8\ \mu\text{F},$$ the response is overdamped.
Main Conclusion
Increasing $$C$$ lowers the oscillation frequency and raises the damping ratio, so both the wiggle spacing and the decay character change.
Capacitor Sweep Plot
$$C=0.5\ \mu\text{F}$$, Case C
$$C=8\ \mu\text{F}$$, Case B
$$C=20\ \mu\text{F}$$, Case A

This plot is generated from the state equations $$\dot v_C=i/C$$ and $$\dot i=(V_A-Ri-v_C)/L$$ with the shared initial conditions $$v_C(0)=-5\ \text{V}$$ and $$i(0)=0.$$ It shows the same trend stated in the textbook answer: bigger $$C$$ pushes the system from underdamped to critical to overdamped while also reducing the oscillation frequency.

Rooms

Room 1: Start from the Same Series RLC Model

  • The capacitor voltage satisfies
  • $$\frac{d^2v_C}{dt^2}+\frac{R}{L}\frac{dv_C}{dt}+\frac{1}{LC}v_C=\frac{V_A}{LC}.$$
  • Only $$C$$ is changing in this exercise.

Room 2: Separate What Stays Fixed

  • With $$R=1\ \text{k}\Omega$$ and $$L=2\ \text{H},$$ the damping coefficient is fixed at
  • $$\alpha=\frac{R}{2L}=250\ \text{rad/s}. $$
  • That means the resistor is no longer the sweep knob.

Room 3: Track the Natural Frequency

  • The natural frequency is
  • $$\omega_n=\frac{1}{\sqrt{LC}}.$$
  • So increasing $$C$$ makes $$\omega_n$$ smaller.
  • The oscillation spacing grows wider as the capacitor gets larger.

Room 4: Track the Damping Ratio

  • The damping ratio is
  • $$\zeta=\frac{\alpha}{\omega_n}=\frac{R}{2}\sqrt{\frac{C}{L}}.$$
  • So increasing $$C$$ makes $$\zeta$$ larger.
  • This is why the response becomes less oscillatory as $$C$$ increases.

Room 5: Find the Critical Boundary

  • Critical damping occurs at $$\zeta=1.$$
  • Solving gives
  • $$C_{\text{crit}}=\frac{4L}{R^2}=8\ \mu\text{F}. $$
  • That divides the sweep into Cases C, B, and A.

Room 6: Classify the Three Representative Curves

  • $$C=0.5\ \mu\text{F} < 8\ \mu\text{F}$$ gives Case C, underdamped.
  • $$C=8\ \mu\text{F}$$ gives Case B, critically damped.
  • $$C=20\ \mu\text{F} > 8\ \mu\text{F}$$ gives Case A, overdamped.

Room 7: Compare This Sweep with the Resistor Sweep

  • Changing $$R$$ mainly changes damping because $$\omega_n=1/\sqrt{LC}$$ stays fixed.
  • Changing $$C$$ changes both $$\zeta$$ and $$\omega_n.$$
  • So the envelope and the oscillation spacing both move.

Room 8: Final Memory Pattern

  • Bigger capacitor means slower natural rhythm and heavier damping.
  • The sweep direction is
  • $$\text{Case C} \rightarrow \text{Case B} \rightarrow \text{Case A}$$
  • as $$C$$ increases through the critical value.

Fast Memory Rule

For this series RLC family, increasing $$C$$ pulls the natural frequency down and pushes the damping ratio up. That is why the waveform both slows down and loses its oscillation as the capacitor grows.
