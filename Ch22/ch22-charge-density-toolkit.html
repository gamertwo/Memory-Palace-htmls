Bridge Page

Charge Density Toolkit

This is the bridge page for every continuous-distribution derivation in Chapter 22. The field of a rod, ring, disk, or volume charge is never found in one jump. You first carve out a tiny source element, write its charge correctly with a density symbol, build $$d\vec E$$ from Coulomb's law, remove the parts cancelled by symmetry, and then integrate what survives.

$$dq=\lambda\,dl,\qquad dq=\sigma\,dA,\qquad dq=\rho\,dV,\qquad d\vec E=\frac{1}{4\pi\epsilon_0}\frac{dq}{r^2}\hat r$$
Major GuideOpen in Memory Builder
Density Choices
Line Density
$$\lambda=\dfrac{dq}{dl}$$ for rods, rings, and arcs.
Surface Density
$$\sigma=\dfrac{dq}{dA}$$ for disks and sheets.
Volume Density
$$\rho=\dfrac{dq}{dV}$$ for 3D charge distributions.
Core Move
Pick the correct slice first, then write its charge.
Rooms: Setup Pattern

Room 1: Choose One Tiny Source Piece

  • Do not attack the whole object at once.
  • Instead carve out one tiny piece that is small enough to behave like a point charge.
  • This tiny piece is the object that produces $$d\vec E.$$

Why This Step

Coulomb's law is a point-charge law. We make a continuous object compatible with that law by shrinking it into tiny pieces first.

Room 2: Match the Object to the Right Density Symbol

  • If the source is one-dimensional, use $$\lambda.$$
  • If it spreads over an area, use $$\sigma.$$
  • If it fills a volume, use $$\rho.$$

Why This Step

The density symbol tells you what kind of slice the object naturally wants. This is how the math stays faithful to the geometry.

Room 3: Write $$dq$$ from the Slice Geometry

  • For a rod piece, $$dq=\lambda\,dx.$$
  • For a ring strip inside a disk, $$dq=\sigma(2\pi r\,dr).$$
  • The differential charge must come from both density and the actual slice size.

Why This Step

This is where the physical object enters the formula. Without the correct $$dq,$$ the integral may still look elegant but it will describe the wrong object.

Room 4: Build the Differential Field

  • Use the point-charge rule on that tiny piece:
  • $$d\vec E=\dfrac{1}{4\pi\epsilon_0}\dfrac{dq}{r^2}\hat r.$$
  • Then rewrite distance and direction using the geometry of the problem.

Why This Step

Now the tiny source element is treated exactly like a point charge. This is the moment where geometry and Coulomb's law meet.

Room 5: Remove the Parts Symmetry Will Kill

  • Split $$d\vec E$$ into components if the source is symmetric.
  • Opposite pieces often cancel sideways parts automatically.
  • Only the surviving component should be integrated.

Why This Step

Symmetry is not decoration. It is the reason many nasty vector integrals collapse into one clean scalar integral.

Room 6: Integrate the Survivor

  • Once only one component remains, integrate it over the full source.
  • Then rewrite the result in terms of total charge or a clean density form.
  • Finally check a physical limit when possible.

Why This Step

The integral is the last step, not the first idea. By the time you integrate, the source slice, geometry, and symmetry should already be settled.
