API correction

`https://api.mangadex.org/docs.html` is a documentation page, so `response.json()` will fail there. The actual JSON search endpoint is `https://api.mangadex.org/manga` with query params such as `title`, `limit`, `includes[]`, and `availableTranslatedLanguage[]`.

Last request https://api.mangadex.org/manga?title=one%20piece&limit=8&includes[]=cover_art

The page searches titles, pulls cover art relationships, and links each result back to MangaDex.
