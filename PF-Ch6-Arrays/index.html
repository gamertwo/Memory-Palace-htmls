Recall the fixed image for the syntax family first.

2. Skeleton

Say the code shape aloud before writing the exact names.

3. Logic

Ask what changes each iteration: sum, max, count, swap, or found index.

4. Dry Run

Trace with three values so off-by-one mistakes show up immediately.
