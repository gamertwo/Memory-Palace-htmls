Strings + Handoff

Character Arrays And Functions

This page trains the memory that usually breaks under pressure: strings are arrays of characters ending with a null terminator, array names travel to functions without brackets in the call, and read-only arrays should use const.

Guideline Page
Quick Data
String Rule
char name[20]; ends with '\\0'
Safe Input
scanf("%19s", name);
Function Style
void printArray(const int arr[], int size)
Rooms: Full Flow

Room 1: A String Is A Char Array

  • In C, a string is just a character array.
  • The last character must be the null terminator '\\0'.
  • That is why a 5-letter word needs 6 slots.
Room Code
char string1[] = "first";
char string2[] = {'f', 'i', 'r', 's', 't', '\0'};

Room 2: Safe scanf Syntax

  • If the array has 20 slots, read at most 19 visible characters.
  • Use scanf("%19s", name);
  • The last slot is reserved for the null terminator.
Room Code
char name[20];
scanf("%19s", name);

Room 3: Characters Behave Like Array Elements

  • You can access individual characters with word[i].
  • You can modify a character with an assignment such as word[0] = 'J';
  • Strings still obey indexing rules.
Room Code
char word[] = "HELLO";
printf("%c\n", word[0]);
word[0] = 'J';

Room 4: Passing Arrays To Functions

  • Write the parameter like int arr[] or const int arr[].
  • Pass the array in the call as printArray(numbers, SIZE);
  • The array is handed over with its size.
Room Code
void printArray(const int arr[], int size);

printArray(numbers, SIZE);

Room 5: Protect What Should Not Change

  • Use const in the function parameter when the function should only read the array.
  • Passing the whole array can affect the original data.
  • Passing a single element sends only a value copy.
Room Code
void modifyArray(int a[], int size) { a[0] = 100; }
void modifyElement(int x) { x = 100; }

Code Block To Rehearse

#include <stdio.h>

void printArray(const int arr[], int size) {
    for (int i = 0; i < size; ++i) {
        printf("%d ", arr[i]);
    }
}

int main(void) {
    char name[20];
    scanf("%19s", name);
    return 0;
}
