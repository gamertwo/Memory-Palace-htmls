Arrays Basics

This page trains the syntax flow that lets you write basic array code from memory: declare the container, respect the bounds, fill the slots, then sweep through them with a loop.

Guideline Page
Quick Data
Core Syntax
type name[size];
Valid Indices
0 to size - 1
Main Loop
for (int i = 0; i < size; ++i)
Rooms: Full Flow

Room 1: What An Array Is

  • An array stores multiple values of the same type in consecutive memory locations.
  • Its size is fixed when you declare it.
  • If you only declare it, the values are not automatically useful.
Room Code
int grades[5];

Room 2: Declaration Syntax

  • Write the shape as dataType arrayName[arraySize];
  • Example: int c[5];
  • The brackets belong to the container syntax, not to the variable type.
Room Code
int c[5];
double marks[100];
char name[20];

Room 3: Indexing Rules

  • Use array[index] to access an element.
  • The first index is 0, not 1.
  • For size n, valid indices are 0 through n - 1.
Room Code
c[0] = 10;
c[2] = 30;
int x = c[2] + c[3];

Room 4: Initialization Patterns

  • Use an initializer list like int a[5] = {32, 27, 64, 18, 95};
  • Partial initialization fills the remaining values with 0.
  • You can also fill values in a loop using a[i] = ...;
Room Code
int a[5] = {32, 27, 64, 18, 95};
int p[5] = {0};
int q[] = {1, 2, 3, 4, 5};

Room 5: Writing Flow

  • Write starter code in this order: declare, initialize, traverse, use.
  • The traversal skeleton is for (int i = 0; i < SIZE; ++i).
  • Once the loop is there, you only have to decide what line belongs inside it.
Room Code
for (int i = 0; i < SIZE; ++i) {
    printf("%d\n", n[i]);
}

Write-From-Memory Block

#include <stdio.h>
#define SIZE 5

int main(void) {
    int n[SIZE] = {0};

    for (int i = 0; i < SIZE; ++i) {
        n[i] = 2 + 2 * i;
    }

    return 0;
}

Memory Palace Path

Walk the basics in one route: 10 toes guard the bounds, 21 net catches the declaration, 35 mail fills the slots, and 34 mower sweeps across every index.

Station 1: Toes Gate

Count zero, one, two, up to the last valid index. The gate shuts before size.

Transition 1 to 2

The toes walk into a giant net that catches five equal boxes.

Station 2: Net Wall

See int c[5]; hanging on the wall as the standard declaration shape.

Transition 2 to 3

Letters and numbers get delivered into the netted boxes.

Station 3: Mail Desk

Mail drops values through an initializer list or one by one with a[i] = ...;

Transition 3 to 4

A mower starts moving from left to right.

Station 4: Mower Lane

The mower loops with for (int i = 0; i < SIZE; ++i) and touches every slot once.

Transition 4 to 5

The route ends when the loop body starts doing useful work.
