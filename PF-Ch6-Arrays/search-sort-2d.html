Linear Search, Bubble Sort And 2D Arrays

This page focuses on algorithm flow. Search checks one element at a time, bubble sort compares adjacent pairs and swaps with a temporary holder, and 2D arrays add one more index plus one more loop.

Guideline Page
Quick Data
Search Result
return i; or return -1;
Swap Pattern
temp = a[i]; a[i] = a[i+1]; a[i+1] = temp;
2D Syntax
int matrix[rows][cols];
Rooms: Full Flow

Room 1: Linear Search Logic

  • Start from the first element.
  • Compare each element to the key.
  • If found, return the index immediately. If never found, return -1.
Room Code
for (int i = 0; i < size; ++i) {
    if (arr[i] == key) {
        return i;
    }
}

Room 2: Search Code Shape

  • Use a loop from 0 to size - 1.
  • Inside the loop, write if (arr[i] == key) return i;
  • After the loop, write return -1;
Room Code
int linearSearch(const int arr[], int key, int size) {
    for (int i = 0; i < size; ++i) {
        if (arr[i] == key) return i;
    }
    return -1;
}

Room 3: Bubble Sort Logic

  • Compare adjacent pairs.
  • If the left value is larger, swap the pair.
  • Repeat passes until the array is sorted.
Room Code
if (a[i] > a[i + 1]) {
    int temp = a[i];
    a[i] = a[i + 1];
    a[i + 1] = temp;
}

Room 4: 2D Array Syntax

  • A 2D array is a grid with rows and columns.
  • Declare it with dataType name[rows][columns];
  • Access each value with two indices such as matrix[r][c]
Room Code
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

Room 5: Nested Loop Flow

  • Use one loop for rows and another loop inside it for columns.
  • The outer loop moves the row index.
  • The inner loop sweeps through each column of that row.
Room Code
for (int r = 0; r < rows; ++r) {
    for (int c = 0; c < cols; ++c) {
        printf("%d ", matrix[r][c]);
    }
}

Code Block To Rehearse

int linearSearch(const int arr[], int key, int size) {
    for (int i = 0; i < size; ++i) {
        if (arr[i] == key) {
            return i;
        }
    }
    return -1;
}

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}

Memory Palace Path

This route moves from single-line decisions to grid movement: 47 rock compares, 70 case returns, 15 towel swaps, 29 knob controls row and column, and 34 mower becomes a nested sweep.

Station 1: Rock Tunnel

A rock checks each element against the search key.

Transition 1 to 2

If the key matches, a locked case immediately leaves the tunnel.

Station 2: Return Counter

The case carries either the index or -1.

Transition 2 to 3

Nearby, two adjacent values need to switch places.

Station 3: Towel Rack

A towel holds one value while bubble sort swaps the pair.

Transition 3 to 4

The floor opens into a control board with two knobs.

Station 4: Knob Grid

The first knob picks the row and the second picks the column of a 2D array.

Transition 4 to 5

One mower becomes two nested mowers moving across the grid.

Station 5: Nested Sweep

Use the outer loop for rows and the inner loop for columns until the table is fully visited.
