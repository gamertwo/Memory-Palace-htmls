Logic Patterns

Array Processing

This page is about how array questions think. Once you know the processing pattern, the code block almost writes itself: set starter values, sweep with the loop, test with a condition, update the answer variable, then print.

Guideline Page
Quick Data
Sum Pattern
total = 0; then total += a[i];
Max Pattern
max = a[0]; then compare from i = 1
Count Pattern
Use if inside the loop, then increment the counter.
Rooms: Full Flow

Room 1: Sum Means Accumulate

  • For totals, start with int total = 0;
  • Traverse the array.
  • Each pass adds the current value with total += a[i];
Room Code
int total = 0;
for (int i = 0; i < SIZE; ++i) {
    total += a[i];
}

Room 2: Maximum Means Compare

  • For maximum, start with the first element: int max = numbers[0];
  • Begin the loop at i = 1 because index 0 is already stored.
  • Use if (numbers[i] > max) before updating.
Room Code
int max = numbers[0];
for (int i = 1; i < SIZE; ++i) {
    if (numbers[i] > max) {
        max = numbers[i];
    }
}

Room 3: Count Means Test Then Increment

  • When the question says count positives, evens, or matches, keep a counter variable.
  • Write the decision inside the loop body.
  • Example: if (a[i] % 2 == 0) ++count;
Room Code
int count = 0;
for (int i = 0; i < SIZE; ++i) {
    if (a[i] % 2 == 0) {
        ++count;
    }
}

Room 4: Translate Question Words

  • Look for verbs: sum, find maximum, count, search, print.
  • The verb tells you the update line you need.
  • The rest of the loop skeleton is usually the same.
Room Code
/* sum   -> total += a[i]; */
/* max   -> if (a[i] > max) max = a[i]; */
/* count -> if (...) ++count; */

Room 5: Writing Flow

  • Starter variable first.
  • Loop second.
  • Condition third if needed.
  • Update line last.
Room Code
int answer = 0;
for (int i = 0; i < SIZE; ++i) {
    if (a[i] > 0) {
        answer += a[i];
    }
}
printf("%d\n", answer);

Code Block To Rehearse

int numbers[SIZE] = {45, 23, 89, 12, 67};
int max = numbers[0];

for (int i = 1; i < SIZE; ++i) {
    if (numbers[i] > max) {
        max = numbers[i];
    }
}

Memory Palace Path

The array-processing route is all about movement and decisions: 35 mail loads the starter variable, 34 mower sweeps through the elements, and 47 rock decides whether the answer changes.

Station 1: Mail Counter

Mail drops a starter value on the desk: 0 for sum or count, a[0] for maximum.

Transition 1 to 2

A mower starts its pass across the list.

Station 2: Sweep Lane

The mower moves index by index through the array.

Transition 2 to 3

Each element reaches a rock that forces a decision.

Station 3: Rock Checkpoint

If the condition is true, the answer changes. If not, the loop keeps moving.

Transition 3 to 4

The same route repeats until the last valid index.

Station 4: Update Desk

See the update line clearly: add, replace max, or increment count.

Transition 4 to 5

The loop stops and the answer gets displayed.

Station 5: Output Board

The finished variable is ready for printf.
