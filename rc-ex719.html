Exercise 7-19

The circuit is driven by an exponential source, so the response contains two exponentials: the source exponential and the RC natural exponential. The main tasks are to identify the dominant one, plot the source and capacitor voltage together, and find the maximum capacitor voltage and when it occurs.

$$v_C(t)=20e^{-50t}-25e^{-100t}\,\text{V},\qquad V_{\max}=4\,\text{V at }t=\frac{\ln 2.5}{50}\approx 18.3\,\text{ms}$$
Quick Data
Thevenin Resistance
$$R_T=100\,\text{k}\Omega$$
Capacitor
$$C=0.1\,\mu\text{F}=10^{-7}\,\text{F}$$
Input
$$v_S(t)=10e^{-50t}\,\text{V}$$
Initial Voltage
$$v_C(0)=-5\,\text{V}$$
Time Constant
$$\tau=R_TC=0.01\,\text{s}$$
Rooms

Room 1: Read the Natural Exponential

  • Since $$\tau=R_TC=0.01\,\text{s},$$ the natural response decays as
  • $$e^{-t/\tau}=e^{-100t}.$$
  • So the circuit's own decay rate is $$100\,\text{s}^{-1}.$$

Room 2: Read the Forcing Exponential

  • The source is
  • $$v_S(t)=10e^{-50t}\,\text{V}.$$
  • So the forcing decay rate is $$50\,\text{s}^{-1}.$$

Room 3: Decide the Dominant Exponential

  • The smaller decay rate dies more slowly.
  • Since $$50<100,$$ the slower term is
  • $$\boxed{e^{-50t}}.$$
  • So the source exponential is the dominant exponential.

Room 4: Reuse the Exponential-Forcing RC Formula

  • From the forced-response template,
  • $$v_C(t)=\left[V_0-\frac{V_A}{1-\alpha RC}\right]e^{-t/RC}+\frac{V_A}{1-\alpha RC}e^{-\alpha t}.$$
  • Here
  • $$V_0=-5,\qquad V_A=10,\qquad \alpha=50,\qquad RC=0.01.$$

Room 5: Compute the Coefficients

  • $$1-\alpha RC=1-(50)(0.01)=0.5.$$
  • So
  • $$\frac{V_A}{1-\alpha RC}=\frac{10}{0.5}=20.$$
  • And
  • $$V_0-\frac{V_A}{1-\alpha RC}=-5-20=-25.$$

Room 6: Write the Capacitor Voltage

  • Substitute the values:
  • $$\boxed{v_C(t)=20e^{-50t}-25e^{-100t}\,\text{V}},\qquad t\ge 0.$$

Room 7: Find the Maximum Time

  • Differentiate:
  • $$\frac{dv_C}{dt}=-1000e^{-50t}+2500e^{-100t}.$$
  • Set the derivative to zero:
  • $$2500e^{-100t}=1000e^{-50t}.$$
  • So
  • $$e^{50t}=2.5 \qquad \Rightarrow \qquad t_{\max}=\frac{\ln 2.5}{50}\approx 0.0183\,\text{s}.$$

Room 8: Find the Maximum Voltage

  • At $$t_{\max},$$ let $$x=e^{-50t_{\max}}=\frac{1}{2.5}=0.4.$$
  • Then $$e^{-100t_{\max}}=x^2=0.16.$$
  • So
  • $$V_{\max}=20(0.4)-25(0.16)=8-4=4\,\text{V}.$$
  • Therefore
  • $$\boxed{V_{\max}=4\,\text{V at }t\approx 18.3\,\text{ms}}.$$

Key Shortcut

Compare Decay Rates First

For this kind of question, do not start with differentiation. First compare the forcing rate and the natural rate. That immediately tells you the dominant exponential. Only after the full response is written should you differentiate to locate the maximum.

Memory Palace Path

This path is ordered by control: first compare the two exponential clocks, then write the full response, then use calculus only at the end to find the peak.

Station 1: Clock Gate

Read the natural clock $$e^{-100t}$$ from $$RC.$$

Transition 1 to 2

Once the circuit clock is known, compare it with the source clock.

Station 2: Source Clock

Read the forcing exponential $$e^{-50t}.$$

Transition 2 to 3

The slower clock dominates later, so the next room decides the winner.

Station 3: Dominance Vault

Store $$e^{-50t}$$ as the dominant exponential.

Transition 3 to 4

Now the full response can be built using the forcing-response template.

Station 4: Template Hall

Insert $$V_0,\ V_A,\ \alpha,\ RC$$ into the standard formula.

Transition 4 to 5

The coefficients must be simplified before the final waveform is clear.

Station 5: Coefficient Lock

Compute $$20$$ and $$-25$$ to get the final voltage expression.

Transition 5 to 6

Once the response exists, the graph tells you there is a peak, so calculus becomes necessary.

Station 6: Slope Door

Set $$dv_C/dt=0$$ to locate the maximum time.

Transition 6 to 7

After the peak time is known, plug it back once to get the peak voltage.

Station 7: Peak Seal

Store $$V_{\max}=4\,\text{V}$$ at $$18.3\,\text{ms}.$$
